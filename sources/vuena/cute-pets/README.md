## 离线复建

在仓库根目录、项目依赖已安装的环境中执行：

```sh
node tools/prepare-fox-asset.mjs
```

脚本只读本地源文件，先校验上述 SHA-256，再写入 `public/assets/wildlife/fox.glb`，并在标准输出提供哈希、包围盒、归一变换和眼部坐标。无需下载或安装额外依赖。

处理规则：

1. 只保留原始 `fox_LOD0`，删除 `fox_LOD1` 节点、mesh 和不再引用的二进制数据。源文件两个 LOD 同时在场景中，不能直接完整加载作为单只动物。
2. 保留 LOD0 的原几何属性、索引、蒙皮、19 根骨骼、原粗糙度及两张嵌入 PNG，不重采样贴图。仅将 `metallicFactor` 显式设为 `0`：已核验原 ORM 蓝通道 512 × 512 个像素全部为 `0`，所以这与原文件默认因子 `1` 乘该贴图的非金属效果等价。
3. 只保留 `idle`、`walk`、`run` 三个原地动画，删除三段中 `Lids` 的 `translation` 通道。其余动画通道逐字节保留，眨眼由运行时统一控制。
4. 源模型已为 `+Y` 向上、`+Z` 朝前，不额外旋转。新增共同根节点 `HOW_fox_root`，以 `idle` 的 `t = 0` 姿态统一缩放至总高 `1.10`，居中并落地。原始顶点与骨架局部变换不因归一而改写。

## 眼部运行时契约

睁眼、深色眼部和白色高光画在头部连续网格的 atlas 上；不存在独立眼球 mesh、眼球骨骼或 morph target。眼皮则是两片独立的原始几何，每片 LOD0 含 169 个导出顶点，均完全绑定到同一根 `Lids` 骨骼。原作眨眼通过把眼皮覆盖片沿头部向前移出，遮住睁眼贴图完成。

下列位置均为原始 `Lids` 局部坐标（父节点为 `Head`），不乘资产归一缩放：

```text
restPosition   = [-4.892150312462651e-22, -7.450580596923828e-9, 9.313225746154785e-9]
closedPosition = [-5.82076742361437e-9, 0.05124984681606293, 0.011388848535716534]
closedDelta    = [-5.820767423613881e-9, 0.051249854266643524, 0.011388839222490788]
```

`closedPosition` 取自原始 `idle` 动画的最大闭合关键帧。运行时在动画更新后应用 `Lids.position = restPosition + blink * closedDelta`，其中 `blink` 范围为 0 到 1。三段裁剪后的动画仍保留原始 `Lids.rotation` 和 `Lids.scale`，但不会再覆盖该位置。

眼部 atlas 位置（源模型空间的 `+X` / `-X`，与左右屏幕无关）：

| 眼部 | UV 中心 | UV 半尺寸 |
| --- | --- | --- |
| `+X` 一侧 | `[0.412841796875, 0.26025390625]` | `[0.028076171875, 0.04052734375]` |
| `-X` 一侧 | `[0.586669921875, 0.26025390625]` | `[0.028076171875, 0.04052734375]` |

眼皮覆盖片 UV 在 `v ≈ 0.627–0.748`，与睁眼区域分离。细微视线变化可在上述睁眼区域对 albedo 和 ORM 使用一致的平滑 UV 偏移，保持周围头部区域不动；这属于贴图表现，不是原作者提供的眼球转动。不得切开连续头部网格当作球形眼球旋转，以免留下缝隙。

`Head` 原始绑定姿态的局部轴对应模型轴约为：X → `[1, 0, 0]`，Y → `[0, 0.2169305, 0.9761867]`，Z → `[0, -0.9761868, 0.2169305]`。因此模型竖直偏航轴在 `Head` 局部空间约为 `[0, 0.2169305, -0.9761868]`；不能把 `Head` 的局部 Y 直接当作模型向上轴。
