# HUD 与操作路径（2026-11-05）

本轮整改沿用透明 HUD、场景内操作与营地侧栏。旧 R4 文档保留历史记录；涉及常驻内容、工具布局和面板层级时，以本文件为准。

## 常驻信息

左上只保留地点与日期时间；右上为沙漏当前速度、暂停，以及夜间才出现的休息入口。物资数量在物品面板内查看；成功存档不常驻提醒，存档故障仍即时提示。常规操作反馈出现 4.5 秒后收起；进行中的进度、取消按钮及阻止操作的原因保留。

右下保留路线、物品、镜头、操作四个图标加短标签。镜头按钮和沙漏倍速点开再显示。常驻层不用不透明底板；上下文层统一森林绿半透明面板、字号、边框和至少 44×44 CSS px 的按钮。不能靠缩字号、隐藏标签或缩小触控区容纳新增功能。

## 查看与行动

点选目标先显示名称、状态和当前动作。设施远处只有一个走近入口，可以展开详情和改造要求；到达不会自动取放、制作、交易或扣料。近处才显示具体操作和材料、图纸限制。安装操作点与普通使用位置有差异时，已选部件明确显示“走到安装位置”。

树木快照单独提供 `near`，由既有采伐距离规则计算；UI 不再用 `canChop` 反推远近。远处走近、近处砍树，体力或额度不足不与距离混为一谈。采枝入口标注“查看枝杈”，与其仅切换选中目标的实际行为一致。

改造列表默认收起，展开后逐件查看；同一时刻仅展开一个部件的图纸、材料和安装按钮。施工时自动展开对应部件和进度。火塘先给喝汤、面包和阅读入口，煮汤配方按需展开。说明不重复展示库存、内部模块、未来接口或实现计划。

路线面板明确分成“营地 · 查看”和“风景 · 前往”。营地快捷入口只选中目标，不偷偷开始移动；风景路线明确发出寻路意图。

物品面板使用随身、营地、家具、图纸、穿戴五个固定文字分组。营地材料类别使用页内筛选，不把十余分类挤进横向图标条。随身负重摘要只出现一次；搬运说明与地面材料列表按需展开。原有拖拽取放和按钮备用路径保留。

## 面板与输入

路线、操作说明、物品与目标详情避免同时堆叠；物品打开时隐藏重复地图。Esc 优先关闭当前工具浮层或目标，再交回既有暂停逻辑；仓库和阅读保留各自关闭行为。底部工具、摇杆和目标操作区保持间距。手机目标卡限制高度并内部滚动，标题和关闭入口保持可见。

## 验证

本轮针对构建、林业距离语义、设施远近操作、面板切换、改造展开及桌面/手机布局验证。最终实测记录见 [整改范围与结果](scopes/hud-interaction-cleanup.md)。
