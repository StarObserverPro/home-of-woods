# HUD 与操作路径（2026-11-06）

当前本地实现采用已获认可的粗木界面；具体范围见 [回接范围](scopes/rustic-ui-mainline.md)。尚未提交或发布。

## 常驻与窗口

探索时显示地点、日期时间、沙漏、暂停及路线／物品／镜头／操作入口。打开玩家窗口时让出常驻工具和摇杆的位置。木框使用项目自绘树皮边缘和斜劈木纹；选中标签由按钮自身绘制，保留完整内边距，不裁切文字或底板。

工作台、设施改造、行商、仓库、穿戴、图纸、火塘和路线复用图标格与分页。桌面和横屏并排显示图标及选中详情，竖屏上下排列；名称、数量、成本与操作集中在选中详情。图标按钮提供可访问名称。长说明使用独立翻页；不以内部滚动条或隐藏溢出适配主要窗口。故事正文保留阅读分页。

## 行动路径

工作台按家具／日用／餐厨筛选配方，学习、制作和装配沿用原运行时命令。设施分为使用、改造、说明三页；改造集中显示一个部件的材料与安装操作。火塘按用餐／烹煮筛选，可选择现有木碗。路线按营地与风景筛选，营地只查看目标，风景按钮发出寻路意图。

物品按随身、营地、家具、图纸、穿戴、地上分类。营地仅列实际持有材料；先选物品，再取出、存入或投放。家具先选物件，再查看用法或进入场景摆放。穿戴先选位置，再脱下或选择随身衣物穿上。物件仍使用稳定身份，数量与操作资格来自原领域快照。

行商买入、卖出和货单共用选择详情，买入加减数量，卖出加入待售，结算统一提交；账单保留粮款偿还、本次赊账和结算后余额，见面礼独立领取。

## 输入与状态

Esc 收起当前窗口，再交回暂停逻辑。普通菜单打开只阻止场景手动输入，制作、导航等既有动作继续；仓库与阅读保留原有暂停语义。摆放和木料投放时退出菜单布局，让出地面操作。菜单本地状态只保存分类、页码与选中项，不保存第二份库存、交易或制作结果。

显示设置在操作窗口或暂停的显示页；存档操作放在暂停的存档页，恢复／重新读取的影响保留在所选操作旁。检视入口使用内存世界与存档，不读写正式玩家存档。

## 2026-11-06 菜单关闭与批量取放

窗口外点击或触屏轻点收起菜单，该次输入不触发场景行走/选中；关闭按钮与 Esc 保留。摆放和手动投放期间仍使用原本的场景操作。
随身材料和营地取出提供 1 份、5 份、尽量多，默认尽量多；拾取按负重与空间上限计算，一次事务完成。随身按批存入及全部存入沿用现有入口。木料堆增加全部放入、全部收回仓库，保留单根手动投放；全部放入最多填满 32 个物理位置，超出部分留在原库存。
本轮范围与验证见 [菜单关闭与批量取放](scopes/menu-dismiss-bulk-transfer.md)。
