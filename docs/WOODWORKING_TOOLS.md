# 基础手工木作：工具、动作与接入边界

**审查草案，2026-11-13。** 本页用于确定后续小游戏的工艺，不是宣布下列工具已经可玩。现有可玩切片仅为正交锯榫及一次辅助收尾。先区分实际动作，再决定需要什么参数和几何；不从“所有工具共用一个深度滑块”反推木工。

下表的动作划分参考实际手工具教学；“游戏接入”是本项目设计判断。斧/锛/劈刀及中式工具形制仍需在其具体任务施工前单独核验。不是穷尽世界各地传统工具的目录。

| 工具或工具组 | 典型动作及工艺要点 | 游戏需要表达的选择与状态 | 当前接入边界 |
| --- | --- | --- | --- |
| 尺、角尺、划线刀、划线规 | 建立基准、跨面转线、等距放样；测量应从一致的基准面/边出发。[1] | 实体工作面、基准边、距离、线所属局部坐标；不是鼠标轨迹好坏 | 已有选面和量具辅助；任意角度及多件划线转移未做 |
| 手锯、背锯 | 顺纹/横纹直切、止锯、废料侧、锯缝；锯肩可以先于锯颊。过深会伤及榫芯。[2] | 入口、切面、往复行程与进深分别定义；可达性、留料侧、未断连接 | 已做正交满行程、有限进深；不同齿型、背板实际净空、斜锯待审 |
| 平凿/榫眼凿 + 木槌 | **薄削、凿剔、劈离是不同动作**。薄削取少量材料；凿孔逐段去料；顺纹劈离受木纹与止裂切口影响。[3] | 开口/已暴露面、刃口宽度和朝向、每层深度、排屑空间、底面、壁面、止裂边界 | 下一轮单独审查。自动收尾不是这套操作的替代实现 |
| 平刨、肩刨、槽刨、清底刨 | 平面修整、台阶、沟槽与定深清底不是同一刀路；槽刨靠边导向并分层，清底刨可在粗去料后校平底面。[4][5] | 刨底支承、导向基准、进出路径、每层吃刀与目标深度 | 平面/槽类可研究复用正交后端，但要实现各自支承及入口规则 |
| 手摇钻/弓摇钻、钻头 | 孔位、轴线、孔径、深度；贯穿孔可在尖端露出后翻面接钻，降低出口崩裂。[6] | 圆孔/轴向去料、入口和出口、背衬、同轴复位 | 需要圆柱/孔特征几何能力；不得用方槽冒充圆孔 |
| 削刀、辐刨、木锉、刮片 | 外形粗修、曲面修整和表层精整；辐刨可处理曲面，切削方向与木纹有关。[7][8] | 轮廓段、可达曲率、切削方向、表层去料与粗糙度 | 不适合直接套有限锯面；先选一种代表性物件另审 |
| 斧、锛、劈刀/木楔 | 劈料、粗整、顺纹分离等候选动作 | 木纹方向、止裂、支承、剥离块与不可预测缺陷 | 本页仅登记候选；需找对应手工过程核验后再定模型 |
| 台钳、夹具、挡块、木槌 | 固定、重复定位、装配；不是每次都去料。[8] | 少量可理解的姿态/支承预设；装配接触、方向、夹持遮挡 | 锯榫已有平放/端头朝上/侧面朝外；无夹具物理，装配沿用主线 |
| 胶、木销、楔、涂饰工具 | 连接、锁紧与表面处理 | 连接状态、消耗物、工时、固化/等待、后续可拆性 | 本轮只有面漆颜色；其他属于连接/表面工序，不能以锯缝状态替代 |

## 工序之间共享什么

工件统一使用毫米坐标，X 沿料长，Y 沿高度，Z 从近侧到远侧。`Surface` 保存外露面的轴、法向符号、平面位置和实体面片；其身份来自工件，不来自相机。新切面只有在实际去料后才存在。当前正交模型的切平面局部坐标由其余两个轴确定。

`Workpiece` 持有原料、实际实体、操作日志、材料账和检查状态。图纸目标不能直接改写实际实体。`SawOperation` 将入口、切面位置、锯缝侧、进深和夹持放进可回放数据；`sawProvider.preview` 被 UI 和执行前校验共同使用。`OperationProvider` 显式声明几何类别，使不支持的工件类型失败，而不是悄悄近似。

新增工具的最小工作包是：

1. 对照一段真实流程，确定前置表面、支承、刀具可达性及可交换工序；写一条玩家能完成的代表操作。
2. 增加该工具自己的操作类型与预览/校验/执行；扩展操作回放分派和版本校验。复用去料、连通性及体积账，而不是复制宿主库存事务。
3. 确认几何后端能表达结果。矩形凿槽可能复用正交实体；圆孔/曲面/斜面需要新增几何支持，并同步面身份、选中、预览、成品包络及评分。
4. 让一个具体图纸使用这个工具。验收合法动作、一个典型错误、材料守恒、可补救性、暂停恢复与真实输入。没有消费者的空 service 不提前建设。

当前教程建议只是 `tenon.ts` 的 `TASKS`；锯切内核不按任务名决定最终表面。后续可有不同图纸及流程建议，不必修改 `solid.ts` 来新增“第六刀”。但这并不表示任意工具只注册名字就能工作。

## 凿子下一轮应该先审什么

先分开做“削平已有榫颊”和“从完整木面开榫眼”的纸面流程，再挑其中一个切片。前者要知道实际凸余在哪里、刃口能否进入；后者还要知道如何分层、何时排掉碎料、壁面如何保留及何时翻面。顺纹劈离涉及裂纹传播，不应伪装为矩形实体减法。[3]

游戏可以压缩重复锤击和薄削次数，但不能把尚未开放的封闭区域、被支承挡住的位置或不能拔出的废料视为已经处理完。锯子的一次确认代表完成一个有限锯入动作；凿子不必采用同一确认粒度。
