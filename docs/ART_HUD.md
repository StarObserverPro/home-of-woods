# 美术、建模与 HUD

对应 HOW-BASELINE-1.0。当前尚无按本基线验收的美术或实机画面；本基线 PR 之前的设计稿、模型和截图均不作为风格锁定或阶段完成依据。

## 视觉目标

Low-poly + 圆润 Q 版 + 塑料玩具感。以清楚的大体块、适量倒角、柔和宽高光表现实体厚度。森林、山体、房屋、人物和 HUD 使用同一比例、调色与材料语言。

| 对象 | 规格方向 |
| --- | --- |
| 树 | 明确针叶/阔叶轮廓、短粗树干与成团树冠；阶段轮廓可辨；巨木有地标体量 |
| 地形 | 大块连续山坡、清楚谷地与溪岸，家园留视线；远山分层减少细碎噪点 |
| 房屋 | 厚屋顶、圆钝边、深窗框；残破/修缮/完成/扩建通过模块变化表达 |
| 人物 | 大头、小身体、短手脚；工具姿态远景可辨；后续支持头部、耳尾和服饰模块 |
| 工具/材料 | 粗手柄与夸张清楚轮廓；枝杈、原木、结构梁外观可区分 |
| 色彩/材质 | 森林绿、嫩草绿、奶油白、暖木棕，少量暖色点缀；不透明非金属为主 |

避免写实脏污、镜面金属、强 bloom、过密叶片和各素材包原色混杂。季节变化仍属于同一套视觉语言。选中、禁用和许可信息同时使用文字/形状，不只靠颜色。

## 免费资源优先，修整后一起接入

先从许可适合本公开仓库的 CC0 等免费模型、纹理、动画和 UI 资源中选型；找不到合适候选时再做有针对性的定制。免费资源也必须修整，不能原样混搭造成不同缩尺与材质。

统一轴向与尺度、根节点/落地点、法线、网格复杂度、材质与色板、UV/纹理、骨骼和动画、碰撞/命中、树木阶段与 LOD。优先交付可导入的 GLB/glTF；实际格式与性能参数在批次前确定。

按“家园+邻近树木+地形”“修屋动作+工具+材料”“四季+行商+扩建”等可见功能包接入。一个批次包含准入记录、修整后的文件、导入/缓存入口、碰撞交互、实际状态变化与截图证据。完整流程见 [ASSET_PIPELINE](ASSET_PIPELINE.md)。

Marble 2 可用于场景建立、空间构图和交互原型；Midjourney 可用于世界构图、配色、角色/建筑设计稿。设计稿用于审稿，不能代替可旋转场景、独立模型或实机交互；产出按同一流程准入，不自动继承 CC0。

## HUD 与输入

游戏场景占据主界面。顶栏只保留日期/季节、必要资源与暂停入口；底部工具栏随已实现功能出现，不保留锄头、水壶或虚设系统占位。

| 功能 | 桌面 | 手机 |
| --- | --- | --- |
| 移动 | 键盘与点击移动；镜头相对方向一致 | 移动区与动作区分离 |
| 目标 | 选择、名称、状态、资源与许可原因 | 同一信息的底部 sheet |
| 主动作 | 明确的采集/采伐/修缮意图 | 大号上下文动作按钮 |
| 背包/配方 | 需要时打开，按用途分类 | 分类或分页，避免无限横滑小图标 |
| 建造 | 占地、旋转、确认/取消、材料需求 | 可触达按钮，预览仍可见 |
| 镜头 | 拖动旋转、缩放、复位 | 明确区分拖动/双指与点按 |

触控目标至少 44 CSS px，适配安全区；图标配短标签。点击 HUD、拖镜头或关闭面板不穿透到场景。键盘提供 Esc、焦点与操作入口；选择树不自动砍树。

视线遮挡时局部淡化树冠/建筑，碰撞和资源不受影响；禁止为看见角色而移动树位。镜头复位与舒适缩放范围在 M0 确定。

动作使用短晃动、轻回弹、少量木屑与尘土，提供减少动态效果选项。domain 先结算，scene 表现；不由动画次数决定资源。

## 看图与操作验收

固定 seed/相机/日期/状态，检查家园望谷、谷底回望、人物/树/屋比例、树木阶段、巨木、许可、修缮/扩建和桌面/手机 HUD。资源包还需修整前后对照、碰撞/命中、LOD 与释放证据。

当前提交的实机图应能辨认塑料玩具质感、资源类型、角色动作和主要交互；不能以旧试稿、漂亮概念图或孤立模型展示替代场景整体结果。
