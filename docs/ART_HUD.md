# 美术与 HUD

状态：首版视觉方向与交互约定，尚无实机画面。

## 塑料玩具森林

**Low-poly + 圆润 Q 版 + 塑料玩具感。** 轮廓主要靠大体块表达，在关键边缘加入少量倒角；低面数保留形体节奏，柔和高光让材质像有厚度的模塑玩具。

| 对象 | 造型方向 |
| --- | --- |
| 树 | 短粗树干、成团树冠，少量清楚的分面；树苗和成熟树沿用同一轮廓语言 |
| 人物 | 大头、小身体、短手脚；工具和挥动姿态在远景也能辨认 |
| 房子 | 厚屋顶、圆钝边角、深窗框、小烟囱；门窗作为明确的立体部件 |
| 农田 | 整齐但略有手工感的田垄，作物阶段用尺寸与轮廓区分 |
| 工具 | 粗手柄、夸张但清楚的斧头/锄头/水壶外形 |
| 环境 | 森林绿、嫩草绿、奶油白、暖木棕，辅以少量橙黄与浆果红 |

表面以不透明、非金属材质为主，保留柔和、较宽的高光；木头、叶子、屋顶通过颜色与适度粗糙度变化区分。避免写实脏污纹理、镜面镀铬、全屏强 bloom 和细碎高频噪点。

首版镜头采用可调缩放的斜俯视，优先检查近似正交的玩具沙盘效果。角色、地块和建筑在同一比例体系里；相机角度与跟随参数由视觉小样确定。挡住角色或建造目标的树冠允许局部淡化，不能改变碰撞或采伐状态。

动作反馈采用短促晃动、轻微压缩回弹、少量木屑和柔和落地尘土；真实结算由 domain 决定，画面只表现结果。提供降低动态效果的选项。

## HUD 信息层级

借鉴水晶花园的顶栏摘要、选中对象面板、主要操作区和手机底部面板。信息按“现在有什么、选中了什么、接下来能做什么”组织。

| 区域 | 桌面 | 手机 |
| --- | --- | --- |
| 顶栏 | 时间、少量关键资源、暂停入口 | 压缩摘要，资源详情点开查看 |
| 工具栏 | 底部 5 个槽：斧头、锄头、水壶、种植、建造 | 大按钮工具条，当前工具带名称 |
| 对象信息 | 选中树/田地/建筑后出现可收起的侧栏 | 底部 sheet：关闭、摘要、展开三个状态 |
| 上下文动作 | 目标名称、可用操作、成本/原因 | 靠近拇指区的主动作按钮，随目标变化 |
| 背包与配方 | 独立面板，类别筛选和清楚的数量 | 分页或分类列表，避免无限横滑小图标 |
| 建造模式 | 旋转、材料需求、确认、取消 | 明确的大号确认/取消，预览区域保持可见 |

首版默认隐藏空白信息与尚未实现的系统。HUD 图标采用有厚度的彩色玩具块，面板使用奶油色底和柔和边缘；文字、数量和选中状态保持清楚。

## 输入与状态约定

- 桌面与手机使用同一套 HUD 数据和 action ID；布局不同，工具选择、背包和结算状态一致。
- 左侧移动区与右侧动作区在手机上分开；点按、拖动镜头和长按必须区分，拖动结束不触发砍伐或建造。
- 点击 HUD、打开面板、滚动列表时，不得同时触发背后的场景操作。
- 触控目标至少 44 CSS px，并适配安全区。图标配短标签；不能只靠颜色区分有效、无效和选中。
- 建造预览显示占地边界与具体无效原因；确认前的预览、旋转和取消都不扣材料。
- 同时只开一个主要面板；关闭后恢复合理焦点与输入。键盘支持操作入口、Esc 关闭和可见焦点。
- 获取材料用短暂增量提示，关键错误靠近当前操作显示，避免遮挡场景的连续弹窗。
