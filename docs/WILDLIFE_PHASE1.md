# 林间动物 · 第一阶段

对应 HOW-WILDLIFE-1。范围为松鼠、野兔及其最小出场闭环；实现位于 `feat/wildlife-phase1`，未合并、未部署。主线前置为 PR #6。当前规则与构建通过，浏览器验收结果单独记录于 [本批证据](../evidence/wildlife-phase1/README.md)，不把模型网站预览当作实机证据。

## 玩家会看到什么

白天，松鼠和野兔在营地外围或下坡小径短距离活动。它们会停下观察，玩家太近时先警觉再退开。动物没有可点击的采集命中体，不挡玩家走路，不占 E 键，也没有未实现的喂食按钮。第一阶段没有爬树、捕食、战斗或掉落。

两只动物来自 Gobkit 同一套免费 CC0 动物包；采用一套尺寸修整、非金属材质和柔和粗糙度，只保留 idle/walk 动画。原文件、许可摘录与修改记录见 [来源目录](../sources/gobkit/animal006/README.md)。松鼠 584、野兔 596 三角形，各 16 骨骼；不使用毛发或透明毛片。近景与普通镜头使用同一模型，远处整体裁剪，不切换另一套造型。

## 出场和接口

`content/wildlife` 定义两种动物及候选参数；`world/wildlife-layout` 提供固定锚点；`domain/wildlife` 负责时段、预算、身份和受限行为；`scene/wildlife-presentation` 只播放表现；`app/runtime` 在现有固定步长内驱动。共享地表与现有碰撞查询决定可走位置，没有额外寻路世界、定时器或 RAF。

常态两只、哺乳动物全局上限三只、同种最多一只；进出场也占额度。当前每 120 游戏秒一个窗口，停留至窗口第 94 秒，退场 1.2 秒；空窗不补满。窗口在营地和下坡两组候选间轮换，而非每个锚点常驻两只。时间取现有视觉昼夜，6–19 点可出现。被阻挡、过近或素材不可用的候选在本窗口跳过，不反复重试。

这些数值用于首轮观感验证，集中维护于 `content/wildlife.ts`，不作为大型稀有动物的刷新参数。出现、退避与自身观察动作不消费库存。查询以 `{kind: 'wildlife', encounterId}` 返回真实存在目标的能力列表；本阶段列表为空。未来显式互动仍接现有玩家动作协调、版本复核与事务系统，不通过动画回调发资源。

## 状态、存档与生命周期

活动 encounter 放在唯一 `GameState.wildlife` 临时切片中，表现重建复用同一批身份。普通环境动物没有好感、物品结果或稀有冷却，磁盘快照不保存逐帧姿态；从已保存的世界 seed/time 恢复同一窗口、候选与到期时间，不重新获得完整停留时长。动物在合法锚点重建姿态，靠近或被占用的锚点可跳过。存档 schema/ruleset、库存与树位身份不变。未来稀有动物或宠物上线前必须另做持久化迁移，不能套用这一临时姿态规则。

可选动物模型加载失败时仅关闭对应候选，不阻断已有游戏。每次退出释放自身骨架、动画和材质副本；几何和纹理由现有 Resources 所有者共享并最终释放。动物无独立监听或音源。检视夜景只改变视觉显示，不推进时钟或重抽实例。

## 验收与回退

`npm run check` 覆盖原有回归及新增动物规则、资源回收、加载降级和存档边界测试。浏览器脚本 `tools/capture-wildlife.mjs` 通过现有游戏 UI 获取桌面/手机视口、单体/同框、夜景与五轮卸载重入证据。`?inspect=1` 的场景检视新增“林间动物”“松鼠近景”“野兔近景”，不新增常驻游戏 HUD。

历史森林接入审计改为读取 PR #6 的不可变提交，原 SHA、证据和断言保留；新实现另验收，不伪装成旧截图仍代表当前源码。没有提高原林下预算。回退本功能批次及其资源即可恢复此前游戏；没有需要反向迁移的持久动物字段。

后续鹿、鸟群、蝴蝶、猫头鹰与音效，以及岩壁/树皮/草苔改进均未实施。真实手机 GPU、长时间游玩观感和跨设备性能仍需实际设备验证。
