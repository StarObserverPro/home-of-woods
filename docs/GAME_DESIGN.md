# 正式需求基线：森林之家

基线 ID：**HOW-BASELINE-1.0**；批准日期：2026-10-29。需求方向已获用户批准；M0–M2 均未按本版验收。实施范围和参数状态见 [MILESTONES](MILESTONES.md)。

本基线 PR 之前的初步试稿与旧原型均失效为产品依据。旧代码或资源需按本版重新准入与验收，旧完成结论不继承。此规则覆盖早期种田循环、美术样式、布局、示例数值和截图。

## 1. 产品定位

单人林场经营 + 自由造景 + 木作制作的轻度 RPG。玩家操纵 Q 版角色，在会生长、换季的森林里采集、维护、有限采伐、种树与建设。游戏进度体现在森林和家园的持续变化。

- 视觉：low-poly、圆润塑料玩具、大色块和柔和光照；可旋转、可缩放的斜俯视。
- 世界：温带混交林、有限连续山谷；长期基础树种 6–8 种，不在 M0–M2 强制一次做全。
- 生活：自由活动与可选小目标；没有普通农作物种植、每日浇水收菜循环，也不以每日签到维持树木和宠物生存。
- 开局：小帐篷与残破木屋，先修理再扩建。基础工具、工作台和第一批材料不能互相锁死。
- 长期：完整工坊链、可选实际雕刻/组装情景、模块化角色、野生动物和宠物、更多 NPC 互动与有限扩张。

## 2. 山谷空间

| 区域 | 布局与用途 | 首版边界 |
| --- | --- | --- |
| 家园混交带 | 主体大山针阔混交处；帐篷、旧屋、工坊空地；向谷地留视野 | 核心建设区 |
| 宅后上坡 | 向上可爬一段，形成回望家园的路线 | 更高山体先为景观 |
| 下坡经营林 | 从家园向溪谷展开，分布林木与采集点 | 主经营路线 |
| 溪谷 | 河岸、林间空地与过溪位置连接两侧山体 | 主水系固定 |
| 对面小山 | 隔溪相望，提供不同林相、坡向与观景位置 | M0 建形体，M2 接通经营路线 |
| 外围群山 | 几座山构成完整景观与未来空间 | 无详细经营模拟 |

景观覆盖与详细模拟分开。通过坡度、树种比例、林间开口、岩石和水系关系形成区域差异，不能只扩大重复森林面积。具体范围、山数和高差均 TBD。

建筑采用预制模块加自由造景。家园、道路与经营树位分别预留占地；主山脊、溪流和巨木不参与普通编辑。长期支持局部平整、台阶和坡地整理；自由塑形编辑器不进入 M0–M2。

## 3. 固定树位与树木个体

树位固定坐标、生态分区、允许树种与占地；树木个体记录这一代的种类、年龄、尺寸潜力、外观变异、健康、保护与采集状态。树位 ID 长期稳定，每一代树使用独立个体 ID。

默认生命周期：成熟树 → 合法采伐 → 树桩/待补生 → 原树位幼树 → 成长 → 成熟。原位回补是默认机制；等待时间、树桩消退和树种延续权重待调平。

- 初始个体和新一代树按生态分区权重生成；个体结果持久化，不因读档、重载或申请许可重新抽取。
- 自然繁殖先以补充预定义空树位实现，不做任意位置扩散模拟。
- 人工种植使用允许的空树位；成功后取消同位置待补生任务。家园先提供预留植树位置。
- 建筑不能占用采伐后暂空的再生树位；放置和塑形不能隐式删除受保护树或重置资源。
- 稀有外观、尺寸与采伐资格分别判定。普通树到达自身尺寸上限后仍是经营树，不自动转成地形巨木。
- 巨木是固定地标，永久不可采伐；可独立刷新枝杈、树脂、果实和特殊物产。女神特批与工具升级均不解除巨木限制。

## 4. 林业资源与年度额度

| 资源线 | 来源与用途 | 约束 |
| --- | --- | --- |
| 森林物产 | 蘑菇、干蘑菇、四叶草、树脂球等；交易、供奉与制作 | 季节性、有限库存与再生 |
| 枝杈/小型木料 | 逐树季度采集、自然落枝；小木工、家具、装饰、工具与轻修缮 | 较宽裕，各树独立恢复 |
| 建筑木材 | 获准整树采伐；原木、结构梁与结构板 | 年度体量点数硬约束 |

结构木可向下产生小型余料；枝杈、小家具或普通贸易不能无限转换为结构木。材质/树种等级与结构用途分开，不能通过换名、升级或拆卸跨越资源线。

### 即时规则审批

玩家选中树后看到资格、成本、预计产物与不可采原因。顺序为：个体资格 → 成材门槛 → 工具条件 → 年度额度 → 操作 → 整笔结算。巨木和未成材小树不可采伐；其他树按持久化个体状态判定。许可审批无随机等待或 NPC 审批时长。

可用点数 = 当年基础点数 + 已授予特批点数 − 已用点数 − 有效动作预留。特批另有年度累计上限。

首版只为执行中的采伐动作短暂预留，不开发长期囤积、可交易许可证。取消或失败释放预留；完成时同时结算树状态、原木、额度和原位补生任务。生长、跨年或目标变化时重新校验，旧个体/旧年度的授权不得重用。

采伐点数与结构木产出消费同一体量依据；个体变异和材料升级不能给出未计点的大量结构木。工具升级可提高效率或解锁合格目标，不突破额度和保护规则。

### 守恒与持久化

- 每个资源池记录个体与日历状态；换季最多恢复到容量，错过季度不无限叠加，树苗不立即领取成熟树整季资源。
- 采伐、制作、供奉、交易、修缮和拆建整笔提交；重复命令或动画回调不能重复结算。
- 移动建筑无损；拆除仅退实际投入的对应材料，升级结算差额。初始破屋结构与玩家投入分开登记。
- 风折、病死、清理、地形编辑与可拆商品不得额外增发结构木；相关玩法上线前必须定义额度或回收规则。
- 存档整体保存时间、库存、树位/个体、额度、建筑投入与到期事项。重载和分区卸载均不刷新资源。
- 跨年基础额度与特批账目仅切换一次，库存木材保留；未用额度是否结转为 TBD。休息跨年是正常时间推进，不设真实世界签到门槛。
- 首版验证正常操作与存读档一致性，不建立联网反作弊或阻止玩家手改本地存档的系统。

## 5. 盖亚、行商与制作

盖亚初期通过神谕纸条介绍规则并提供交互。M2 接入多档祈愿：明确的基础回报加额外惊喜；特批点数受统一年度上限约束，森林赐福只使用合格空树位或受限生长效果。无可用树位时的延期/替代结果需明确提示，不能扣供奉后无反馈。女神模型、祭坛和短情景后续制作。

行商每季定期来访几次，基础交换加季节需求；带来工具材料、种苗、图纸与后续治疗用品。M0–M2 不提供无限建筑原木或可拆出大量原木的商品。小物产需在交易、供奉和制作之间形成选择，具体交换比率待调平。

未来可请行商组织深山大树搬运；活树移栽或大木料运输、许可与额度归属待专项确定，不并入首版普通商店。

完整工坊链是长期目标；M1 使用简易工作台完成修屋，M2 加入材料等级升级、少量小木工与木屋扩建。实际手作小游戏可选，普通配方仍可完成基础目标；手作结果不能增发受限结构木。小游戏失败损耗与外观奖励后续定义。

## 6. 时间、事件、角色与操作

唯一游戏时钟管理日/季/年、成长、再生和来访。允许休息推进时间；暂停、后台与关闭期间首版停止推进，不补算离线收益。到期事项按时间有序、幂等处理，不为每棵树建立真实时间定时器。

生态事件包括自然采集机会、少量树病/风折和特殊发现。疾病通过行商快速治疗与祈福等待形成成本/时间交换；不设计离线期间突然损失整片森林的惩罚。复杂事件、传播与治疗平衡在 M2 后扩展。

长期支持人类、拟人动物和森林精灵的模块化外观，基础移动与工具规则共用，初期不设种族数值差异。宠物有窝、跟随和轻探索提示，野生动物可观察；培养和复杂互动后续开放。

桌面键盘移动与点击移动/交互结合；移动方向与镜头一致。手机触控移动加上下文动作。镜头可旋转、缩放与复位；遮挡淡化不改变碰撞和资源。点击目标、拖镜头、HUD 操作与建造确认明确区分，采伐必须是显式动作。

## 7. 首版路径与排除项

M0：山谷、人物、镜头、树位和资源生命周期。M1：帐篷到修好木屋，采伐额度、原位补生和存档闭环。M2：跨季跨年、人工种植、盖亚、行商、材料升级、扩建与少量造景。

完整验收以 [MILESTONES](MILESTONES.md) 为准。完整树种、宠物培养、全角色定制、自由塑形、复杂生态、女神场景、手作小游戏和深山搬树均不作为 M0–M2 的完成门槛。
