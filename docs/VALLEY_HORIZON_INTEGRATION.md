# 山谷景观 R2 主体接入

2026-11-06。状态：implemented-local / verified-main（下述范围）。已按授权接回当前本地 main；未提交、推送、开 PR、合并远端或部署。保留现有营地生活和 UI 工作区修改。范围见 [scope](scopes/valley-horizon-r2-integration.md)。

## 当前实现

- 四组相连雪山保留获认可的主峰、侧峰、鞍部与岩雪比例，网格减至 17,128 个三角形；沿用主体天空、PMREM 和昼夜。正常角色镜头保留，检视另提供望山视角。
- 外景从原地表 128 个边缘顶点连续接出，延伸两岸坡体和溪流河湾；远裁面调整至 3,200，雾距为 300–1,050。模拟地图、导航范围、经营资源额度不变。
- 道路直接着色在地表材质上，取消独立路面网格。溪谷碎面凸起收浅；网格和 surface 使用同一规则，原近场通路高度保持一致。
- 2,389 棵外景树使用五种低面数轮廓：块冠阔叶、狭冠阔叶、开展松冠、云杉、冷杉。低处阔叶比例约 66%，高处约 2%；高度、冠幅和颜色有固定种子变化。
- `tree-slot-17-17`、`tree-slot-17-18` 两个造景树位分别移至 (51,27)、(57,32)，实际树冠避开整个规划桥位通廊；580 个身份、151 棵经营树及各自角色保持不变。
- PR24 仍独立处理。本地主体尚无该桥的施工和通行玩法，因此西岸显示“东岸桥位／待修建”，不移植沙盒展示桥作为可走桥。

## 所有者与入口

静态规格在 `content/environment.ts`、`landscape-routes.ts/json`、`tree-slot-corrections.ts`；地表延伸在 `world/horizon.js`，近场仍由 `world/surface.ts` 管理。`terrain-sampler.js` 仅索引已建网格，供装饰落地，不提供另一份玩法地表。

`scene/horizon.ts` 组合外坡、林带、岸石与道路标识；`mountain-geometry.js`、`outer-forest.js`、`trail-material.js`、`landscape-props.js` 各管对应表现。主溪流与两段延伸共用 `creek.ts` 的材质、倒影和昼夜 uniforms；倒影渲染时隐藏延伸水面，避免对当前渲染目标自采样。几何、材质、纹理和实例均交给原 Resources 释放，没有新增循环、状态源或存档写入者。主体无运行时沙盒依赖。

## 实际验证

- `npm run build`、`npm run verify:assets` 通过；15 个登记 GLB、地表及 159 张已准入 UI PNG 检查通过。构建仍有既有大脚本体积提示。
- `environment`、`scene-props`、`forest-intake`、`camp-exit` 四组 17 项测试，以及新增 `valley-horizon` 4 项通过。覆盖封闭网格、实际地表接缝、水道无遮挡、桥位树冠、海拔分布、预算及资源只释放一次。
- 沙盒 `verify` 十项、`verify:r2` 六项与构建通过；近场 16,908 个三角形重心的表面查询最大误差约 0.000005，819 个原通路采样不变。
- Windows Chromium / AMD Radeon WebGL 2：主体查看望山、上游、下游、越岭、岩壁及夜景；1280×720、390×844、844×390 已检视并保存同帧 PNG/JSON。九份捕获均为零着色器错误、无上下文丢失。控制台另有一次 ANGLE 浮点精度优化警告，未形成着色器编译失败。
- 通过原有路线按钮从营地走至宅后望台，最终路径节点归零；刷新后恢复原坐标与已访问地点。实际卸载重入后画面恢复。浏览器诊断自动读取在重入阶段遇到超时，因此浏览器 GPU 归零未单独取得回执；自动资源专项已验证释放次数与 owner 清零，两者分开记录。

主体外坡/林带/标识为 93,624 个三角形，四组山体为 17,128，两段水面为 1,140，合计 111,892 个三角形、43 个绘制对象，满足本轮 120,000 / 50 预算。该口径不含原游戏树木、天空与倒影/阴影重复通道；整场景 renderer 数值不能直接与之比较。未以后台浏览器的帧时样本宣称稳定帧率，真实手机 GPU、双指操作及发热仍待实机检查。

截图位于任务批准的临时证据目录，不进项目树。主线开发捕获默认写系统临时目录 `home-of-woods-scene-evidence`，可用 `HOW_SCENE_EVIDENCE_DIR` 指定批准目录。
