# 溪流东岸：通路、林区与收运

本轮在 HOW-BASELINE-1.0 上验证第二块林地，属于 M2-08 的局部实现。范围见 [scope](scopes/east-bank-expansion.md)。工作分支的实现、验证、合并和发布分别记录。

## 当前可玩内容

西岸营地保留原位置，溪流东岸从既有固定景观树位中开放 28 棵经营树，并登记 3 个宿主的枝杈、蘑菇和碎柴，共 9 处采集来源。全世界仍有 580 个固定树位和 1 棵受保护巨木；不新建营地，不重抽旧坐标或个体。

仓库的基础图纸中加入跨溪木桥。沿溪谷到桥头，查看材料后明确选择“修建木桥”；投入 4 根已收运原木和 3 份枝杈，施工完成后桥面与通路同时开放。材料和图纸资格由原升级事务校验，一次扣除；取消不扣料。数值仍是原型参数。

桥面铺板、角色落脚、点击移动、键盘移动、掉落木料和选中提示共用高程。栏边拦住侧向走出；桥头衔接原地表。桥梁留作搬运通道，不在桥上摆家具。东岸的进入、采集和搬运依赖这条实际通路，未建桥不能直接跨河。

## 哪片林地欠料，就拦哪片

| 行为 | 对采伐限制的影响 |
| --- | --- |
| 在东岸伐倒树 | 给产物记东岸来源，拦东岸下一次采伐；西岸仍可伐木 |
| 在西岸伐倒树 | 只拦西岸；东岸独立判断 |
| 拿起原木、搬过桥或临时放下 | 保留来源和批次，不换地区、不清账 |
| 送回部分原木 | 仅减少已入库的数量，剩余原木继续限制来源林区 |
| 该批原木全部存入营地 | 解除该来源林区的限制 |
| 取出仓库普通木材、摆在院子里 | 不产生采伐欠料 |
| 离区、补生、重新进入或读档 | 不删除尚未交付的原木及其来源 |

`harvest` 随库存栈保存 batchId / regionId / treeId。搬运保留标签，入库的份额移除标签，成为普通库存。没有第二份数量账本；年度采伐额度仍沿用全世界同一账本，本轮只把欠料限制按来源林区隔开。制作、交易、修桥和其他消耗不接受未交付采伐木料，避免途中消耗绕过收运。

## 区域与表现

| 参数/所有者 | 本轮实现 |
| --- | --- |
| 林区与通路 | content/regions 中登记边界和连接；navigation 先走区域通路，再做局部 A* |

| 共享资源 | 原 Models / Resources 缓存；区块只移除表现，不释放别处借用的几何/材质 |

女神初始覆盖以营地为中心。覆盖查询与通路状态分开，修好桥不会给东岸增加赐福。登记的祭坛覆盖等级是后续升级接线口；当前没有新增正式祈愿收益或可执行的祭坛范围升级。

存档继续保存同一 GameState：桥在 workshop，东岸树与物产在 forestry / gathering，探索在 visited，未交付来源在 inventory。紧邻上一版的固定山谷仅补齐新增东岸记录和基础桥梁图纸，保留原营地进度；不建立通用历史迁移系统。

## 当前边界与回退

本轮共用固定的自适应地形和低成本远山，营地道具也继续常驻。没有实现无限地形、地形网格/纹理流送、船筏驾驶、多日疏浚、分营地或远方玩家。普通林区可沿区域注册、稳定树位、通路及物产配置继续增加；扩大总地表时仍要维护统一高程与接缝。

本轮不代表完整 M2 完成，也不包含合并或部署。回退整个功能 PR 可恢复上一版代码；扩区后的存档布局不能由旧版读取，回退试玩可使用新会话。
