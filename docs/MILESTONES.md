## 所有阶段共同的交付规则

- 明确实现提交、固定 seed、视口、相机、时间与状态；记录实际运行的检查及未测项。
- 视觉/建模交付先按 [ASSET_PIPELINE](ASSET_PIPELINE.md) 核验授权、修整，再按可见功能包接入；来源、许可、加工与入口写入 [ASSET_REGISTER](ASSET_REGISTER.md)。
- 当前阶段截图、操作演示、交互/碰撞与资源释放必须来自本游戏；素材网站、Midjourney 设计稿和 Marble 2 外部演示不能代替实机。
- 布局灰盒用于迭代；M0 视觉完成前替换成经审查的资源或明确批准的定制模型，不能永久以粗占位物充当最终风格。
- 不通过降低验收、提高性能预算或复用旧回执报告完成。资源授权、功能接线和美术一致性在同一功能包验证。

## M0：可行走的山谷

目标：家在山上，经营区向下坡、溪谷、对面小山展开；玩家能行走并欣赏完整山谷。

内容：主体大山、溪谷、对面小山与外围山景；家园帐篷/破屋；一名基础角色；针叶/阔叶两种经营树轮廓、一类巨木；树位布局；基本 HUD、选择、移动、旋转缩放镜头。

| ID | 验收条件 |
| --- | --- |
| M0-01 | 家园与谷地下方关系清楚，宅后可爬路线及未开放高山边界明确，家园留观景视线。 |
| M0-02 | 家园—下坡—溪谷主路线连续，人物贴地、不穿建筑、不悬空；对面山体建立形体。 |
| M0-03 | 镜头可旋转、缩放、复位，角色和目标可辨；相机拖动与 HUD 不触发场景动作。 |
| M0-04 | 固定树位可复现；经营树、巨木与远景林身份分开，不因重建随机变样。 |
| M0-05 | 修整后的树、人物、房屋、环境形成统一低多边形塑料玩具比例与材质，资产准入记录齐全。 |
| M0-06 | 单一循环、输入监听和共享资源生命周期成立；重复进入、暂停恢复、卸载后无持续增长或重复运行。 |
| M0-07 | 提供家园望谷、谷底回望、角色近景、目标选择与桌面/手机 HUD 截图，以及行走/转镜头演示和设备性能采样。 |

不要求：采伐经济、完整四季、祈愿交易、制作或可进入的完整屋内场景。

本轮原 R4 的检查包含五个生产 GLB/地表来源与 hash、19 项行为/几何/资源测试、类型检查、生产构建，以及固定 seed 的当前游戏截图、漫步/镜头和采伐录像、五轮实际卸载重入记录。最终雪山已修为亮白雪面与浅蓝冰沟；采伐采用斜侧站位，树体倒伏后躺地保留 1.8 模拟秒。这里只登记已取得的冻结版本证据；主体回接结果以最终 VERIFICATION 和 evidence/integration 为准，不预填通过。

## M1：从帐篷到修好木屋

目标：正常操作完成一次修屋闭环，所有进度可保存。

新增：基础斧头、可用工作台、枝杈/基础物产、简易加工、即时规则审批、体量点数、采伐、原位补生、分阶段修缮、神谕规则说明、基础游戏时间与存档。M0 资产继续复用，补齐动作、树桩、幼树和修缮阶段。

| ID | 验收条件 |
| --- | --- |
| M1-01 | 新存档依次采集、加工、轻修缮、申请/执行采伐、加工结构木、修好木屋；基础工具和材料无循环锁。 |
| M1-02 | 允许的开局 seed 满足关键材料可达、可采和额度足够；不依赖稀有掉落、祈愿惊喜或付费工具。 |
| M1-03 | 巨木、幼树、受限个体和额度不足无法采伐；界面显示原因、预计产物和所需点数。 |
| M1-04 | 重复点击、取消、失败、动画结束与存读档均不重复扣点、发木材或创建补生任务。 |
| M1-05 | 新幼树在原树位出现，有新个体身份；旧许可失效，重载不提前成熟，不能与人工占用叠生。 |
| M1-06 | 修缮阶段可见，材料账目正确；移动、取消、升级和回收不复制结构木或把轻料变结构料。 |
| M1-07 | 存档整体往返时间、库存、位置、树位、个体、额度、再生与建筑；读档失败保留原数据。 |
| M1-08 | 场景内采集、挥斧、倒树、加工和修缮有清楚反馈；新资产完成碰撞、命中、性能与释放检查。 |

不要求：行商、祈愿奖励、全套季节美术、宠物与手作小游戏。

当前有限林业已覆盖 M1-03、M1-04、M1-05 和 M1-08 的部分规则与表现；人工占用、加工、修缮场景及建筑存档仍须随 M1 补齐，现有世界存读档已追加实现。原位补生/成材由确定性测试验证，短采伐录像未覆盖完整等待周期。当前 GameState 已能整体持久化及校验恢复；M1-07 中尚未出现的建筑状态仍须随修屋功能补齐。

物品身份、普通/精品/未分级堆叠、库存切片 JSON 兼容读写与旧会话原木转移已实现，见 [物品数据演进](ITEM_DATA_EVOLUTION.md)及[本轮证据](../evidence/item-stack-compatibility/README.md)。这为 M1-07 提供库存边界，现有世界的统一保存、恢复与跨切片校验已追加实现，见 [世界存档](WORLD_SAVE.md)与[本轮证据](../evidence/world-save/README.md)。

## M2：持续林场经营

2026-10-30 R5d 追加：溪流、封闭外围、崖面与道路、白昼炭堆/夜间营火、库存原木架、祭坛供品/神谕表现已回接当前实现分支。固定观察位仅用于检视；正常镜头保留。该视觉昼夜及祭坛状态不等于正式日历、燃料或供奉交易，见 [本轮记录](../evidence/scene-r5/README.md)。

目标：经历一个游戏年后森林继续可经营，并可扩建家园。

新增：四季日历与表现、跨年账目、逐树资源再生、分区生态换代、人工种植、神谕多档祈愿、一个行商、基础交换/季节需求、一次材料等级升级、木屋扩建、少量造景物；接通对面小山经营路线。

| ID | 验收条件 |
| --- | --- |
| M2-01 | 正常游玩与休息推进均可跨季跨年；按时间顺序结算事件，不重复刷新额度、商货或资源。 |
| M2-02 | 采伐—原位补生—成长—资源再生持续运行，分区权重有效，布局稳定；人工种植取消对应待补生。 |
| M2-03 | 每树有限资源池独立恢复；跨多个季度不无限囤积；幼树无成熟树即领收益。 |
| M2-04 | 多档祈愿有明确成本/回报与惊喜；年度特批上限有效；无合格树位时有明确延期或替代结果。 |
| M2-05 | 行商按日历来访，基础交换和季节需求可用；重开商店不补货，不提供可无限转成结构木的路径。 |
| M2-06 | 能完成一次材料等级升级和木屋扩建；移动造景物无损，采伐额度耗尽后仍可采集、小制作和布置。 |
| M2-07 | 完整验证跨季—供奉—特批—采伐—加工—扩建—跨年—存读档；测试正常重复命令与中断边界。 |
| M2-08 | 多林区往返时表现资源正确加载释放，离区数据保留；季节资产、角色与行商可读性和性能达到已定预算。 |

后续：全部 6–8 树种、完整工坊链、自由塑形、宠物培养、树病治疗与复杂事件、完整角色定制、雕刻组装小游戏、女神场景和深山搬树。不把预留扩展视为已实现。
