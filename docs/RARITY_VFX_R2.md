# 稀有物品特效 R2：表面流光与星芒

2026-11-02。用户否决 PR #9 初版仅靠亮度/色相差异的表现；数据层和五级 UI 不变。本文件替代初版“静态弱自发光已经满足视觉要求”的结论。当前代码在 PR #9 分支继续提交，不合并、不部署。

## 视觉含义

“柔和”指边缘渐隐、变化舒缓，不是把特效压到看不清。参考 Blizzard 的 [Midnight Season 1 Galaxy 武器幻象](https://worldofwarcraft.blizzard.com/en-us/news/24266321) 所呈现的亮核、彩色柔边和星芒层次；没有复制其素材，也没有照搬大范围喷射效果。

史诗紫、传说暖金。新效果由三部分共同形成：沿完整表面缓慢流过的宽柔光带、光带中的明亮细核、贴附实际模型三角面的四角星芒。星芒有亮心和彩色渐隐外缘，在不同表面交错闪现。它不是头顶悬浮徽标；顶面、侧面都有覆盖。普通、优秀、稀有仍使用原材质，不新增特效。

物体的原色、粗糙度、基础光照保持；亮带经过处暂时更亮，未经过区域仍保留木材明暗。没有提高全场曝光、添加光柱/地面光圈，亦没有全屏或选择性后处理 bloom。局部柔光外溢来自星芒自身的解析渐隐，不将它称作屏幕空间泛光。

## 接入与边界

`content/item-vfx.ts` 单独管理视觉参数，不改变稀有度 ID、生成权重、词条或成本。`scene/item-surface.ts` 负责材质变体，`scene/item-glints.ts` 负责确定性的实际表面采样及单批点精灵。

每个可见的发光网格增加一批 Points 绘制。当前五木墩案例为 4 个表面材质变体、2 个共享星芒材质、2 个星芒批次；不是旧版的零额外 draw call。每件史诗/传说分别采样 9/12 个点，背面按法线渐隐，远距 145–185 世界单位渐隐。点大小分别保留 12/15 像素的最小屏幕尺寸，也有 52/62 像素上限，避免近景填满画面。

所有点跟随实际网格变换，开启深度测试，不写深度、不投影、不参与射线命中。收回/卸载时解除表现对象，材质/几何由现有 Resources 所有者统一释放；重复摆放不无限新增缓存。

动画消费既有 app 主循环的未乘沙漏倍速的 `dt`，不创建 RAF、timer 或存档字段。暂停/后台停止随主循环生效，`dt=0` 不移动特效；减少动态效果固定到可读相位而非熄灭特效。当前适配普通静态 Mesh；SkinnedMesh/InstancedMesh 显式跳过，不能把本轮结果直接宣布为人物装备骨骼适配已完成。

- 没有改动 domain 数据读写、稀有度生成、库存 UI 或存档格式。真实手机 GPU、长期满营地珍品负载及其他未来模型尚未验收。
