# 固定观察点相机

## 目标与范围

在默认室外构图不变的前提下，允许玩家升高和缩远，限制空中横移，并给远景准备提供可预测的有界相机路径。改动涉及 content 相机参数、scene 导航 rig / 近景所有权、app 移动门禁与唯一 RAF、UI 镜头工具和操作说明。

可见验收包括：桌面拖动/滚轮和手机拖动/双指/升降按钮可用；高处锚点不跟人物或输入平移；WASD/摇杆/点击路线等待回收完成再移动；家具近景退出时半径不跳变；动作、屋内和检视归还后仍由正确镜头接管；暂停准备只改表现、不推进世界。

本次不改默认 POV、角色比例、树形拓扑、中距离树简化、材质、持久 ID、碰撞、资源与存档格式。不增加独立 RAF。森林可见集合由组合层消费实际与预测相机，远景准备复用前一份 PR 的工作队列。

## 实现与验证

已实现 navigation / overlook / returning 与借用状态，readiness 扩张门禁，按实际相机投影生成的短前瞻，家具半径过渡和桌面/触控输入。新增 `tests/anchored-overlook.test.ts` 覆盖默认构图、锚点、输入洪泛、帧率无关速度、readiness、完整回收、借用归还、半径过渡、预测不改变状态和移动端真实投影。`tests/presentation-loop.test.ts` 覆盖暂停后的单 RAF 准备、硬停止及恢复不补时。

后续 [Rainier 镜头](../RAINIER_RENDERING.md#高位广角与克制的焦外) 将缩远半径扩展为 110–220，并按画幅放宽投影；仍由本控制器限制径向速度、保持锚点和执行回收。实际导航与预测共用山谷外侧地形净空，家具归还相机时连续接回投影与半径。

远景规划保留当前完整树界、实体阴影与水面反射，加入 0.1/0.25/0.5 秒预测集合；每批任务每步最多处理 8 棵树，过期意图、倒树和世界替换均重新验证。相机推进前检查准备状态，最终画面缺项当帧补交；补交与规划明确在协作预算外统计。`tests/forest-view-plan.test.ts` 覆盖冠缘、镜像、阴影、前瞻、反向输入、分步准备和世界替换。

本文件记录实现与定向离线验证。仓库 `Frame Budget Review` 在桌面和手机尺寸的 Chromium WebGL 中运行真实主场景，验证暂停收敛、升高缩远和路线回收，截图与诊断作为临时 CI artifact 保存；具体结果见 PR 的当前运行记录。构建、数学测试和软件 GPU 都不代表实体设备帧率。

## 回退

可整体回退本次相机控制器、输入门禁和工具按钮，恢复旧导航镜头；没有世界或存档迁移。独立的 presentation RAF 修正可保留供表现队列使用。
