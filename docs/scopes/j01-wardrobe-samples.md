# 林工 J01 衣柜样件

## 目标

为当前林工 J01 做第一批可以实际换穿和旋转查看的三维衣物。先试林场劳动、镇上便服、林地巡游三种搭配，分别采用晚维多利亚至 1920 年代启发的工衫、背心与束带野外外套。保留 J01 的头身比例、脸、手与步态，衣饰沿用森林之家的圆润造型和低面数表面。林地巡游允许铜制蕨叶、绳结等少量幻想细节。

以现有八槽组织样件。上衣、裤装、鞋靴、帽子各有独立轮廓，背负、手部、腰部与颈部各做可交换的配件。每个款式支持独立染色。升级沿用同一版型，以加固片、包边或五金体现变化，饰件使用衣服自身的挂位。套装按钮用于一次穿好，单槽仍可混搭。

## 范围和入口

独立入口为 [本地试衣间](http://127.0.0.1:5296/)，重开方式见 [沙盒说明](../../sandbox/j01-wardrobe/README.md)。源模型取已认可的本地 J01，输出和截图放入忽略目录，供本机预览。沙盒有自己的场景、资源和状态，采用项目共享 Timber UI，以及 `shared-shadow-rules-v1` 的 `interior` 受光和 `character` 足底接触配置。预览可查看正面、侧面、背面和斜侧，并检视步行、屈膝与抬臂时的袖口、裤腿、鞋靴和挂件。桌面及触屏视口使用同一模型和控制。

PR #17 的衣装结构、PR #21 的八槽约定、PR #44 的 J01 接入供后续接线参考。PR #19 提供低阶词条的配色与特效词汇。本批交付沙盒款式、染色、可见升级和挂件。正式装备、库存、稀有度和存档接线另行授权，审阅确认后可按槽与原骨架导入。沙盒和私有基模供本地审阅。

## 首轮交付和校验

| 搭配 | 上身与腿部 | 鞋靴与帽子 | 代表挂件 |
| --- | --- | --- | --- |
| 林场工装 | 立领工衫、直筒工裤 | 圆头短工靴、八片短檐帽 | 工坊铜章、帆布包小水壶 |
| 镇上便服 | 粗呢双尖背心、及膝裤与长袜 | 窄楦系带鞋、偏冠贝雷 | 怀表链、斜挎书袋卷图筒 |
| 林地巡游 | 束腰野外外套、收口裤 | 长筒绑带靴、短檐软毡帽 | 铜蕨胸针、行囊侧挂水壶 |

八个部位各三款，每款有原色及五个可选色。精制和挂件用可独立显示的蒙皮层，弯曲时与各自对应的衣物一起变形。Blender 在空场重导确认版型、精制、挂件与适配层共 117 个对象，以及原有 50 根骨骼和每点一至四个权重。可编辑文件保留 J01 原步行动作。

1360 × 880 桌面和 390 × 844 触屏视口均完成试穿。验证逐款切换颜色、精制、挂件及可取下的配件，并检查背带、腰带、领巾对三种上衣的 27 种组合。每套检视正、斜、侧、背和 J01 原步行、抬臂、屈膝，检查试衣姿势回到站立后的恢复。触屏使用实际点击完成混搭。两种视口的行内对齐误差实测为 0 CSS px，最小控件尺寸为 44 CSS px。

首轮屈膝特写记录了巡游帽檐内侧的一小段亮缝。图片、GLB 读回和浏览器报告位于沙盒的 `.cache`，有相同镜头的干净图和辅助线图。TypeScript、沙盒构建及 `npm run verify:ui` 通过。

## 帽子贴合修订

以原 J01 头部网格的额头和两侧截面确定帽口，用可见轮廓估算被头发遮住的后脑。八片帽、贝雷帽、巡林帽分别做较贴头的版型，发型与帽子共用头骨挂载，各款都有对应的帽下收发。修订入口沿用试衣间，验收沿用相同视角，对照帽围、帽高、帽檐、耳侧发梢和低头接缝。其余样衣沿用首轮结果。

按 GLB 外轮廓测量，八片帽的宽、高由 257 × 113 mm 收为 227 × 81 mm，贝雷帽由 280 × 93 mm 收为 237 × 82 mm，巡林帽含檐由 342 × 121 mm 收为 265 × 98 mm。三套帽下发型都使用原发型的发际、鬓角和发尾。卸帽恢复完整原发型。每个帽型的帽身、精制、挂件和发型固定在同一 `head` 骨，衣柜导出共 120 个蒙皮对象，其他七槽的 108 个网格逐属性核对一致。

同机位对照和低头、步行特写保存在本地 `.cache/hat-fit`。巡林帽最初的亮缝和发束穿出在这组复核图中已消失。后脑位于原网格的开放区域，尺寸采用由头部横宽和骨骼中心推得的承托弧。悬空或穿出的检查以有原网格可采样的部位和浏览器画面为依据。
