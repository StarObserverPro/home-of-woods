# 林工 J01 步态复核

以本地游戏正在使用的 J01 模型为基准。先对照静止和步行中的轮廓、骨盆、髋膝踝、鞋底及肩肘，核验绑定、骨长和蒙皮。按待机、启停、步行、跑步及转向复核动作采样、重心和落脚。另取采集和双手持斧姿势，检查步态调整与既有动作的交接。

先在独立的 `.cache/j01-gait-review/` 复核和制作候选。保留原模型与本机游戏，使用同一角色、机位和地面标记记录原版和候选的骨骼叠图及动作对照。实机验证在同一游戏源码的隔离副本运行，使用固定种子及独立浏览器存档。桌面和触屏视口均复核。交付可编辑 Blender 动作和本地运行候选。审看通过后可将动画采样和所需配置接回游戏，再删除临时验证副本。

本轮范围集中在主角动作及显示接触。角色身份、服装款式、来访 NPC、道具事务、公共资源清单及发布均在本轮范围之外。模型来源沿用既有的[本地 J01 素材](np120-character-intake.md)。

## 复核结果

绑定姿势的左右大腿长约 0.209 m，小腿约 0.193 m。三视图检查髋、膝、踝、肩和肘位于相应轮廓内。蒙皮每点最多四个权重。候选 GLB 保留原始节点、皮肤绑定、网格、材质、贴图和旧动画，另加新的站立、步行和跑步动画。近景还能看到原鞋底边缘的细缝。

原步行每周期的靴底位移为约 1.12 个游戏单位，游戏根节点在同一周期前进约 3.77 个游戏单位。原跑步从 KayKit 转译，鞋底相位也随另一套骨架变化。候选用 J01 的鞋底和腿长解出落地、推蹬、摆腿与重心，按实际位移采样。步行保留双脚同时落地的阶段，跑步增加独立的腾空阶段和上身摆动。收步时先由较低的脚支撑，再把另一脚收回。转向时角色显示朝向随输入快速过渡。室外取样使用游戏地表查询。

候选步行速度为 2.70 游戏单位每秒，跑步为 4.32。原有两档分别为 5.20 和 8.32。试跑速度配合同一周期 1.46 与 2.09 游戏单位的完整步幅，减轻短腿角色为追上旧速度而提高步频的幅度。原回退角色仍按既有速度运行。

## 场景落脚复核

本轮核查营地及西岸坡道、跨溪木桥及东岸、木屋和帐篷出入、睡醒出帐，以及从主游戏进入的三片林地。用相同角色测量鞋底相对当前可见地面的高度、停步时骨盆的变化，以及静止后是否仍有漂移。另核对各场景使用的实际模型、动作驱动和切换时的起始姿势。复用既有入口和本地分析脚本，记录在 `.cache/j01-scene-review/`。动作未通过的场景先单独修正，再接回实际入口。

### 结果与接入

| 场景 | 原因与复核结果 |
| --- | --- |
| 营地、西岸坡道和东岸林 | 按实际蒙皮取靴底和脚尖，补正混合姿势中短暂低于地面的鞋底。下坡跑停从最后一个跑步姿势过渡，避免骨盆突然切到另一个高度。 |
| 跨溪木桥 | 原桥头把整块木板当作大面插值，导致局部可见桥面比行走高度高约 0.30 游戏单位。细分高差处的桥板，桥面和行走共用同一坡面。240 个桥板取样点的最大高度差为 0.0048 游戏单位。实机从西桥头走停，再过桥抵达东岸。 |
| 木屋、帐篷和清晨出帐 | 实际木板与地布分别与室内的 0、0.288 高度基准对齐。清晨旧动作从地布下方开始，最深约 0.30 游戏单位。现在从门外安全通道迈一步，复测最大重叠约 0.002。门内外的首次站姿重新按当前空间取样。 |
| 雾杉高林、斑荫横岭和白桦溪甸 | 搭载与营地一致的 J01、衣着和走跑轨道，换图和回营地重置步相。三处林地从营地实机入口完成走、跑、松键及换图回程，停稳后骨盆漂移为零。备用角色按本图三角地面调节靴底，原来停住后仍有一只脚陷进坡面的现象已修正。 |

桌面键盘实机核对了木屋、跨溪木桥、东岸和三片林地，帐篷使用手机尺寸的触控模拟。坡面回归还按 30／60／120 Hz 重放不同的松键时刻。末轮极端坡面的备用角色走动样本有小于 0.009 游戏单位的瞬态靴底重叠，停稳后保持贴地。角色、门口和林地相关测试与生产构建通过。
