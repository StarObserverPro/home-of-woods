# HOW-WILDLIFE-1 · 第一阶段范围与交付

日期：2026-11-01（美东）。工作分支：`feat/wildlife-phase1`，承接 `docs/wildlife-plan`；主线代码前置为 PR #6 的 `d3e4566`。本批未开 PR、合并或部署。

## 目标与已实施范围

完成松鼠、野兔的同风格素材准入及最小出场闭环。常态两只、哺乳动物全局最多三只、同种最多一只；白天按固定窗口选择营地或下坡锚点，待机、受限移动、停看、警觉和退避共用既有主循环、地表与碰撞。进出场也占额度，不按分区重复生成。

content 登记定义和候选数值，world 提供固定候选，domain 管理预算/身份/行为，scene 播放模型，app 驱动唯一状态。采用同一 Gobkit CC0 包中的两个模型，各 16 骨骼，统一落地点、尺度和粗糙度，只开放 idle/walk。来源、许可、原件、修整脚本和 manifest 已入库。

动物不占点选或 E 键，稳定 encounter ID 与类型化 targetRef 为后续互动保留接线；当前能力列表为空。临时姿态保存在唯一 GameState，磁盘格式不变；已存时间重建同一窗口和到期时间。稀有冷却、宠物或互动结果尚未实现，不能借本批规则绕过未来持久化迁移。

## 验证与边界

当前实现、测试、桌面/手机视口截图、五轮卸载重入和素材加载失败降级结果，统一见 [本批证据](../../evidence/wildlife-phase1/README.md)。浏览器以实际游戏入口和现有检视 UI 取证。双动物检视根据竖屏宽高比缩放，并检查动物中心投影在画面内；不是仅检查 visible 标志。

手机是 390×844 视口/触控仿真，未做物理手机 GPU 验收；软件渲染帧时间不代表用户设备性能。参数仍为首轮候选，美术方向可据实机继续微调。不将本批等同于完整 M1/M2 或全部动物完成。

## 不涉及

不增加鹿、山羊、狐狸、鸟群、音效、蝴蝶、青蛙；不改岩壁、树皮、草苔及其他制作支线；不实现爬树、喂食、招手、宠物、经济奖励或制作加速。

## 工程收尾与回退

一次性素材获取和代码运输脚本已完成，运输脚本已移除；后续检查仅具仓库只读权限，不自动推送或在普通构建下载素材。保留离线修整脚本供重建，显式下载模式有来源 hash 校验。历史 PR #6 证据仍校验其不可变源码，当前动物实现由本批新证据负责。

回退本功能批次即可恢复旧场景；无新增持久动物格式需要反向迁移。共享资源仍由现有 owner 释放，动物离场只归还自身骨架、动画及材质副本。
