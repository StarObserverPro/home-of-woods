# HOW-WILDLIFE-1 · 第一阶段范围

日期：2026-11-01。工作分支：`feat/wildlife-phase1`，承接 `docs/wildlife-plan`，主线代码基点为 PR #6 的 `d3e4566`。

## 目标

完成松鼠、野兔的同风格选型与最小出场闭环。常态两只、全局哺乳动物最多三只；日间有效锚点、受限移动、停看和靠近退避共用既有主循环、地表与时间。保留稳定 encounter 身份及只读能力查询，首阶段能力列表为空，不抢点选或 E 键。

## 涉及层

content 登记定义和候选数值；world 提供有效锚点；domain 管理预算、时段与行为；scene 加载和表现；app 组合并驱动。资产沿用现有许可登记、manifest 和缓存生命周期。必要的状态变化须符合唯一 GameState/存档语义；不为装饰动物增加独立存储或定时器。

## 可见验收

两种动物同框，颜色、比例和材质一致；在正常游戏中出现，移动不穿树、房屋或水岸；暂停不动、重入不加倍；夜间退场；可观察稳定 ID、预算和回收统计。补充固定视角截图、规则测试、构建和资源释放证据。缺乏实机证据的项保持未验收。

## 不涉及

不增加鹿、山羊、狐狸、鸟群、音效、蝴蝶或青蛙；不改岩壁/树皮/草苔；不实现松鼠爬树、喂食、招手、宠物、经济奖励或制作加速；不修改其他制作支线；不合并或部署。

## 验证准备

当前执行环境不能直接 clone 或联网安装依赖，使用连接的 GitHub 在本分支进行读取、提交和 CI 验证。临时诊断产物只打包公开仓库文件、公开 npm 依赖和候选免费资产，不包含 .git、凭据或环境变量；不进入运行时或素材批准清单。诊断准备不代表动物已实现。最终实现记录与结果另行更新。
