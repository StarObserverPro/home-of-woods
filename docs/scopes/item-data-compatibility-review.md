# 物品扩展与存档兼容设计范围

日期：2026-10-30。回应物产细分、普通/精品品质和深加工的后续需求；范围是提前设计数据兼容方式。当前工作区为 `codex/gathering-sources`，保留已有采集、仓库和角色修改。核对远端 main 为 `d22ac56`，PR #3 尚未合并。

## 目标与涉及层

只读检查本项目 content、inventory、warehouse、processing 和持久化约定，以及水晶花园当前 main 的物品、库存事务、迁移、加载保护和相关回归案例。形成 [物品数据演进方案](../ITEM_DATA_EVOLUTION.md)，明确物品身份、品质堆叠、旧泛品、未知目录项、版本边界、加工结果与单一余额所有者。

## 可见验收

方案能解释新增菌种/木种为何通常不迁移存档，普通和精品如何分别计数，旧“蘑菇”“原木”如何保留，配方调整如何避免重算历史产物，以及缺失目录和损坏结构各自如何处理。列出首个持久存档前的实现顺序和必要回归场景，来源链接绑定所查源码版本。

## 不涉及内容

本轮只新增设计文档和现有架构文档入口，不改运行时代码、存档键、资产或物品配比，不实现通用迁移框架、品质系统或加工执行。水晶花园保持只读，不移植其业务与治理框架。不开 PR、不合并、不部署。文档检查不替代后续实现和存档往返验证。
