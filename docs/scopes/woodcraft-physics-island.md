# 营地 Woodcraft 物理岛

以 PR #7 的 `7bfc749` 为前置，另开叠加 PR；不合并、不部署。目标是把同一库存中的原木/枝杈移入营地局部刚体区域，预备木堆时留一根供玩家亲手投放。首版容量 32 件，批量最多占 31 个位置；超过容量的材料继续留在原库存。无赠送木料，不修改浏览器外的存档。

涉及 content/domain/app/physics/scene/ui 和唯一世界存档。Rapier 仅负责局部接触、重力、旋转和休眠；业务事务、所有权及存档仍归现有 GameState/app。材料从 stacks 转入 woodcraft.pieces 后不能同时用于制作；收回恢复原批次。独立家具实例不改，物理缓存不另存所有权。

验收：库存守恒、留一根、点击投放、自然堆叠、移除支撑后再次下落、暂停/倍速、旧档迁移、刷新恢复、远离及销毁释放，桌面与手机视口实际操作。未测不标为通过。

不做全地图物理、玩家刚体、伐倒树碰撞、柔体、关节、工具加工、家具堆叠或工作台表面投放。本次营地木料区作为后续工作台复用的第一个可玩切片，所有结果/限制记录于 WOODCRAFT.md。
