- UI 仓库支持打开/关闭、物品分类、真实数量、来源与加工方向，适配桌面/手机。原木从 ForestryState.wood 派生，新增物产从唯一 inventory 派生；不复制余额。面板消费统一暂停/输入模式。
- content/world 建立树种物产配置、稳定宿主/树位与地表挂点；蘑菇以树下成圈布置，同一圈共享来源池，枝杈位于对应树下。先用有界数量的可达宿主验证；树脂等预留树干挂点，不先增添未准入模型。

- 注册加工输入、输出、工作条件和待定参数，提供实际被仓库消费的查询/校验服务；不在本轮执行制作或擅定配比、耗时。

## 可见验收与边界

仓库显示实得物品、分类与加工信息；开关/键盘/手机可操作，不穿透场景。松/栎蘑菇圈与树下枝束位置可辨，同圈多个命中映射同一来源，采空与卸载不补货。宿主倒伏、换代和旧命令有测试；加工登记拒绝悬空引用和小料越级变结构木。复核资源共享与卸载、采集/采伐回归，保存本轮固定 seed 的桌面和手机证据。
