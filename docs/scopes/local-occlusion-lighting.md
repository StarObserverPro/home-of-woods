# 营地局部遮蔽与林间亮度衰减

日期：2026-11-12。基于 PR32 `5290393b3eb270d0287ebbc0f718429b289467aa` 的独立后续分支；不合并、不部署，不修改家具取得、空间资格或存档。状态：规划与实施中，未声称视觉验收通过。

## 目标

近景优先房屋内外、帐篷内外和高密度互动区；先处理相对稳定且不需逐帧追踪的位置：墙根、帐篷下沿、柜/床/桌下。可移动家具的遮蔽跟随真实实例，移动/收回后不留暗印。远景保留低成本、低频的环境遮蔽预设。森林本期仅提供按树冠覆盖度变化的整体林间亮度衰减；森林近景精细遮蔽延期。

## 分层与边界

- content：强度、过渡距离、森林覆盖参数及预算。
- world/纯计算：平滑遮蔽核、覆盖场采样与测试；不创建新的空间或玩法事实。
- scene：共用资源、材质链式补丁、世界坐标遮蔽、近远平滑混合；沿用唯一主循环。
- 正式营地与 PR32 室内展台各用薄接线层，不修改模型、寻路、经济和保存。
- 环境遮蔽主要调制间接照明，不把火焰/灯的自发光或直射光统一涂黑。保留最小亮度；近景细节不制造黑边。
- 剖墙/隐藏屋顶只改变审看显示，不让固定房间遮蔽消失；真正移走家具才移除其遮蔽。
- 不增加全屏高采样 SSAO/GTAO、逐帧重烘焙、额外 RAF、实时 GI 或新依赖框架。

## 可见验收

同一几何、材质、相机和时刻的开/关对照：室内墙根/桌下、房屋及帐篷外侧、营地互动区、森林/林间空地、远景。桌面与手机视口检查；昼夜均保持可读。家具移动/收回/恢复、剖墙和近远切换不残影、不突跳；实际着色器编译和浏览器错误为零。记录纹理尺寸、附加 draw call/采样策略与真实测得指标；不将软件 WebGL 速度当作真机性能。
