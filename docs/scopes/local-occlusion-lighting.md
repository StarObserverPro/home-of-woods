# 营地局部遮蔽与林间亮度衰减

任务日期：2026-11-12。PR33 为 PR32 `5290393b3eb270d0287ebbc0f718429b289467aa` 的独立后续分支；不合并、不部署，不修改取得、空间资格或存档。原计划先于实施提交，以下记录实施与验证边界。

## 目标与范围

近景优先房屋内外、帐篷内外和高密度互动区，先处理墙根、帐篷下沿、柜/床/桌下等相对稳定的位置。可移动家具的遮蔽跟随真实实例，移动/收回后不留暗印。远景保留低成本、低频的环境遮蔽预设。森林本期仅提供按树冠覆盖度变化的整体林间亮度衰减；森林近景精细遮蔽延期。

正式营地已接入建筑、工作台/家具、储木架与森林；新木屋内部接在 PR32 独立展台。后者仍不是正式世界的可进入内装，不以本 PR 扩展其玩法。

## 已实现

- `src/content/occlusion.ts` 集中强度、近远过渡、覆盖图与内存上限。
- `src/world/occlusion.ts` 的柔和区域、近远权重、树冠场为纯计算；`local-occlusion-field.ts` 将局部暗区写入两通道三维缓存：R 保存稳定宽暗部，G 保存近景接触暗部。重叠取较强值，不重复相乘成黑块。
- `src/scene/lighting/ambient-occlusion.ts` 链接原木纹/天气/稀有度材质补丁。局部范围外跳过采样；范围内一次三线性采样替代首版逐像素遍历所有家具。仅衰减间接光，不改直射光或自发光。近景细节在18至64世界单位内平滑退场，宽暗部保留；夜间适当减弱。
- 实例布局变化才重建局部缓存；同一状态不重复重建。尺寸变化时释放旧GPU纹理并替换共享uniform，避免可移动家具扩大范围后沿用不可改变尺寸的GPU存储。全部纹理由原Resources所有者管理。
- 建筑读取原GLB命名的地板、墙体、帆布和基础后变换到世界空间，不纳入绳索或隐藏升级件；遵循抬高地板与真实门口。帐篷前面不人为封一条暗带。
- 正式家具使用原参数化尺寸及注册实例。展台使用SHELL_PLAN、itemPose和原支撑关系；桌子收回/移动时，其暗区及桌上独立小物的暗区同步更新。剖墙/隐藏屋顶不删除物理房间遮蔽。
- 森林覆盖图为192²核心区与128²远景区，包含树冠覆盖、地表高度和冠高；经营树砍倒/补生/生长阶段变化才更新。林下变暗，空地、冠顶和区域边界平滑过渡，不整片树林统一涂黑。

## 实测成本与限制

在已核验的营地布局中，局部纹理128×48×128、RG8；两张树冠纹理合计212,992字节；三者原始纹理数据合计1,785,856字节（约1.70 MiB）。完整木屋展台局部纹理82×30×71，约0.33 MiB。实际显存还包括驱动分配开销，不将原始字节数等同整个场景显存。

不开新全屏pass、不加几何、不增加RAF或draw call，但新增片元采样和离散CPU烘焙仍有成本。大营地的网格受上限约束，极小接触细节比独立室内展台更粗；这不是几何精确AO、实时GI或太阳软阴影重做。动态角色/门板不作为逐帧重烘焙遮蔽体；原动态直射阴影仍保留。
