# M0 可行走山谷：实施与回接范围

对应 HOW-BASELINE-1.0、基线 PR #2 合并提交 d22ac56。用户最初授权合并 #2 并完成第一阶段；2026-10-30 又明确“允许回接主线，准备实现 PR”。冻结 R4 的白名单代码和选定资产现已复制到主体的 `feat/m0-walkable-valley` 工作分支。这里的“回接”是进入主体实现分支，当前实现分支待PR审查、未合并 main、未部署。

## 目标与涉及层

交付 M0 可行走山谷，并包含用户追加的实际砍树倒树、透明合并 HUD、林下/草甸色块、PNW 启发的雪山、河水与白昼天光。保留主体大山、家园台地、宅后可走路、下坡与溪谷的空间关系；对岸与高山仍是明确边界外的景观。

实现 TypeScript + Three.js + React HUD：content 提供布局/参数，world 提供唯一地表和固定树位，domain 提供移动/林业规则，scene 提供模型/环境/动作和资源释放，app 提供唯一状态提交与主循环，ui 展示快照并发送意图。参考水晶花园的职责划分，不复制其业务、素材或私有记录，不采用旧 PR #1 的完成结论。

有限林业包含成材/保护/距离校验、单动作额度预留、取消与一次结算、斜侧走近、挥斧、完整树体倾倒、1.8 模拟秒躺地停留、树桩和同树位新一代幼树。App 保留同一 GameState 引用供会话重入，不能替代持久存档。

## 入口与可见验收

主体根目录执行 `npm.cmd ci`、`npm.cmd run dev -- --port 5173`，访问 <http://127.0.0.1:5173/>。普通流程在场景内移动、选择和执行砍伐；`?inspect=1` 仅提供诊断、最近成熟树选择、重入及录像，不自动砍树。完整参数见 [PARAMETERS](../../PARAMETERS.md)，R4 具体范围见 [SCOPE-R4](../SCOPE-R4.md)。

验收覆盖固定 seed 的家园望谷、谷底回望、角色近景、目标选择、桌面与 390×844/844×390 手机视口；实际行走/镜头和采伐演示；HUD/摇杆输入隔离；唯一循环、暂停恢复、模型碰撞、资源与多次卸载收敛。雪山采用最终亮白雪面/浅蓝冰沟版本，倒树采用斜侧站位与落地停留版本，不沿用首检缺陷或旧 R3 图作结论。

冻结原版为 `HOW-M0-SANDBOX-20261030-r4`，运行时指纹 `00cd10ce44cbc567ad24b854c52867ec1ba27c5215e92d01401e65a4ba50dd42`，记录位于 [source-freeze.json](../../evidence/r4/source-freeze.json)。原 R4 已有工程、实机和五轮资源循环证据；主体接入清单见 [intake.json](../../evidence/integration/intake.json)，最终回接检查另存 evidence/integration，统一结论见 [VERIFICATION](../../VERIFICATION.md)。本 scope 不预填尚未取得的分支检查通过。
