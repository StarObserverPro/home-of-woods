# 林工与路过营地的村民

本轮以已认可的本地 J01 制版、两档工衫、工裤、贝雷帽和接地步态回接玩家，覆盖营地和木屋。原压缩包的四套整模成为低频村民。原版 J01 只调整发色和少量肤色。

验收包括人物走路、穿脱、室内外切换、村民进出和素材缺失运行。来访消费现有世界时钟、导航和地表，阿榆保留自己的交谈与来访流程。提供本地素材导入工具，人物包和生成数据在忽略目录中，正式构建使用已登记资源。开 PR 交给主线审阅。

## 可见行为

- 林工复用玩家 ID、移动、装备与持物动作。站立和走路用 J01 的原骨架。工作姿势用原动作带动，必要时重新对手掌和道具挂点。
- 小帆布背包和亚麻领巾随 J01 骨架运动。粗布手套按手部蒙皮权重覆盖，保留原有指节和持物姿势。三件配饰按仓库的实际穿戴显示，装备帆布背包时优先显示大背包。
- 每三游戏日轮换一位村民，从 15:15 起沿现有导航路径进营地，停留 12 世界秒后原路离开。其位置由世界时间和路线求出，重载可按同一时间还原。村民为营地环境人物，阿榆和行商继续提供现有互动。
- J01_02 原包的基础色来自 `NP120_J01_02_B_1.png`，皮肤、头发和上衣原本都是灰调。导出时按 UV 遮罩为脸、颈部、前臂和手补上暖肤色，保留原有明暗、眼睛、发色和衣料。

## 本地素材入口

`.cache/j01-player/j01.glb` 为已认可的林工运行文件。四位村民用 [Blender 导出脚本](../../tools/np120/prepare_villagers.py) 从用户提供的 NP120 ZIP 生成。可以在后台 Blender 执行 `blender --background --python tools/np120/prepare_villagers.py -- <NP120.zip>`。输出和原包都留在本地。

开发服务器同源回环地址读取五个固定角色文件。有林工文件时自动启用，缺少文件时使用已登记的 KayKit。有村民文件时匹配该日来访外观。回退时可移走该本地文件或者还原该 PR 的代码。正式构建使用原资产清单。

## 本轮验证

基线为 `a091ae3`。正式构建、公开资产核验和 37 项角色、换装、来访、坐姿、扫帚与加载相关检查通过。桌面游戏完成林工步行、两档工衫和帽子切换、仓库脱穿上衣、进屋、室内步行及出门。使用相同世界种子与日期快照检视了第 1、4、7、10 日各一位村民。390 × 844 触屏视口通过加载和近景检查。临时隐藏本地素材后，游戏正常用 KayKit 代替玩家造型。

冲突处理后，在含 Rainier 和高位镜头的组合版重新运行公开资产核验、生产构建及 44 项定向检查。以种子 `104729` 在桌面 1160 × 760 和触屏 390 × 844 实际穿脱背包、手套和领巾，复核了近景和桌面行走。拦截本地 J01 请求后仍正常回退到 KayKit。

读回四个村民 GLB，各含 50 骨。在绑定原点采样站姿和一个循环的 37 帧，最低鞋底与参考面间距低于 0.15 毫米。实机路点再由既有的地表查询定高。J01_02 调色后通过 Blender 同机位对照检查，其 50 根骨骼和 150 条动画通道的采样值均与原导出一致。四个村民合计约 5.19 MB，林工约 3.90 MB，均为本地资源。照片和运行报告留在忽略目录。
