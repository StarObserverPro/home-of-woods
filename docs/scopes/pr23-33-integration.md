## 重叠处的裁决

- 真实树枝接点以 PR28 的 composed woodSegments 为基础；不退回仅按树干高度射线估算的旧枝束。PR23 的树皮与命中改进使用同一真实变换，保留主线碎柴和端面木纹。
- 木色、树皮、天气和间接遮蔽必须沿同一材质钩子链组合，避免重复加深或把叶片、布、金属染成木色。颜色依赖稳定物件身份，不增加树种或物种库存字段。
- 东岸沿用当前 R2 地形与桥位两处景观树移位；桥廊实际需要的额外造景剔除保留身份，且不得留下隐形碰撞或点击对象。林相覆盖场应与最终可见树木相符。
- `harvest` 保留来源林区和欠料批次，未收运木料不能直接被制作消费；`woodCondition` 不参与料批身份，湿度变化不能把已开工的同一批木料判成另一批。入库、加工和保存沿用单次事务。
- 当前主线的坐姿、持物、天气、存档和唯一循环优先保留；旧 PR 的整段代码不能覆盖这些后续更新。
- 按区块压缩采集实例时，矩阵和稳定木色一起写入目标索引；近树初次加载与反复重载借用同一几何、UV、树皮权重和地表高程。桥廊可见树名册也作为林冠遮蔽输入，隐藏景观不继续投暗。
- 修桥后的长凳坐下与扫帚走近共用区域通行权限，点击移动、拖放和实际行走共用建成桥面。树冠与建筑淡化材质在首次使用前接入完整树皮/天气/遮蔽链。
