# 固定本地入口

2026-11-06。目标：为森林之家建立不依赖聊天进程的本地入口，独占约定端口而不干预其他项目。涉及 Vite 启动配置、Windows 看护脚本、快捷入口和本机登录任务。验收：5286 返回本项目页面与资源，任务运行，重复启动不新开端口。范围不包括远端部署、局域网开放、操作系统休眠时服务、旧源存档迁移。用户已授权建立持续可用且不抢占其他项目的入口。

实施结果：已注册当前用户的 Windows 登录任务 `HomeOfWoods-Local-5286`，限制为非管理员权限、重复启动忽略、无运行时长限制、允许电池运行。页面 HTTP 200 且标题和 src/main.tsx 入口匹配；重复启动仍一个监听者。定向结束本项目 Vite 子进程后，看护自动拉起新 PID，随后再次 HTTP 200（冷启动期间一次 10 秒请求超时，准备完成后恢复）。其他项目 5283、5294 的监听 PID 保持不变。未实际重启 Windows；登录触发器已注册。只绑定 127.0.0.1。

## 入口断开后的修正

首轮返回后任务退出，LastTaskResult 为 `0xC000013A`，端口无人监听；先前仅验证游戏子进程重启不足以保证看护进程被终止后的恢复。当前改用 `wscript.exe //B` 无窗口包装启动器，并加入每分钟重复触发，正常任务采用 IgnoreNew，脚本互斥锁防止多实例。尝试 S4U 非交互账户运行被 Windows 权限拒绝，因此实际仍为当前用户登录期间的 Limited / Interactive 任务；不宣称未登录可用。

已修正说明：整项进程链退出后的恢复可能需要等待下次分钟触发及启动时间，不能保证零中断。原端口与回环监听范围保持不变。

修正验证：定向核对本项目绝对命令行后结束 Vite 和 PowerShell 看护进程，未调用手动启动；07:59 的分钟触发器自动启动新进程，HTTP 200 且项目标题匹配。随后在浏览器重新打开同一 5286 地址成功。Windows 重启／退出聊天后的长时运行仍应以实际运行结果为准。
