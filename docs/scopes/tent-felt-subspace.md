# 帐篷：曲面毡布与独立子空间

## 目标与范围

在主营地现有 A 字帐篷上完成七项可见改进：轻微垂曲的轮廓、纤维与柔和掠射反光、赭红/靛蓝/暖白重复几何纹带、门前挂点、可点击进入的独立帐内空间、固定支撑下的微风布动与两态门帘，以及门后可见的睡袋、小鼓、颂钵。

入口、占地、地表与营地身份沿用当前帐篷；场景、材质和子空间由表现层负责，进出与移动由 domain/app 负责，玩家界面复用 Timber UI。原帆布、绷绳、撑杆、风铃升级与夜间休息继续使用现有业务记录。

## 可见验收

- 布面边缘与中部有有节制的垂曲；脊、撑杆和地面固定点保持稳定。
- 近景可见纤维层次与侧光软反射，中远景保留清楚的大色块纹带。
- 打开的帐门后能辨认三件陈设；放下门帘后遮住入口。
- 桌面和手机可从门口进入、在帐内走动和观察，再从同一门前返回。进出使用同一画布与淡切，室内不绘制室外世界。
- 新素材有确定种子、材料/线框/法线诊断和实际三角形/纹理统计；进出不重复创建资源。

## 实现边界

本轮为轻量表现与可进入的室内。陈设不发放物品，挂点为后续装饰保留稳定身份；不引入布料碰撞求解、逐根毛发、乐器玩法或装饰交易。纹样为项目原创几何构成，借鉴纺织品的色块与连续纹带组织，不复刻特定部族图案。

帐内可站立范围限定在中部：横向半宽 1.45 m，前后墙各留 0.80 m 净空。依据当前角色约 2.53 m 的实际身高、头帽侧向约 0.66–0.68 m 的外伸和转身轮廓最远约 0.714 m 的外伸，按真实蒙皮顶点检查弧形布面的内表面，并计入布层厚度和风动余量。低矮陈设仍使用独立的 0.48 m 脚下碰撞半径，中部通道和家具前后绕行保持可达。

## 验证与交付状态

当前代码已接入主营地。帐篷几何/门洞/风/材质、实际角色净空、帐内导航、镜头拟合、昼夜照明、材质进出生命周期和现有营地/木屋入口共 24 项定向检查通过。浏览器画面与真实输入由 `Tent Appearance and Portal` 工作流检查。

`7c88538` 的实际远近景、clay 与风相位截图已人工检查：下沿弧度可见，纹带远处保留大色块，近处有细纤维受光，门后睡袋、鼓、颂钵可辨认，原左前角岩石穿插消除。此前桌面及手机的完整进出流程通过，但人工审查同时发现帐内取景裁切、夜景偏暗及退出后的 WebGL 采样器冲突；旧轮自动通过不作为完整图形验收。当前修复采用 HUD 留白下的真实网格拟合、昼夜织物散射填光和稳定室内材质；新轮会将图形警告及现有 WebGL context 的 `getError()` 一并作为失败条件，结果待补。

本地浏览器进程受到 socket 权限限制，不能在此环境完成 WebGL 截图；浏览器检查转到仓库既有 GitHub Actions 环境执行。截图、录屏及日志仅放 CI artifact，源码树保留代码、正式素材和轻量记录。门帘状态和室内局部姿态不跨刷新保存，刷新回门前，门帘默认掀起；晚间休息继续使用已有清晨落点。

操作：从「路线 → 营地 → 帐篷 → 查看」选择帐篷，再点「走到帐篷门前」；或直接点场景里的门洞。帐内可走动、转镜头、开合门帘，点「出帐篷」走回门口。外部低面数陈设与内部模型共用尺寸配置，实际视角变化有近景视差。

回退本 PR 即恢复原帐篷 GLB 与木屋单一室内入口；没有存档 schema 迁移。本批不包含合并和部署。
