- `HOW-CHARACTER-1` 四档预算、部位分配、图集/色板、服装与眼睛/骨架约定，以及同 PR 更新规则。

- 共用呼吸、上半身微摆、稀疏理衣/手触头侧与面部能力适配，接入当前主角、行商、邻居、local villagers 及室内共用主角；无新 RAF、日历或存档状态。

### 本地验证

- `npm run build` 通过，包含主程序与 cabin 类型检查。
- `npm run verify:assets` 通过：原 15 个 GLB、地表和 159 张 UI 图的校验未受影响。
- `npm run verify:characters` 通过其声明的日常检查范围；报告如实保留 11 pending，不能据退出码宣布素材完成。
- 30 项针对性测试通过：character-quality、character-audit、character-liveliness、character-contact、character-wardrobe、neighbour-presentation。覆盖实际 KayKit 骨架/脚底、重复采样不累积、不同帧率、持斧/扫帚/碗接触和资源释放。
- Blender 4.3.2 对公开回退副本实际试减：7,574 → 7,448 三角形；23 骨及其名称/顺序不变，UV0/NORMAL/JOINTS/WEIGHTS 与 1024×1280 嵌入图集保留，审计无解析问题。保护区使它未达到 6,000 目标，工具正确保留待人工复核；副本只在 `.cache/`，没有覆盖正式资产。
