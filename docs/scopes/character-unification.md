# 现有人物的自然待机

本轮只修改游戏已经使用的人物表现：林工 J01 / 公共回退主角、现有行商、邻居及原本的本地村民适配器。没有实际模型文件的六个候选已经从本 PR 撤掉；人物规格、准入清单和减面工具也全部撤掉。

## 已接入的表现

角色静止时有轻微呼吸、上半身慢摆、头部小转向，空闲且双手没有任务时偶尔理衣或抬手碰头侧。每个人按已有 ID 错开节奏。J01 继续使用原眨眼图集 / morph；公共回退不添加假眼睛。

同一主循环内先恢复上次叠加，再采样原动作及持物约束，最后添加待机表现。根、骨盆和脚不被待机层移动。行走、砍树、采集、读书、扫地、持碗和搬运优先；交谈时不插入手部小动作。暂停冻结，减少动态效果关闭这些附加变化。帐篷、木屋共用主角路径。

代码入口为 `src/scene/character-liveliness.ts`，参数仍在 `src/content/character-motion.ts`；没有新日历、库存、存档写入者或 RAF。现有 GLB 和人物身份没有替换。

## 实际验证

本地类型检查、生产构建、原有资产校验及 18 项针对性角色测试通过。测试使用真实公开 KayKit 骨架检查脚底、斧柄、扫帚和碗的接触以及暂停、重复采样与资源释放。用户本地 J01 / 原四位文件不在当前 checkout，其适配用与当前导出结构一致的 fixture 检查，不将它当作私有模型已完成看图。

[人物浏览器检查](../../tools/verification/character-browser.mjs) 固定 seed 104729、14 时，在同一主游戏内先以 550×380 记录相隔 0.5 秒的自然待机，再用已有衣装检视在桌面 1100×760 和手机 390×844 采样实际角色的静止、手势及减少动态效果画面，另外检查暂停、行走和横砍止点。采样只覆盖主角显示位姿，游戏、场景和 NPC 时钟不变；截图文件名带 `sampled`，不将其当作自然播放录像。
