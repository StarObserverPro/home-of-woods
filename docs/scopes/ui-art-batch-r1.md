# UI 美术批次 R1

日期：2026-11-05。以下保留独立美术设计阶段的范围与结果；后续正式采用见[菜单接入 R1](menu-clarity-art-r1.md)。

- 目标：依据当前物品、HUD 和营地生活候选，制作统一玩具质感的图标与界面皮肤候选，按母版批量生成并切割加工。
- 涉及层：独立 `sandbox/ui-art-r1/` 的母版、透明 PNG、尺寸变体、索引、加工脚本和独立预览。现有 `src/`、`public/` 和其他沙盒只读。
- 可见验收：六组母版；图标可逐个查看，透明边缘、缩小识别度和深浅背景可检查；界面组件有可伸缩演示，桌面和手机预览能用。
- 批次：材料与补给 16、食物与炊具 16、衣装与旅行 16、营地与家具 16、功能图标 16、界面组件 9。实际数量以生成质量和切割检查后的清单为准。
- 已有与候选：以 `src/content/` 为已有目录依据，`sandbox/camp-life/src/content/` 和正式需求文档为候选依据；图标存在不表示玩法已实现。
- 不涉及：正式游戏 UI 接入、改动布局或玩法、替换生产 SVG、存档、PR、合并或部署。
- 用户看过基础母版后认可风格，并要求按等级和已规划细分扩量；追加八类树形对应的木材外观及木料规格 16、既有衣装设计库中的版型 16、四类常用物件的五级外观候选 20。树形名称不等于生产物品目录已拆出八种木材，五级外观不修改当前等级规则。
- 入口：`sandbox/ui-art-r1/index.html`，独立静态服务，不依赖游戏状态或运行时。
- 去留：先独立审阅；经用户明确批准后再按选定清单接入主体。淘汰母版与调试证据可清理，保留采用素材、来源和可重建脚本。
- 来源：内置 imagegen 生成，自拟提示词，不含第三方参考图片；不标为 CC0。保留提示词和加工记录，正式公开入库前按项目流程登记输出权利。

## 实际结果

独立设计阶段九批共 141 件：132 个图标、9 个组件；当时已清理透明底噪、校正切线并输出原生裁片与四档图标。独立预览的桌面、390 × 844 视口和交互检查见[历史验证](../history/ui-art-r1-2026-11-05/VERIFICATION.md)。当时的沙盒清单、预览和 `sandbox/ui-art-r1-delivery.zip` 属于本地设计交付，未在该阶段接入正式游戏；本合批不附完整沙盒、zip 或批次审阅图。后续按用户授权选用 79 个语义图标的 64／128 px 版本及 1 张空白物品格，共 159 PNG；正式采用范围、来源和游戏内验证分别见[资产登记](../ASSET_REGISTER.md#how-ui-art-r12026-11-05用户批准采用)及[菜单接入 R1](menu-clarity-art-r1.md)，不把 141 件候选都记为生产素材。
