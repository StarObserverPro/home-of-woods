日期：2026-10-30。用户授权完整保存/恢复库存、额度、树木、资源池与动作，并要求损坏档保护及按类别/类型扩展的物品注册。保留当前采集、角色及独立 scene-r5 沙盒的已有修改；不将沙盒并入主体。远端 main 仍为 d22ac56，PR #3 未合并。

## 目标与涉及层

content 明确物品类别、类型和通用用途引用；domain 提供完整世界存档格式、结构/跨切片校验、确定性恢复与库存兼容；app 作为唯一存档写入者接 IndexedDB、自动/手动保存、事务备份、竞争写入检测和保护状态；UI 提供保存状态、导出与安全恢复入口，仓库展示类型及通用去处。

## 可见验收

刷新后位置、游戏时间、库存品质、额度、树木代次、资源池与进行中动作一致；进行中采集/采伐与已结算倒树跨刷新只发一次资源。损坏、未来结构、跨引用矛盾和存储失败不覆盖原数据；保护状态能导出原始存档，明确操作后才从有效备份恢复。新增同类型物品无需修改存档格式，同类通用用途由类型定义驱动。

## 边界

不增加具体菌种、木种、加工执行、交易执行、年度经济、离线收益或在线数据库。参考公开 MMORPG 的模板/持有记录与类型划分原则，按单人本地游戏裁剪。不改历史冻结证据，不开 PR、不合并、不部署。
