# 首批采集物实施范围

日期：2026-10-30。依据：用户指定的《森林之家采集物注册与接入指导》v1.0。实施基底：PR #3 的 `4ed0c0f`；核对时 main 仍为 `d22ac56`，PR #3 未合并。本轮为获准的功能实现，工作分支 `codex/gathering-sources`，不属于将独立实验回接主线。

## 目标、涉及层与入口

同时接入落枝堆和蘑菇簇：content 的物品/来源注册、world 的固定布点、domain 的最小库存/采集候选/恢复契约、app 的唯一动作协调与同步提交、scene 的模型/命中/释放、ui 的通用目标和明确采集意图。入口沿用 `npm run dev`；诊断入口 `?inspect=1`。

人物支线仍在独立 KayKit 实验中。本轮仅提供 `gather.pickup` / `gather.pluck`、世界坐标锚点、动作 ID、阶段与进度，不改人物网格、骨骼或姿态。

## 可见验收

- 两类来源同一注册和命中流程，可选中、合法走近、明确采集；来源变化、数量和收获提示成立。
- 稳定来源身份；相邻同模型不串 ID；取消、旧版本、重复命令和重入不重复发物品或补货。
- 采伐和采集互斥；继续使用统一地表、游戏时间和资源 owner；保持既有行走与采伐。
- 周期补足和采空等待分别用受控输入验证，正式参数缺失时保持耗尽；来源、库存、恢复与动作记录可序列化。
- 素材来源和许可、修整、加载、命中与释放记录齐全；取得当前桌面与手机视口操作/截图和卸载证据。

## 不涉及与交付

不实现正式日历/恢复调度、配方、修屋、交易、祈愿、树体附属资源、完整持久存档或人物动画。不重复登记 `ForestryState.wood`，不改原木权威余额。不采购、不自行开 PR、合并或发布。

验证与文件清单保存在 `evidence/gathering/`；文档分别记录实现、验证和启用状态。已有未跟踪的 `kaykit-character-lab.md` 属于其他工作，保持原样。
