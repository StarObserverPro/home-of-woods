# 第一段可玩森林

状态：首个可玩原型已完成，基于 `main` 的文档初始化版本。实现、实机画面与验收结果见 [验证记录](../VERIFICATION.md)。

## 目标与范围

全屏三维森林场景，Q 版角色自由行走；斧头采木、补种树苗、开垦播种浇水收获、预览并搭建小屋和围栏。提供键鼠与触摸输入、暂停、单个本地存档与损坏存档保护。

涉及 content/world/domain/scene/ui/app 六层。游戏世界是主界面，HUD 只显示当前资源、目标、工具和操作提示。固定种子、共享资源、唯一 RAF、唯一存档写入者从首版建立。

## 可见验收

- 进入即看到可操作的玩具森林；角色、树苗、成熟树、农作物和小屋可区分。
- 一次劳动改变世界与背包；重复结算、无效建造和取消不产生额外资源或扣款。
- 桌面和手机都可走动、换工具和执行动作；UI 不向场景穿透点击。
- 刷新恢复进度；暂停、后台停止游戏时间；销毁后不残留循环和输入监听。
- 提供固定 seed、视口与状态的实机截图，以及实际运行的行为和生命周期检查。

## 入口与去留

正式实现入口为 `src/main.tsx`，通过 `npm run dev` 启动。本次是正式第一版代码，不另建平行沙盒或重复引擎。通过 PR 合入前同步核心文档。
