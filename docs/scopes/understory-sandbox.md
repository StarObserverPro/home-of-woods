# 林下形态独立沙盒
目标：柔和玩具森林的阴凉林下、林缘空地、溪谷缓坡三组可旋转实景。
涉及：独立程序网格、实例绘制、地表与观察 UI。入口 sandbox/understory/index.html。
验收：三组形态可辨、蕨群有疏密、地表一致、显示实际绘制统计；桌面与窄屏检查。
预算：单组目标低于 100k 三角形、40 次主通道调用；DPR <= 1.5，无后处理、纹理、透明叶片和实时反射。预算不是手机帧率承诺。
隔离：不导入 src 或 public 核心资产，不改存档，不加入生产构建。仅只读使用已安装 Three/Vite 库。
去留：先用户检视；继续独立改进，收到明确指令才考虑回接。未开 PR、未发布。

第二轮：用户明确继续隔离精修，禁止回接。新增验收重点为树荫蕨群、无蕨空地、单体灌木、棱角石、自然朽木与落叶；预算不提高。实际检查见沙盒 README 第二轮记录。

第三轮：树冠投影遮罩阈值控制蕨类资格，连续场控制片区密度和高度；草改为合并带状叶实例批次。维持原预算与独立范围。
