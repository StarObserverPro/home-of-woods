# 树杈与树皮（2026-11-05）

范围：scene 表现与命中审计；复用 world 树位/seed、domain 物产库存及地面行动点。验收为渐细连生枝杈、贴合宿主、可见位置可点击、采空隐藏；静态/动作树皮一致，冠叶不染木纹，远景无纹理。

风险：合批 UV、动作几何和透明冠 shader；不改变 renderer/RAF、地形、资源产量及存档。Resources 拥有共享贴图/模板，临时动作只借用贴图。固定相机 before/after、桌面/手机视口、draw calls/triangles/textures 与实际采集验证；不以软件渲染帧率声称手机性能。

预算：一组 128×128 中性色/高度法线图；所有经营树共享，远景不绑定贴图。枝杈共用五段低边数叉枝，单实例批次；状态改变才上传矩阵，不逐帧重绘纹理。回退本提交即可恢复旧表现。
