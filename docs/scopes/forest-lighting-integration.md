# 林地模块共用照度与阴影

日期：2026-11-19。基于 PR39 的森林扩展模块。用户明确要求未来正式林区适配共用规则；路径仍为 `/sandbox/forest-expedition/`，不将它归为废弃沙盒。

## 目标与范围

将三片林地的表现接到共用户外阴影、范围照度和角色接触暗部。保留每个场景自己的 renderer、资源所有者与宿主循环；不回接主营地状态、不改采集或库存事务、不改历史沙盒。

- 用真实树冠几何的世界包围体提供稳定的物理覆盖，观察相机淡化树冠不再削弱遮光。
- 树干、根部、道具和角色保留实时实影；冠层采用共用柔和透射场，避免完整树冠几何硬投影重复压暗。
- 林间环境照度沿真实冠层覆盖渐变；地面、角色与物件消费同一场。
- 去掉固定硬边脚下圆片，用动画后的双脚落点驱动共用接触暗部。
- 在本模块的已有状态变化与绘制中调用共用组件，不增加 RAF、全屏处理或跨模块渲染器。

## 可见验收与验证边界

三图各检查空地到林下、树干根部、巨木高冠、转动镜头、角色行走/抬脚、近中远镜头。光照场不能跟着镜头移动，接触暗部不能在抬脚后悬留或越过地形；换图清理旧纹理与材质包装，角色仍受新图照度影响。

源码/几何测试覆盖真实冠层输入、相机淡化与物理覆盖分离、公共规则接入与资源清理。构建和数值通过仅说明代码与输入合法；本环境如无法提供 WebGL，明确保留实际 GPU 编译、画面与手机性能待验收。

## 实际实现

`scene/lighting/forest-expedition-lighting.ts` 是本地图的薄适配层。它按当前地表与真实冠层 AABB 构造共用户外光场、按同一冠层的水平投影面积生成间接光覆盖，并把实际动画脚底传给共用接触模块。冠层两种照明共用一套空间事实；树种与地形不被重新推测。

`expedition-vegetation.ts` 为每株冠层保存稳定的世界中心与半尺寸。相机遮挡只改可见材质中的透明度；不再向深度材质传播。活动林区将冠层实影关闭，由共用三维透射场承担宽柔影；树干、根部、角色及地面物品仍投射实影。原先每走5单位跳移太阳投影的代码删除，由共用光空间像素对齐负责覆盖移动。三图采用相同基础太阳/半球光，林下差异来自空间覆盖，取消给高林整图降亮度的替代方式。

原纯色硬边角色圆片已移除。`foot-contact-anchors.ts` 在启动动画前读取真实角色皮肤的脚/趾权重顶点，保存每只脚相对其骨骼的脚底偏移；动画后用骨矩阵更新世界落点和脚掌方向。脚底尺寸随真实皮肤和整体缩放变化，缺少脚部皮肤时不生成猜测圆影。接触暗部通过共用间接光规则衰减，无额外几何或绘制。

地图卸载依次恢复 AO 与冠影材质包装，再释放地图资源。角色是场景级资源，切图后重新接入新光场；地面物件新建后也接上相同规则。主游戏 renderer、玩法、存档与所有历史沙盒保持各自职责。
