# 物品身份 品质堆叠与库存兼容实现

日期：2026-10-30。用户授权按物品演进方案先实现身份、品质堆叠和兼容机制，具体菌种、木种以后添加。沿用当前工作分支，保留采集、仓库、角色与场景已有修改。

## 目标与涉及层

content 登记稳定物品身份、材料/形态和品质；domain 实现按物品与品质计数、整笔候选、库存切片 JSON 读写、旧泛品适配及未知目录隔离；app 在会话进入时整笔适配旧库存和原木余额；采集、采伐、HUD 与仓库共用唯一库存。原木额度仍由林业账本持有。

## 可见验收

普通、精品、未分级分别显示和计数；未知物品/品质有可见占位且无法消费。新增、重排目录不改变旧库存；旧会话原木转移一次，不重复发放。真实 JSON 往返保留未知目录记录，未来结构、损坏数据和双余额冲突进入保护，安全规范化可再次读写。采集和采伐的守恒、取消、过期候选及幂等回归通过，检查桌面与手机仓库。

## 不涉及内容

不增加具体菌种、木种、稀有掉落或经济配比，不开放加工执行。库存切片读写为完整世界存档提供边界，本轮不单独自动保存库存；完整世界持久化仍属 M1，库存、额度和资源池以后整体恢复。不修改第三方项目，不开 PR、不合并、不部署。

## 实现结果

身份、品质堆叠、库存 JSON 兼容与旧会话转移已实现，采集、采伐和仓库已接通。52 项测试、类型检查与生产构建通过；四种视口、实机采集与重入、独立检查页的未知目录恢复及冻结生产包均已检查。源码归档、实际输出和边界见 [本轮证据](../../evidence/item-stack-compatibility/README.md)。
