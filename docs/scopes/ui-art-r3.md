# 林地物产、HUD 图标与营地近景美术

## 界面与可见入口

- 天气菜单的晴阴雨雪、主营地镜头控制、走近动作、品牌叶片和林地镜头使用新 PNG。林地产物窗、随身、寄存、地面和营地仓库能辨认菌类、林果、坚果、树脂、种源、果干、罐子的空满和糖浆。
- 复用既有 R1 的 GameIcon 入口和 Retina 规格。独立试样位于 `.cache/ui-art-r3/`。四张 ImageGen 母版分别为天气及走近、果菌、收液器具及菌簇、叶片及镜头。采用 R1 图作风格参考，要求三分之四视角、圆润玩具轮廓、纯透明间隔、每格一个主体、大色块及无文字。目标母版 1024²，上限 2048×2048。检查 28 px 效果后，用 [裁切工具](../../tools/prepare-ui-art-r3.py) 注册 31 个 64/128 px PNG 对。
- 从主营地走近交互物、打开天气和镜头，或沿林地小径进入后打开「物产」「行囊」查看。路线地图、摇杆、进度、状态和 Timber UI 仍由实时数据与组件绘制。

## 场景近景

- 正常来访期间可见换装后的带篷车。CC0 车厢保留四个独立轮轴及货舱轮廓，原有驴加牵具与车连接。先在 `.cache/scene-art-r1/` 验证导出，再接进游戏资产加载。
- 桥新增倒角板缝、两道栏杆和斜撑，走道仍消费同一桥面。近远路牌共用倒角木板、固定木钉和实际路名。储木架增加檐梁、立柱斜撑和分板屋面，晾菌架增加落地石脚、挂杆及带瓶罐的下层架。三件陈设随建成架出现，规格与许可见 [资产登记](../ASSET_REGISTER.md#营地近景资产)。
- 工作台与木作一起做。木屋当前可见的是围护和壁灯，床、桌、凳、壁架与地毯在独立展台，木屋内装作为后续范围。林下及岩石沿用当前几何。

## 行商角色

本轮回接车厢和牵具。两套人物候选经用户审看后撤回，游戏沿用现有行商模型。后续以 J01 作为同机位参照，按游戏视角看约五头身的整体比例、脸型和五官、发型和服装轮廓。头身比以实际观感为准。

## 检查

本地构建、运行时资产校验和 44 项定向检查通过。额外运行的历史树位对比仍缺已归档的 `before-trees.json`。裁切后的 31 个 64 px 文件保有透明四边及不透明主体。Chromium 软件 WebGL 在 1280×800 桌面和 390×844 触屏视口渲染主营地，天气切到雨、雪后切换图标，镜头与走近图标加载正常，手机物产入口显示红果、平菇、种源和原木。无横向溢出，桌面和手机的天气状态各留一份干净图和网格图。

倒角板网格闭合，面板顶点与桥面高程一致，桥体为 3 个批次，共 3,696 三角形。使用受控读档在正式入口渲染来访驴车、满料原木架及建成的晾菌架和桥，浏览器无页面错误。场景图留在 `.cache/scene-art-r1/`，瓶罐近景及实体手机性能仍待验收。原件与成品均能由清单追溯。工作区 UI 合同发现已有的 near-pov-character 本地目录未登记，单独复制本轮所用的正式入口与样区后，5 个活跃模块的合同检查通过。
