# 纯视觉林片与高位恒速镜头

本轮承接已合并的 PR #45 场景准备预算与 PR #46 固定高位观察点。

## 视觉与空间约束

远景林是独立视觉布景。将来接近可玩林地时可通过真实树冠、山坡和道路遮挡转场，随后由独立场景重新生成树位与物产。远景林无需与未来林地逐树对应。林内通过近树与后排遮挡、较深的冠层暗部和现有空气透视制造深度，不要求深处真实树木分布。

本轮保留五类远景简树的源布局。密集部分以每组三至四棵树的少面数、不透明冠层代理表示；每块保留最高的简树，较近的、稀疏的树继续逐棵绘制。生成仅发生在装饰外景，不碰可采树的身份、碰撞、资源、地表和存档。原冠影场继续消费完整视觉源样本。提供 ?farForest=trees 进行原貌对照；运行诊断报告原始树数、实际单树数、冠层代理数、源/现用三角形。

## 镜头与边界

高位镜头保留 #46 的速度上限、锚点和回收行为，按现有预测继续预取精细远树。精细实例尚未准备完毕时，通常也保持既定转向与升降速度；当前帧可见的树沿原有紧急补交流程补足，计数仍公开。这一立即补交在 JavaScript 准备软预算之外，是否出现卡顿需靠真实设备采样，不声称硬帧时保证。

不加入全屏雾动画、模拟叶片滤镜或鸟类过场；不增加第二个 RAF，不新增中景树。若后续森林面积显著扩大，可把独立视觉林从已有树位压缩进一步替换为直接采样密度场与林片层次剔除。
