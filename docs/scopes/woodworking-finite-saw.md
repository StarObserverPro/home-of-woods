# 锯榫重做：立体选面与有限锯切

基线：main `14992fb7da4152af3b9c5a554c853dbf6a1e365c`。当前状态：规划已确认，以下功能尚待实现与验证。分支 `feat/woodworking-finite-saw`；不自动合并或部署。

## 用户目标与边界

在现有 `sandbox/woodworking/` 重做直榫练习，不另起一套正式游戏。实际立体木料是操作对象：悬停/点击仅高亮和选择工作面；三视图只作图纸参考。选面、设定位置、设定深度、明确执行是分离动作。滑块、数值与步进消除鼠标画直线的困难，保留选基准、留料侧、进刀方向和止点等有意义的选择。

深度在同一木料坐标中定义。侧向视角只是观察辅助，保留旋转和立体视角；不可把图纸当作可加工木面。浅锯留下有限锯缝；可从原锯缝继续加深；两条锯缝完全分离废料后才去料。肩与颊不强制唯一顺序。夹持采用少量预设及工序建议，不做夹具物理。

试配提供几何冲突与评分；可减材补救的微小误差可明确确认一次自动收尾。过薄、锯断或关键结构损伤不能凭评分恢复。凿子、刨子、钻具、劈削等先做工具/操作审查，不把锯切界面强套到其他工具，不冒充已实现。

## 涉及层与复用

- 复用现有独立挂载、示例宿主、主线库存事务、成品包络与图纸参考。
- domain：有限切削几何、实际表面身份、操作前置、材料体积账本、试配及补救；不把五个教程按钮作为通用几何内核。
- viewport/UI：同一几何事实的立体显示、可靠选面、锯缝与止点预览、精准输入，桌面与窄屏。
- host：加工草稿、暂停/恢复/卸载及一次性收件。可再用余段保留尺寸；细碎料仅记体积，不塞入 Woodcraft 物理岛或重复结算。
- 扩展：实现实际使用的操作接口与能力边界；记录各传统工具不同的动作/几何需求，不堆无实现 service。

## 可见验收

1. 点面不会画线或切料；拖拽转动不误选。立体高亮与实际选中面一致，允许从控件选取背面。
2. 同一条线可用滑块、数值、步进定位；图纸不是精确3D投影模板。
3. 浅锯、续锯、肩先/颊先、未脱料与脱料、错误留料侧及过深都有可解释结果。
4. 切除体积、锯屑、独立余料与在制木料守恒；重复操作不复制产物。
5. 完成一次直榫、一次可补救偏厚及一次不可补救失误；加工中刷新仍保留锯缝，收件只产生一个物品。
6. 针对性测试、类型检查、构建与桌面/手机视口实际操作。截图放临时目录或CI artifact，不能以测试通过代替看图。

## 去留与非目标

继续独立沙盒和可挂载包；不开放正式游戏入口，不改变主线物品/世界格式，不做通用CAD、任意曲面、多轴加工、木纤维断裂、完整榫眼或凿子模拟。旧原型存档不构成迁移门槛，但不能静默用新模型伪造旧加工结果。完成后更新本页实际证据及入口。
