# Rainier 营地的更新小树与有限采伐

2026-11-24。以主线的 Rainier 营地为底图，在独立完整检出开发。预览基于含营地美术的 main `cba71ef`。普通游戏入口沿营地坡林、林窗和溪谷步道穿行。

## 目标与范围

- 利用已有的成熟林分布、地形、水系、树位和物产。复用前一版评审树的程序枝干，将高冠针叶、宽冠阔叶和有限的新生小树放在同一片林地，游戏中能够从人高观察树干与树冠层次。
- 登记林窗边、透光坡肩、湿润台地和林下更新条带。按世界种子、位置与生境确定树种、尺寸和稳定身份，沿途有成簇更新和留空的间隔。株数及名册规模按场景可读性与取材节奏设定。
- 普通生活木料取自条带内部分达到小径材尺寸、且具备操作与倒伏空间的树。利用原选择、审批、额度、截取产物和原位补生。成熟林承担林相和已登记物产。现有活树、林下模型、碰撞、近远景与采集走同一套地表、光照和资源所有者。
- 本轮边界为主营地与相邻林路的活树生态、采伐资格和文档。倒木专题另行交付。

## 可见验收

从营地走入坡林，再走到溪谷，有连续高冠与较低的阔叶冠层，林边能看到成簇的小径树，也有通向水边和设施的清楚空段。核对固定 seed 的登记数、树种和位置，实际选择一株允许申请的针叶或阔叶，走近、审批、结算、保留小树位，并检查一次重读。按实机桌面及手机视口核对大小、道路和命中。

## 入口与去留

独立分支使用正式游戏首页和当前共享场景。在检出目录运行 `npm ci` 和 `npm run dev -- --port 5296 --strictPort`。通过 `/?inspect=1` 打开「运行检查」，在「场景观察位置」选择「下坡林窗 · 更新小树」或「溪谷台地 · 针阔交接」。退出检视后可选中树，沿「走近」「砍树」操作。截图放在本地缓存，验收后可按本次任务范围接回主线。

## 实际布局

默认种子登记 658 个主图单株树位。580 个旧树位原址保留，其中 3 个纳入更新带。新增 28 个高冠与次冠层树位、50 个更新小树位。六条更新带合计 53 株，22 株具备申请资格。树种依据、分带计数、胸径和高度见 [营地近景生态](../RAINIER_ECOLOGY.md#营地近景的混交林与小树更新)。

## 本地验证

- 基于 `cba71ef` 的预览通过构建、资产检查、Timber 界面合同和 71 项相关测试。测试覆盖固定种子、落位条件、站位与倒向、两岸通行、树木阴影、原采集点、原木架按料径变化、一次发放和原位补生。
- Edge WebGL 桌面视口 1440×900。查看林窗、溪谷台地和巨木保护提示，从开局位置走到林窗边一株花旗松并采伐。获得一根 3,000 × 251 mm 原木，退出重进后树桩、原木和额度一致。
- 同一游戏使用 390×844 触屏模拟视口复核林窗画面、选树和走近。六张桌面及手机视口截图和运行数据保存于本地 `.cache/review/`，包括关闭局部遮蔽的林窗对照。手机验证范围为浏览器模拟视口。
