# KayKit 角色与挥斧止点回接

日期：2026-10-30。状态：本地已回接并验证。用户已授权：先修正横砍、竖劈的受阻止点，其余外观沿用已审阅 R2，完成后接回主体。此授权不包含 PR 合并或部署。

目标：横砍在树干近侧受阻并限制入木深度，竖劈在承托木桩上表面停止；停止整套持斧姿态后回收，保持双手握柄。接入黑发、已微调眉眼的玩家与局部挥手 NPC，保留现有采伐/采集、唯一主循环及资源所有权。

涉及：content 的角色/资源规格；scene 模型载入、独立骨架、动作采样、接触约束、共享纹理与骨架释放；现有采伐表现适配；必要的营地静态角色锚点；资产许可/登记与验证。sandbox 预览、独立循环、测试按钮和整套素材库不进入主体。

可见验收：固定状态下，斧刃接触树干后不穿过整干；下劈不穿透承托桩顶；双手保持握柄，走路/采集/取消可衔接；主体可实际选择、走近、砍倒树并只结算一次；桌面/手机视口及重复卸载复测。

不涉及：改变额度/产出/树位换代规则，完整制作与修屋系统、持久存档、真实手机性能验收、NPC 交易、付费素材或发布。当前采集支线的已有修改保留，不批量覆盖其他工作。

来源白名单：已审阅沙盒的两个角色 GLB、使用到的动作、原创斧头、随包 CC0 许可及加工脚本；接触控制经独立验证后按主体架构适配。来源、修改、hash 与本次证据另登记，不把 R2 无止点录像作为本次通过结论。

结果：41 项测试、资产/类型/构建与组合版实际采伐、取消、仓库、两种手机视口、三轮卸载检查完成，证据见 [characters](../../evidence/characters/README.md)。实际斧长要求将交互外伸收紧到 1.15、自动站位 1.1；额度、产出与耗时不变。竖劈仅开放检视，未新增制作业务。
