# 重量、占用空间与材料搬运

基于 PR #10 的 55858f6；本批独立 PR，不合并、不发布。保持沙漏和离线规则不变。

目标：材料注册重量与占用空间；混合携带、软减速、硬容量、整理打捆；采集进入随身、采伐落地、就近拾取/放下、回营存放与取出。材料沿用唯一库存事务与世界存档，地面表现复用已有资源。最低移动倍率 1/3 为本项目待调参数，不宣称网游通行标准。

涉及 content/domain/app/scene/ui/存档与测试。验证容量边界、打捆守恒、失败原子性、地面距离与通路、旧档迁移/往返、沙漏不放大步速、桌面与窄屏操作。

人物大背包/怀抱枝束/肩扛原木只登记语义，不修改骨骼模型；包裹、筐、背包、推车登记数值候选和同一计算规则，暂不免费解锁。无全地图刚体、耐力/饥饿、自动运输或在线经济。
