# 2026-11-06 景观、交互与天气合批

## 目标与范围

将已获准接回本地主体的景观、木材表现、菜单与交互、天气及木料湿度整理为一个可审阅 PR。基线是远端 main `ffcf093`，已有 PR27 的营地生活、时钟和完整规划不重复覆盖；源试玩目录和暂存区保留原样。

- 场景：山谷 R2 外坡/河道/雪山/混交林、两棵造景树避开规划桥位、函数木纹、连树枝杈及可辨识碎柴。
- 交互与 UI：粗木边框、图标分页和集中详情、窗口外关闭、批量取放、木料区入口及晾晒提示、1.6 倍跑动、书页外禁选字、道具拖动/重摆/收回。
- 天气与领域：晴阴雨雪、全范围密度、地表湿润/积水/覆雪、储木架遮雨棚；真实木料湿度、转移守恒、精细加工工时及唯一存档流程。
- 本地入口：固定 127.0.0.1:5286、Windows 启动/看护脚本；仓库仅提供脚本，首次注册属于本机设置，构建不会注册系统任务。

可见验收为景观正常加载、桌面/窄屏可操作、跑动与拖放可靠、降水强度不缩小覆盖区域、露天和棚下木料形成实际湿度差、保存刷新后继续。按 HOW-BASELINE-1.0 推进已有 M0 场景/输入与 M1 木作/存档切片；不据此宣称整阶段完成。

不包括 PR24 桥梁施工及开放区域、未批准的独立沙盒、季节经济、体力、在线服务、历史存档迁移、合并、部署或采购。生产实现不依赖本地设计沙盒、截图、冻结存档或交付 zip。
