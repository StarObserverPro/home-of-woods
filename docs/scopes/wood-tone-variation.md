# 木色分组与稳定深浅漂移

本次补充基于 PR33 `17966e02d2ae435f3a5c8ec4513b91e1b947938b`，只修改木材美术表现，不合并、不部署。状态：规划与实现中。

目标：在现有低模和有限木纹基础上形成浅杨木、暖松木、深棕碎柴的统一色阶；同组内小幅、可复现的深浅和冷暖偏移。不做逐帧颜色动画，不为木色引入新的玩法树种或改变材料、批次和品质身份。

实现优先复用已有木纹坐标、顶点/实例色及共享材质；按木件而非随机三角面变化，保留端面与侧面关系；树皮与裸木分开，布、绳、金属、叶片及品质流光不改。木屋、家具与木料统一接入；带明确树种来源时尊重来源，未知来源只取中性木色，不伪造物种。

验证：固定seed/相机的日夜与近远画面、原木/碎柴/板件色阶、刷新与搬动稳定、贴图和木纹保留、材质缓存及释放；不改变几何、碰撞、规则和存档。先看实际画面，再记录已验证范围。截图只留临时目录或CI artifact。
