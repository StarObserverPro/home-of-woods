# 木色深浅变化

本次补充基于 PR33，只修改木材美术表现；未合并、未部署。按最终范围，**不注册树种、不关联物种或库存来源**。浅奶棕、暖蜜棕、中木棕、旧木深棕仅为视觉色阶。

同一木件整体施加稳定的小幅深浅变化，不对三角面随机上色，不随时间、世界位置、品质或加载顺序变色；端面、树皮和劈裂面保留原有关系。现有森林树种外观不重新映射。

复用木纹、几何/实例属性和共享材质；地板合并材质，碎柴以深棕为主并保留可辨的浅断面。布、绳、叶片、金属和品质特效不参与新木色处理。不改变几何形状、碰撞、玩法和存档。

验证范围：固定机位日夜/手机视口、木屋板材与家具、原木/碎柴对照、刷新稳定、材质和缓存释放。代码测试不代替画面检查；结果按实际完成记录。截图只留临时目录或CI artifact。
