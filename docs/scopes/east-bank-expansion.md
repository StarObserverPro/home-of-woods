# 溪流东岸扩区

目标：保留西岸营地，接通一块复用现有资产的东岸经营林，用真实木桥验证探索、采集、采伐和搬运。

涉及 content/world/domain/scene/app/UI 与存档；普通功能分支，不另建游戏沙盒。

可见验收：未建桥不能穿河；基础图纸和材料施工后桥面可走，点击寻路和负重往返共用通路。东岸有树木与采集物，无第二营地。完整树木与交互按 chunk 近身加载，远处保留简化林相；模拟范围独立，成长按统一时间补算。树木、桥梁、探索和未运材料保存重入。

未收运采伐只拦来源经营林区。拿起、越界和临时放下均不解锁；全部入库才解除，仓库取出的木头不计入。未交付的采伐木料不能绕过收运直接用于制作或交易。

女神初始赐福只覆盖营地；祭坛升级的覆盖查询与通路开放分离。本轮不做完整祈愿收益、船筏、疏浚、分营地、远方玩家、无限地图或通用历史存档迁移。原 PR24 验收未包含合并或部署；后续按用户的 PR23–33 整体合并授权接回主线。

实现和验证结果归 docs/WORLD_EXPANSION.md；截图与临时记录在仓库外，正式代码、资产登记与轻量结果随 PR 保留。现有 HUD 和独立树皮分支的归属保持清楚。
