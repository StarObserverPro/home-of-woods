# 统一光照与阴影规则

日期：2026-11-19。当前主线基于 `81a01f8`；新林地适配基于 PR39 `77cd116`。

## 目标

以共享的生成、单位换算和更新规则表达范围照度、实影、软影与接触暗部；提供室外环境、人物、室内三类配置，主角的连续可见性与接地表现优先。修复主游戏接触细节过早退场，并将新林地作为未来正式模块接入共享规则。

## 涉及层

- content：有限的阴影类别、尺度和预算参数。
- world：可复现的冠层/太阳投影场及单位换算，不拥有游戏状态。
- scene：共享材质、影图稳定、角色接触与各正式模块的适配器。
- docs：沙盒必须调用游戏共享规则；木作入场光照快照与室内独立性约定。

## 可见验收

- 普通主镜头及投影放大后，目标附近的接触细节按可见尺寸保留。
- 空地/林下对同一角色和地面产生位置相关的照度差异。
- 树干保留明确投影，高冠具有更宽更浅的投影；镜头淡冠不改变物理遮光。
- 主角真实投影持续更新，足部小暗区响应真实脚位、地表和抬脚，不留固定硬圆。
- 固定输入与共享模块的诊断图可复现；记录实际GPU验证，CPU测试不冒充画面结论。

## 明确边界

- 旧沙盒不逐个改造，也不以其旧灯光作为新规则验收；本轮只更新开发文档要求。
- PR39 新林地虽暂由 `/sandbox/forest-expedition/` 提供独立入口，属于未来游戏模块，必须实施接入。
- 木屋内部家具、转场、剖墙和屋顶显示另立专题，暂不实施。
- 木作正式入口取得一次环境光快照后独立计算；本轮规定接口内容及所有权，不为旧木作沙盒追加另一套光影。
- 不增加全屏AO、PCSS、全森林多级实时影或新的投影灯，不合并或部署。

## 状态

规则文档、主营地接线、共享室外/人物实现及新林地适配已完成，位于审阅分支；未合并或部署。具体规则由 [SHADOW_RULES](../SHADOW_RULES.md) 维护。

本地 TypeScript/Vite 生产构建通过，产物包括独立冠影Worker。共享阴影、人物接触、真实KayKit脚底锚点及原局部遮蔽共43项定向检查通过。共享校验入口直接调用正式模块，远端工作流生成固定输入截图和逐层A/B，并检查正式主游戏；新林地入口存在时追加正式模块检查。

本机浏览器因系统套接字权限限制不能建立WebGL上下文。首轮已在远端Chromium/SwiftShader完成真实渲染：核心[工作流44670901815](https://github.com/StarObserverPro/home-of-woods/actions/runs/44670901815)和林地[工作流44671124038](https://github.com/StarObserverPro/home-of-woods/actions/runs/44671124038)均通过，shader和页面错误为0，截图已目视检查。

实图发现高处木质枝架仍偏硬，因此追加共享高度渐淡，并增加同机位普通实体影/树木影A/B。浏览器实际Worker往返也追加太阳转向、移冠、恢复3次请求，检查提交前不改太阳、提交后方向一致、纹理产生实际差异、恢复逐像素一致。新增检查的结果以本分支后续 `Shared Shadow Rules Review` 与产物为准；实体手机GPU耗时、三图完整运动巡查和长时间游玩尚未验证。
