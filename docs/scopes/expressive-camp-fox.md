# 营地小狐狸与眼神

## 本次范围

用户认可候选 2 号兔子与 3 号狐狸的外形，要求眼睛能动、稍作加工后替换原兔。本次选用可取得源文件的 Vuena CC0 狐狸，替换营地和林缘的旧野兔。

涉及模型准入、动物内容登记与表现层。沿用现有出现、警觉、避让和退场逻辑；狐狸使用原游戏时钟、地表、模型缓存与资源所有者。眼部增加有节奏差异的眨眼、有限视线偏移与看向附近玩家的头部动作；移动、受惊分别使用源模型的 walk 与 run。

可见验收：真实营地近景能辨认睁闭眼和左右视线；停留、走路、跑步的姿态与地面关系正常；镜头转动不改变注视对象；暂停时表情不再推进；桌面与手机视口模型加载、光照和资源释放正常。

本轮不包含动物交易、喂食、奖励、宠物培养、购买兔子模型、PR 合并或部署。图片、录像和运行报告写临时目录或 CI artifact，不进入源码树。

## 来源与加工

来源、锁定版本、原件与产物校验值由 `sources/vuena/cute-pets/` 和 `public/assets/manifest.json` 记录。源狐狸的眼睛画在头部贴图上，闭眼使用独立眼睑网格及 Lids 骨骼；没有可独立旋转的眼球。本次在原眼区内做有限 UV 形变，并复用原眼睑，不把效果描述为眼球骨骼旋转。
