# 营地小狐狸与眼神

## 本次范围

用户认可候选 2 号兔子与 3 号狐狸的外形，要求眼睛能动、稍作加工后替换原兔。本次选用可取得源文件的 Vuena CC0 狐狸，替换营地和林缘的旧野兔。

涉及模型准入、动物内容登记与表现层。沿用现有出现、警觉、避让和退场逻辑；狐狸使用原游戏时钟、地表、模型缓存与资源所有者。眼部增加有节奏差异的眨眼、有限视线偏移与看向附近玩家的头部动作；移动、受惊分别使用源模型的 walk 与 run。

可见验收：真实营地近景能辨认睁闭眼和左右视线；停留、走路、跑步的姿态与地面关系正常；镜头转动不改变注视对象；暂停时表情不再推进；桌面与手机视口模型加载、光照和资源释放正常。

本轮不包含动物交易、喂食、奖励、宠物培养、购买兔子模型或手动部署。用户追加授权：完成下述眼部湿润效果并验证后，合并 PR #51。图片、录像和运行报告写临时目录或 CI artifact，不进入源码树。

## 追加范围：眼部湿润感

已在原眼区增加角膜材质反光，使用局部低粗糙度、浅弧面 clearcoat 法线与随观察方向变化的反射，保留原有眨眼、视线和头部动作。复用主场景的 PMREM 天空、直接光和材质，不增加额外渲染通道、贴图、模拟时钟或眼球网格；毛发继续使用原粗糙度。原 ORM 参与眼区遮罩，眨眼同时收起反光，角膜间接反光接入共享 AO。

可见验收包括同姿态反光开启／关闭对照、转头后的高光变化、闭眼不漏出反光，以及桌面和手机视口的近景。完成定向测试、构建与实际看图后合入 main；自动发布如由仓库既有工作流触发，以其结果另行记录。

## 来源与加工

来源、锁定版本、原件与产物校验值由 `sources/vuena/cute-pets/` 和 `public/assets/manifest.json` 记录。源狐狸的眼睛画在头部贴图上，闭眼使用独立眼睑网格及 Lids 骨骼；没有可独立旋转的眼球。本次在原眼区内做有限 UV 形变，并复用原眼睑，不把效果描述为眼球骨骼旋转。

## 实现与验证

实现已进入 [PR #51](https://github.com/StarObserverPro/home-of-woods/pull/51)。运行资产只含一个 mesh / material、7,300 三角形和 19 根骨骼，GLB 641,856 bytes；几何与贴图由缓存共享，实例仅拥有自己的材质和骨架。原版重复 LOD 及无关动画已移除。

已完成本地验证：

- `npm run verify:assets`、`npm run build`、`git diff --check` 通过。
- `node --experimental-strip-types --test tests/fox-expression.test.ts tests/wildlife*.test.ts tests/final-integration.test.ts`：28 / 28 通过。
- 真实 GLB 的睁闭眼位移、左右注视方向、相机不参与注视、暂停 60 次更新无额外旋转累积、run 切换和五次生成／退场后的资源归还均通过。
- 独立检查确认身体转向后，头部仍绕正确的世界竖直与横向轴偏转；albedo 与 ORM 粗糙度使用同一局部位移，保持营地 AO、树冠阴影和空气透视的材质钩子。
- 离线复建输出一致；源 ORM 的 R 通道全 255、B 通道全 0，输出显式非金属因子不改变外观。
- 追加湿润材质后，28 项动物与整合测试、15 项既有 AO 测试及构建通过。眼部实例的反光 uniform 独立、闭眼归零、重复编译保留同一 uniform，干湿对照和眨眼不产生新 shader 程序。

实际主游戏画面由 `Fox Appearance and Expressions` 工作流生成，结果、人工看图结论与 artifact 链接维护在 PR #51。固定开闭眼、左右视线及步态两相位使用桌面 1100 × 760 / 手机 390 × 844；每端另有睁眼、闭眼和左右转头共四组同姿态干湿对照。自然眨眼观察使用 550 × 380 画布，降低软件渲染负担，同时核对暂停与资源请求。固定取样使用暂停的原场景，不等同于自然游戏录像。截图、探针和 JSON 仅在 Actions artifact，软件 WebGL 与手机视口模拟不作为真实手机 GPU 性能结论。

本地浏览器因执行环境限制未启动，因此未以本地构建或参数测试替代实机看图。合并与发布状态以 PR 为准。
