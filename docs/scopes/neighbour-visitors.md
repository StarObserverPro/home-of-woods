# 一位邻居的营地来访与记忆

日期：2026-11-19。开工主线：`81a01f8519b921128575f6cf462416c191ae392c`。

## 目标与范围

只增加一位住在山另一侧的邻居，形成可以继续扩展的营地 NPC 基础：固定人格、分离的外观引用、结构化重要记忆与承诺、一次来访的短计划和会话、自然离场，以及受当前能力和世界观约束的输入回应。完整规则见 [NPC 来访合同](../NPC_VISITORS.md)。

本轮直接完成可由本地代码承担的部分，并定义 AI 的数据边界。环境没有可用模型 API 凭据；不创建密钥、账号或付费调用，不把模型输入输出合同和本地预写回应宣称为真实 AI 已接入。

## 可见验收

1. 同一位邻居沿可行路径来访，可被招呼、交谈或明确请他自行转转；无人回应时自行做可用活动并离开。
2. 全屏木工可通过专注状态让客人自行活动；客人不抢镜头、焦点与制作输入。独立木作组件的真实接线范围分别记录。
3. 接待、交谈和共同活动限制 4× / 12×；允许各自活动后可以加速，停留期限按世界时间推进，行走和短动作维持普通速度。
4. 有限自由输入能区分有效话题、指代不清、离题、尚无能力与缺少现场条件；未知输入不产生虚构动作或资源。
5. 重要经历可以保留梗概、减少细节和置信度或遗忘；事实承诺和已结算结果保持独立，模型无法通过隐藏原文恢复完美记忆。
6. 来访会话一次构建有限上下文，其后通过事件增量更新；没有逐帧模型请求或每一步重读全人物档案。
7. 当前状态、记忆和承诺可随世界保存与恢复；重复响应、过期提案和重载不重复提交效果。

## 当前交付边界

- 不增加其他普通访客、第二营地、邻居住所地图或人物家庭模拟。
- 原行商交易、货单、铜币与供给节律继续由现有模块管理。
- 真实共餐、帮厨、木作协作、舞蹈和留宿按现场能力逐项开放；缺前置时自然暂缓，不能用台词代替实现。
- 模型任务分为输入理解、来访规划、角色表达和记忆整理；只是可配置职责，不把讨论中的模型称呼硬编码为 API ID。
- 当前不运行真实模型，不宣称完成云端 Agent、供应商会话缓存或模型成本验证。
- 不加入第二时钟、第二保存器、模型自主库存、网络经济、历史存档迁移工程或无关全量证据门禁。
- 不自动合并或部署并行木作/地图扩展 PR；本轮的提交、PR 和发布状态分别记录。

## 本地试玩入口

在本分支运行 `npm ci`、`npm run dev`，进入营地并保持沙漏运行。新游戏从 14:00 开始，约 30 世界秒后阿榆在山路上出现；玩家可点选人物或底部来访提示，在空地等他到来。正常来访包含打招呼、短对话、看工作台、火塘边停留、明确各自活动和告别。

可以分别试“我在做一把新椅子”“别跳舞，看看椅子”“我唱歌，你跳舞”及明显不属于世界的话题；前两项进入有限的木作交谈/观察，未实现的舞蹈不会执行。通过“约好下回来看看木作”明确形成一条承诺，当前即可询问回忆，下一次真正观察工作台后才登记完成。

当前工作台面板已调用 `setNpcHostFocused`。独立木作 PR 的全屏宿主后续用同一接口接入；不能将该宿主错误接到会冻结整个世界的仓库 `setInterfaceOpen`。睡眠前应告别；若他已经开始离场，睡眠过渡可完成这次离场。
