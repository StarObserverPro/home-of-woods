# HUD 与文案整改范围

- 基线：main `5f85efd`，2026-11-05。
- 目标：恢复透明且克制的常驻 HUD，消除操作与说明堆叠，统一查看、走近、操作的顺序。
- 涉及层：UI/CSS、林业快照的距离展示字段、对应文档。沿用已有素材与图标，无新游戏资产或运行时依赖。
- 可见验收：远处设施仅一个走近操作且不自动扣料；改造按件展开；五个物品分组完整可见；桌面、390×844、320×640、844×390 无操作区重叠与横向溢出；常用按钮不小于 44 px。
- 不涉及：经济数值、物品归属规则、资产建模、树形、渲染预算和历史存档迁移。
- 交付：独立 PR；合并和发布另行记录。

## 验证结果

- `npm run build` 通过；保留已有的产物体积提示，本轮未新增运行时依赖。
- `npm run verify:assets` 通过，15 个 GLB 的加载清单、哈希和许可检查通过。
- 林业、库存交互、升级、营地外部、日循环和食物的针对性测试通过；林业新增“近处额度不足仍属近处”的回归用例。
- 当前 CI 使用的衣柜、人物换装、行商、食物、日循环、词条与发布整合测试共 39 项通过。
- Chromium 153 / WebGL2 / SwiftShader，seed 104729，DPR 1：检查 1000×740 桌面、390×844 与 320×640 竖屏、844×390 横屏。实机截图确认层级与文字；按钮尺寸、工具区间距及横向溢出检查通过。横屏截图发现标题负边距与内边距不一致，已对齐并复测。
- 实际操作通过：营地路线只选中不移动；物品与路线面板互斥，Esc 收起；镜头操作与 Esc；改造默认折叠且一次展开一个部件；远处木屋仅一个走近入口，到达不扣料、不自动开工，材料不足时近处安装按钮禁用。
- 测试期间未出现应用异常、资源请求失败、着色器错误或 WebGL context 丢失。软件渲染只用于布局与操作检查，不作为实际设备帧率结论。拖拽取放沿用既有回调，本轮未重复完整拖拽事务测试。
- 可复用检查入口：`tools/verification/hud-flow.mjs`，连接已有 CDP 浏览器，支持 `TEST_ORIGIN`、可选 `BASELINE_ORIGIN` 与 `EVIDENCE_DIR`。截图仅保留临时证据，不提交仓库。
