# 每帧场景准备预算

## 范围

本 PR 为现有主循环加入协作式场景准备队列。近身交互、游戏时间、碰撞和事务仍同步执行；区块 Mesh 准备按小步骤排队，完成后同帧提交近远表示和命中集合。中距离树的形状、面数、树位和持久身份保持现状。

目标是限制一次移动引起的准备工作尖峰，公开实际步数、耗时、超支和取消统计。JavaScript 单步不能抢占，因此这是可测的软预算，不是整帧 CPU/GPU 的硬实时保证。

地被按有效实例压紧矩阵与颜色；新林地树冠透明度使用 ID 索引。暂停时由同一个循环完成表现准备，模拟不前进；隐藏、失去图形上下文、捕获锁和销毁仍停止。

## 近景管线决定

当前共享光照已有缓存冠层/局部环境遮蔽、真实脚位接触、实体阴影、冠影场和单次色调映射。本轮没有建立新增 GTAO、PCSS、泛光或自动曝光的明确近景收益，因此保留当前管线。此决定来自实现审查，不是新增效果的 A/B 性能结论。

## 验收

- 小预算真实跨帧续做，任务去重、取消和销毁有效。
- 每次区块提交后每棵树恰有一种有效表示，近景和命中集合一致。
- 倒树、树桩与换世界不会被旧任务恢复成站立树。
- 暂停只继续表现准备，不推进世界时间。
- 本地 43 项定向测试与 TypeScript/Vite 构建通过；包括队列 deadline/续做、每个 slice 的树身份守恒、反向取消、换世界、倒树、资源释放、暂停时钟、地被压紧及树冠索引。
- `Frame Budget Review` 使用真实主游戏、正式存档适配器和原有导航/固定步进，检查 1280×800 与 390×844 的暂停收敛、步行跨区块、着色器和绘制统计。截图和 JSON 留在 CI artifact。WebGL 结果以当前 PR 的工作流为准，软件渲染不能代表实体手机帧率。

受约束高位镜头与沿镜头路径的可见性预备由后续独立 PR 接入本队列。回退本 PR 恢复同步区块切换；世界存档格式不变。
