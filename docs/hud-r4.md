# R4 透明 HUD

R4的 `src/ui/App.tsx`、`src/ui/style.css` 已获准回接当前实现分支；PR合并与发布另行记录。UI 读取快照、发送意图，不计算砍伐资格、额度扣减、木材奖励或补生规则。

## 合并与视觉

- 原品牌、地点、天气和探索卡合为左上角一组：品牌、当前地点、天气、已发现风景及木材摘要。
- 原底部探索栏与右侧镜头栏合为同一组工具，保留漫步、路线、操作、旋转、缩放和复位入口。
- 常驻 HUD 移除奶油色卡片及按钮底板。文字使用两层柔暗阴影，SVG 和符号另有轻量投影；实际背景继续可见。
- 小地图移除实色地面，改为透明山形、路水线条和地标。打开路线、帮助或目标详情时隐藏重复的小地图。
- 目标、路线和帮助使用克制的深色透明渐变与轻模糊，主要依靠文字阴影衬起内容。暂停对话框同样为透明层。
- 普通提示不与目标详情、帮助、路线或动作状态重复叠加。稳定树位和个体 ID 只出现在诊断模式；正常操作显示树木状态、距离、资格原因和动作。

## 尺寸约束

以下为 CSS 设计约束，不代替浏览器实测。

| 场景 | 布局 |
| --- | --- |
| 桌面 | 左上摘要、右上透明小地图、右下合并工具组；目标详情位于左下，避开工具区 |
| 390×844 竖屏 | 工具组宽 236 px，右下分两行；摇杆宽 106 px，位于左下；上下文面板位于工具组上方 |
| 844×390 横屏 | 工具组收为一行；摇杆宽 94 px；路线、帮助和目标详情限定高度并允许滚动 |
| 小于 360 px 的竖屏 | 工具组进一步收窄；镜头按钮分两行，复位跨两行；摇杆缩为 94 px |

产品按钮全局最小触控框为 44×44 CSS px，底部和边缘适配安全区。诊断摘要不属于产品触控入口，保留紧凑显示。复选框通过至少 44 px 高的标签区域操作。

## 输入、状态与林业合同

常驻摘要、地图和工具区域有自己的 DOM 命中区域；场景输入仍只监听 canvas。原有 Esc、焦点轮廓、暂停恢复、摇杆捕获及防文本选中行为保留。

林业区读取 `Snapshot.forestry`：

- `wood`、`points` 仅显示运行时结果。
- `selectedTree` 提供状态、距离、资格、成本、产出、禁伐原因与当前个体 ID。
- `active` 提供 `chopping` / `falling`、进度和击打次数。

UI 意图通过 `approachSelected()`、`chopSelected()`、`cancelChop()` 发送。只有经营树且 `standing` 时显示砍树入口和预计成本 / 木材；实际启用由 `canChop` 决定。巨木卡不显示收获预测或砍树按钮，仅显示保护状态与原因。树桩、幼树按运行时理由禁伐。倒树阶段没有取消按钮。

选中树的进度留在上下文内；关闭目标后，进行中的动作可用紧凑状态条显示，避免与其他面板叠加。诊断个体 ID 使用快照的 `individualId`，可反映补生后的 `:g1`，不沿用静态第一代标签。

App 通过 `sessionState` 持有 `Runtime.getState()` 返回的引用，重入时传入 `createRuntime` 第三参；UI 不复制或修改该状态。额度和木材仍由 app/domain 的唯一状态拥有，诊断重入不另建 UI 余额。

## 清理与诊断

异步场景初始化保留取消检查。卸载仍销毁运行时；诊断重入的 audit 记录移到按钮事件中，避免在 React 卸载清理时更新 UI 状态。录像期间禁用重入按钮，防止旧 canvas 被销毁后仍继续录制。原有录制、播放和保存到指定沙盒目录的入口保留，录像 URL 仍在卸载时回收。

诊断“选择经营树”读取当前 slot 状态，只在 `standing` 的经营树中按当前人物距离选最近目标。它只发送正常的选择意图，不瞬移、不开始砍伐、不改树木状态或额度；走近仍通过正式寻路命令完成。普通场景拾取路径未改变。

诊断录像区分两种固定模式：`walkthrough` 保留自动前往溪谷的漫步流程，`forestry` 仅录制当前画面，不自动选树、走近或砍树。开始新录像会释放旧 URL 并清空旧 Blob，录制期间不可保存旧片或重入。保存路径只由模式联合类型决定：`/__evidence/walkthrough` 或 `/__evidence/forestry`；UI 不接受任意文件路径。R4 目录及两个实际输出文件名由开发服务器白名单处理。
