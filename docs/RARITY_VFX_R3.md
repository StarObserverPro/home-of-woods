# 稀有物品特效 R3：传说收光与三档显示

2026-11-02，继续 PR #9。以 `e221ecc161ec161da97bbdd7f55729f1070bd312` 的 R2 为基线；按用户最终确认，**史诗保持原样，只降低传说亮度**，新增完整／简化／关闭三档。未合并、未部署。

## 玩家入口与表现

普通操作面板和暂停面板都有「稀有物品特效」，共用同一个显示设置。

| 档位 | 地图表现 | 库存与属性详情 |
| --- | --- | --- |
| 完整（默认） | R2 表面流光和动态星芒。史诗不变，传说略收光，夜里再压低。 | 原有等级颜色、标签和词条照常显示。 |
| 简化 | 恢复物体原材质，每件史诗／传说只保留一颗紫／金静态表面星标。不铺流光、不闪、不转。 | 不变。 |
| 关闭 | 恢复原材质，不绘制流光、星芒或星标。 | 不变。 |

显示偏好保存于本机 `localStorage` 的 `home-of-woods.rarity-vfx`，不进入 `GameState`、物品数据或世界存档；不增加世界 schema，不重抽等级。缺失、未知值或读取被拒绝时默认完整；存储写入失败不阻止本次切换，界面说明本机未能记住选择。设置在场景创建前应用，刷新和场景重建继续使用该档位。

## 只收传说，不改史诗

`ITEM_VFX` 的既有色相、流动、点数和尺寸均保留。新 `ITEM_VFX_LIGHT` 将表面光与星芒使用的强度系数集中管理：史诗仍为白天 `1.0`、夜晚 `0.86`；传说为白天 `0.82`、夜晚 `0.62`，昼夜之间随现有天空夜间量连续插值。这是 shader 发光系数，不等同于经过色调映射后的屏幕亮度百分比。没有调整全场曝光，也没有再抬高史诗。

## 简化星标确实贴在表面

`scene/item-emblem.ts` 使用项目已有 Three.js 的 `DecalGeometry`，从实际网格三角面求交，再以目标表面法线进行局部投影和裁切。生成的贴花处于模型局部坐标，随模型变换，不朝向相机，不在头顶悬浮。当前木墩星标位于上端面；多个网格的物品最多选一处适合的表面，不按材质槽重复贴星。

星形由解析 shader 绘制，无外部素材、无新依赖、无动画时钟；使用普通透明混合，不添加外溢光晕。深度测试开启、深度写入关闭，polygon offset 避免同面闪烁；不投影、不参与射线命中。星标在夜间保持可辨但不呈现灯泡式高亮。关闭和简化档均恢复原表面材质，完整模式才绑定流光材质和动态 Points。

材质和几何继续由现有 `Resources` 所有者缓存及释放。五个木墩样品中，完整档多 2 个 Points 批次，简化档多 2 个贴花批次，关闭档没有附加批次；切换复用缓存，不随着操作次数增长。只有完整档推进特效时钟，仍由已有 app 主循环提供未乘沙漏倍速的 dt。

当前仍只适配普通静态 Mesh。SkinnedMesh 和 InstancedMesh 沿用跳过策略；无合适投影面的未来模型不强行生成悬浮标记，需要对应模型接入时另做适配。简化档不提供不受遮挡或任意远距可读的 HUD 图标。
