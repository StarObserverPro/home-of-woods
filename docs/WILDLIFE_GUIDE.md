# 最终动物接入

2026-11-02。以物品／物理主线 `79f4375` 为基础，只从动物最终交付 `0133eb5` 提取四种模型、动作与必要接线；不合入候选选型、旧羊、试错提交或临时工作流。此文件是当前动物范围的唯一说明。

## 山谷里会出现什么

| 位置 | 动物 | 表现 |
| --- | --- | --- |
| 营地附近、近处林缘 | 松鼠、野兔 | 短暂停留、走动，玩家接近时警觉和避让。 |
| 远处开阔山坡 | 雄鹿 | 驻足、抬头巡望、缓步，作为偶遇景观。 |
| 峡谷岩肩 | 北美山羊 | 最终三角块面模型，驻足、转头、抬前蹄和短程慢步。 |

所有动物都是装饰性偶遇，不带捕猎、喂食、拾取、好感或物品奖励。每种最多一只，总上限三只；近处小动物目标两只，远景大动物同时最多一只。稀有窗口与退场规则沿用最终动物实现，不把它们变成常驻摆件。具体候选参数集中于 `src/content/wildlife.ts`。

整合时发现旧野兔锚点 `(-30, 5)` 与新增 Woodcraft 区域重叠，已移至旁边空地 `(-31, 1)`；对应检视镜头同步更新。四个小动物锚点均以包含工作台和物理岛的当前碰撞集合校验。鹿与山羊原有远景锚点和模型没有替换。

## 保留的架构

动物使用现有 `GameState.time` 和应用主循环，不新增时钟、库存入口或存档写入者。`state.wildlife` 只是会话临时状态，保存时剔除，读档后按已保存的时间与 seed 重建候选。库存仍为核心格式 4、世界规则仍为 5；不会把本轮物品可选属性的兼容规则覆盖回动物支线的旧版本。

动物模型是可选资源：下载失败只跳过对应动物，不阻塞山谷和其他玩法。共享几何、材质和骨架资源归既有 Resources；实例退出释放自己的材质与骨架。退出、暂停、重新进入沿用现有生命周期。

## 最终素材

运行目录 `public/assets/wildlife/` 仅含 `squirrel.glb`、`hare.glb`、`stag.glb`、`mountain-goat.glb`。旧 `goat.glb`、Gobkit animalB 候选、候选选型文档均未带入。稳定玩法 ID `wildlife.goat` 指向 `how-wildlife-mountain-goat`，不是旧羊。

松鼠与野兔使用已登记 Gobkit CC0 原件，雄鹿使用已登记 Quaternius CC0 原件。采用部分的来源原件、许可证和校验值继续随仓库保留；不为减小仓库而删除许可或可复建源文件。北美山羊为项目原创模型：1908 三角形、21 关节，无贴图，保留最终修正后的落蹄和父节点相对动作。逐文件 SHA-256、出处和规格见 `public/assets/manifest.json`。

离线复建入口：`tools/prepare-wildlife-assets.mjs`、`tools/prepare-stag-asset.py`、`tools/build-mountain-goat.py`。后两项已复建并核对产物与最终交付字节完全一致。没有新增依赖。
