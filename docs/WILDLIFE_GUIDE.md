# 最终动物接入

2026-11-24 更新。沿用已接入的四种动物系统，将营地野兔替换为 Vuena CC0 小狐狸，补充眨眼、有限视线偏移和看向玩家的头部动作。此文件说明当前动物范围；本次加工与验收记录见 [营地小狐狸与眼神](scopes/expressive-camp-fox.md)。

## 山谷里会出现什么

| 位置 | 动物 | 表现 |
| --- | --- | --- |
| 营地附近、近处林缘 | 松鼠、小狐狸 | 短暂停留、走动，玩家接近时警觉和避让；狐狸会眨眼、张望及转头，受惊时奔跑。 |
| 远处开阔山坡 | 雄鹿 | 驻足、抬头巡望、缓步，作为偶遇景观。 |
| 峡谷岩肩 | 北美山羊 | 最终三角块面模型，驻足、转头、抬前蹄和短程慢步。 |

所有动物都是装饰性偶遇，不带捕猎、喂食、拾取、好感或物品奖励。每种最多一只，总上限三只；近处小动物目标两只，远景大动物同时最多一只。稀有窗口与退场规则沿用最终动物实现，不把它们变成常驻摆件。具体候选参数集中于 `src/content/wildlife.ts`。

狐狸沿用已避开 Woodcraft 区域的营地空地 `(-31, 1)` 和林缘锚点；近景检视固定在同一营地地表。四个小动物锚点以包含工作台和物理岛的当前碰撞集合校验。鹿与山羊保留原有远景锚点和模型。

## 保留的架构

动物使用现有 `GameState.time` 和应用主循环，不新增时钟、库存入口或存档写入者。`state.wildlife` 只是会话临时状态，保存时剔除，读档后按已保存的时间与 seed 重建候选。库存仍为核心格式 4、世界规则仍为 5；不会把本轮物品可选属性的兼容规则覆盖回动物支线的旧版本。

动物模型是可选资源：下载失败只跳过对应动物，不阻塞山谷和其他玩法。共享几何、材质和骨架资源归既有 Resources；实例退出释放自己的材质与骨架。退出、暂停、重新进入沿用现有生命周期。

## 最终素材

运行目录 `public/assets/wildlife/` 仅含 `squirrel.glb`、`fox.glb`、`stag.glb`、`mountain-goat.glb`。`wildlife.fox` 对应 `how-wildlife-fox`；原 `hare.glb` 已退出运行目录。稳定玩法 ID `wildlife.goat` 继续指向 `how-wildlife-mountain-goat`。

松鼠使用已登记 Gobkit CC0 原件，狐狸使用 Vuena / Popyca 免费样本中的 CC0 原件，雄鹿使用已登记 Quaternius CC0 原件。原件、完整许可与校验值随仓库保留；历史 Gobkit 兔子原件仍保留，但不加载。北美山羊为项目原创模型：1908 三角形、21 关节，无贴图。逐文件 SHA-256、出处和规格见 `public/assets/manifest.json`。

离线复建入口：`tools/prepare-wildlife-assets.mjs`（松鼠）、`tools/prepare-fox-asset.mjs`、`tools/prepare-stag-asset.py`、`tools/build-mountain-goat.py`。狐狸复建不联网，也不新增依赖。

狐狸只保留单个 LOD0：7,300 三角形、19 关节、单个材质，运行 GLB 641,856 bytes。总高归一为 1.10，保留原始 albedo / ORM 贴图和 `idle`、`walk`、`run`。眨眼复用原始 `Lids` 骨骼，间隔按个体 seed 变化；移动时仍会眨眼。眼睛原本画在脸部贴图上，本次用局部 UV 位移表现轻微视线变化，并同步粗糙度。它没有独立眼球骨骼，因此不把该效果写成完整眼球转动。

附近玩家是注视目标，镜头位置不参与计算。眼神先跟随，头部缓慢跟随；奔跑时回到前方。表情仅消费 `GameState.time`，暂停时保持原姿态；减少动态效果时关闭额外的眼神、头部和眨眼动作。检视入口“小狐狸 · 眼神检视”暂停在真实营地光照中；仅开发模式 `?inspect=1` 提供绝对姿态采样，采样不改世界时间或动物状态。

## 验收与记录

当前针对性测试覆盖动物准入、碰撞锚点、眨眼与注视、暂停无累积旋转、实际跑步动画，以及五次生成／释放后的材质和骨架归还。狐狸的主游戏浏览器复现脚本为 `tools/verification/fox-review.mjs`。`evidence/final-integration/report.json` 保留早期四动物组合记录，不作为新狐狸的视觉证据。

当前树不再保存验证 PNG/JPEG/WebP/GIF。历史截图仍在不可变提交中，历史审计临时取回原始字节并于检查后删除，不放宽 hash 校验。新的实机截图只写临时目录或 CI artifact；游戏模型、正式纹理和源素材不受此规则影响。

浏览器检查使用 Chromium / ANGLE SwiftShader 和手机视口模拟，不替代真实手机 GPU、长时间游玩和大量物体性能验收。合并状态以 GitHub PR 为准，不把源码整合写成已部署。
