# 当日沙盒成果主体使用核对

本批接入 PR #6；既有主体以已合并的 PR #4/#5 为前置。此表核对实际入口，不将独立沙盒文件存在视作已接入。

| 成果 | 实际生产入口 | 本批核对 |
| --- | --- | --- |
| 八类树形、颜色/比例与枝冠起伏 | world/tree-appearance → Models.sourceForTree → forest-shapes → createForest | 580 个固定树位全部采用新树形，8 类均有实际实例；经营树静态/攀爬/采伐共用来源，远景降低冠面细分 |
| 蕨类片区、带状草、单体灌木、棱角石、朽木、落叶 | createScene → createUnderstory | 10 批实例；树冠阈值 .42、道路/水岸/建筑/坡度避让；伐后隐藏宿主蕨丛，幼树长成后恢复；只做装饰，不发放资源 |
| 溪流倒影/水花、山崖/封边、雪山/天光 | createTerrain / createEnvironment / createCreek | 主场景现行调用；地形统计含 166 处碎面与封闭地形，反射单目标 |
| 昼夜篝火、原木架、石基与悬浮祭坛/纸页 | createCampProps | 当前场景仍加载；原木架数量来自真实库存，日间焦木与夜火通过场景检视切换 |
| KayKit 人物、双手工具、访客与接触止点 | createCharacters / character-grip / axe-contact | 主体角色运行，原包及修改许可记录保留；新树动作沿用现有接触系统 |
| 上树采枝、蹲采蘑菇、拾碎柴、定向断口伐倒、祈祷 | runtime → player-actions → characters/actions + forestry-presentation | 原有事务与镜头仍在主操作链；新树源用于动作树，避免动作切回旧树形 |
| 库存、木料规格、完整世界保存 | domain/inventory / world-save + app/save-controller | 未改变数据结构；回归包含树位、库存守恒、幂等、存档往返与损坏保护 |

本批没有复制沙盒渲染器、主循环或存档代码。树形的属级名称是视觉分类，物产仍为原有针叶/阔叶规则；尚未实现的制作、供奉交易与完整 M1/M2 不计入本次成果。

## 入口与回退
正常游戏入口直接使用新形态；`?inspect=1` 的运行检查增加“树形与林下”观察位置及 treeShapes/understory 统计。独立样区继续保留，生产代码不导入 sandbox。
回退本批生产接入提交可恢复旧表现；树位/世代/物产身份与存档版本没有变更。

## 预算与验证口径
林下上限 90 株蕨、320 草簇、40 灌木、45 碎石、12 朽木、10 批实例及 100000 三角形；当前固定场景为 80 株蕨、86358 三角形。全部地被不投实时阴影，接收现有光照。树形缓存每类 3 变体，远景冠形低细分，经营树保留近景形态。统计中游戏总三角形包括阴影与反射，不能直接与沙盒单通道比较。
当前测试、浏览器截图和统计见 [本批证据](../evidence/forest-intake/README.md)。历史动作证据改为校验由 PR #5 提交提取的不可变源码压缩包；原 SHA 和断言均保留，当前行为由本批回归与新证据承担。
