# 游戏日、晚餐与林间阅读 · 首轮可玩接线

2026-11-05：本范围已随营地生活获准回接本地主体，继续复用 [食物基础链路](FOOD_FOUNDATION.md) 和现有行商规则。当前座位、书碗互斥、生活日与恢复合同及主线验证统一见 [CAMP_LIFE_INTEGRATION](CAMP_LIFE_INTEGRATION.md)；本文保留首轮节律设计。

后续目标与阶段边界见 [食与生活四阶段规划](FOOD_LIFE_PHASES.md)；[当前推进映射](CAMP_LIFE_PROGRESS.md) 单独记录 P2 代表链、有限 P3/P4 及本轮沙漏修复状态，初版接线记录不替代后续验收。

## 一天怎样经过

- 继续使用唯一的 `GameState.time` / `clock.speed`。一天仍是 1200 游戏秒，沙漏可停（0）或走 1×、4×、12×。本轮没有重置季节、林业或生产的时钟。
- 顶栏显示实际 HH:mm 和“时间”入口；停钟时直接提供“继续时间”。整理物品、读书及游戏暂停会显示原因，结束后保留原速度。速度切换纳入现有自动保存检查点，即使停钟且没有物品变化也能保存所选档位；本轮实际验证见根 [VERIFICATION](../VERIFICATION.md)。
- 无论当时选哪档速度，**第一次跨越该日 18:00** 时精确截断在 18:00，自动置为 0×，留下当天的停靠标记。不会跨越晚餐、悄悄刷到第三天，也不会在原地再次触发同一天停靠。玩家可以直接选择 1×/4×/12× 继续傍晚和夜间探险。
- 沙漏停下后，已有的动作仍可选择；开始一锅真实汤品会恢复到 1×，以便依原先世界时间完成烹饪。打开阅读界面暂停日历但保留轻量场景动画。未吃饭仍然可以结束一天；用餐与重体力资格按 06:00 换生活日，凌晨进食仍能为眼前日出做准备，再吃饭保留已经获得的当前资格。
- 从 18:00 到次日 06:00（或已经入夜后的最近一次 06:00），**玩家主动选择**「结束一天」才跳过夜晚。只能在营地帐篷附近且没有正在进行的作业、未煮完的汤时使用；如果玩家还在远处，按钮先变成「回帐篷」，按现有寻路返回后再结束一天，拒绝从外面的山头瞬移睡觉。睡眠只跳至**下一次日出**，不额外跳几天。
- 起床时视角短暂暗下、从次日晨光中恢复，角色在帐篷门口做一段简短出门步行（纯表现、不修改碰撞位置），沙漏重回 1×；正进行的蘑菇晾晒由同一游戏时间到期结算一次，树木和采集资源使用各自原有到期规则，不创建第二条离线收益通路。

## 阅读

- 营地火塘附近提供「坐下读故事」。沿用原场景镜头，轻微聚焦篝火与座位；角色在真实座面坐读并持书；木碗只由成功进食事件展示，与阅读互斥，不能凭当天吃过饭而自动端碗。座位前方、脚下或起身通道受阻时先拒绝入座并说明原因。
- 故事内容来自 `src/content/forest-stories.ts`，初版是固定的十则本地短篇（每则三页）。按世界 seed、当前游戏日和用户翻阅次数确定性选择。阅读不需要 API、不扣物品、不发奖励、不推进世界时间。
- 首版不是几十万字文库，也没有对接外部自动生成；文库可以独立扩展为预生成内容包，需统一叙事风格、篇幅、标签与离线打包。需要实时生成的访客故事另走 NPC 分支，不能把网络调用放在游戏主循环里。

## 共享服务与存档

- `src/domain/day-cycle.ts` 只负责傍晚边界、睡眠目标和能否入睡。日历单位由 `src/domain/local-clock.ts` 一处定义；`src/scene/create-scene.ts` 的环境短动画使用独立展示时间，沙漏真正停下时不会把火焰与人物行走全部冻住。此展示时间不产生库存、经验、计时器或世界进展。
- `dayCycle.lastEveningStopDay/nightsSlept/wokeAt` 随统一世界存档保存并校验。旧有效存档缺少该附加字段时补安全缺省，不需要独立数据库。
- `sleepUntilSunrise` 只改变时间、角色位置与本分支状态，应用层沿现有主更新服务处理到期的菌类加工、森林换代和采集状态。
