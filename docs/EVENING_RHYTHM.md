# 游戏日、晚餐与林间阅读 · 首轮可玩接线

本范围依赖 [食物基础链路](FOOD_FOUNDATION.md) 所在的 PR #18。**基于它的分支工作，不合并、不部署，不擅自改写现有行商经济。**

## 一天怎样经过

- 继续使用唯一的 `GameState.time` / `clock.speed`。一天仍是 1200 游戏秒，沙漏可停（0）或走 1×、4×、12×。本轮没有重置季节、林业或生产的时钟。
- 无论当时选哪档速度，**第一次跨越该日 18:00** 时精确截断在 18:00，自动置为 0×，留下当天的停靠标记。不会跨越晚餐、悄悄刷到第三天，也不会在原地再次触发同一天停靠。玩家可以直接选择 1×/4×/12× 继续傍晚和夜间探险。
- 沙漏停下后，已有的动作仍可选择；开始一锅真实汤品会恢复到 1×，以便依原先世界时间完成烹饪。打开阅读界面暂停日历但保留轻量场景动画。未吃饭仍然可以结束一天；下一日由现有 `heavyLaborAllowed` 判断重体力劳动资格。
- 从 18:00 到次日 06:00（或已经入夜后的最近一次 06:00），**玩家主动选择**「结束一天」才跳过夜晚。只能在营地帐篷附近且没有正在进行的作业、未煮完的汤时使用，拒绝从外面的山头瞬移睡觉。睡眠只跳至**下一次日出**，不额外跳几天。
- 起床时视角短暂暗下、从次日晨光中恢复，角色重置在帐篷门前，沙漏重回 1×；正进行的蘑菇晾晒由同一游戏时间到期结算一次，树木和采集资源使用各自原有到期规则，不创建第二条离线收益通路。

## 阅读

- 营地火塘附近提供「坐下读故事」。沿用原场景镜头，轻微聚焦篝火与座位；角色采用轻量坐姿以及在当天已吃饭时才出现的木碗表现，不要求打开锅内放大镜。
- 故事内容来自 `src/content/forest-stories.ts`，初版是固定的十则本地短篇（每则三页）。按世界 seed、当前游戏日和用户翻阅次数确定性选择。阅读不需要 API、不扣物品、不发奖励、不推进世界时间。
- 首版不是几十万字文库，也没有对接外部自动生成；文库可以独立扩展为预生成内容包，需统一叙事风格、篇幅、标签与离线打包。需要实时生成的访客故事另走 NPC 分支，不能把网络调用放在游戏主循环里。

## 共享服务与存档

- `src/domain/day-cycle.ts` 只负责傍晚边界、睡眠目标和能否入睡。日历单位由 `src/domain/local-clock.ts` 一处定义；`src/scene/create-scene.ts` 的环境短动画使用独立展示时间，沙漏真正停下时不会把火焰与人物行走全部冻住。此展示时间不产生库存、经验、计时器或世界进展。
- `dayCycle.lastEveningStopDay/nightsSlept/wokeAt` 随统一世界存档保存并校验。旧有效存档缺少该附加字段时补安全缺省，不需要独立数据库。
- `sleepUntilSunrise` 只改变时间、角色位置与本分支状态，应用层沿现有主更新服务处理到期的菌类加工、森林换代和采集状态。

## 留给后续模块的交接提醒

**当行商 NPC、物资供应和五金/器具采购进一步施工时**，应顺便核对这次食物链：混合粮袋的数量与交易成本、谷物/豆/黑面包的供货比例、干香料口味、金属锅与五金件、晾晒架改良配件以及未来发酵器具。这些应归同一套行商库存与到访规则；当前不复制商人日程或季节补货。

**暂缓**：更多汤、盐渍/烟熏/发酵、橡实加工、丰富 NPC 帮厨、复杂厨房、食谱全集和全部 F01–F100 奇趣词条。首版着重日常节律闭环，不为了故事系统新设饥饿或体力条。

## 验证与限制

`tests/day-cycle.test.ts` 应覆盖 12× 恰停 18:00、0× 不再推进、后半夜可选探索、最近一次日出、缺饭的次日重体力禁用、睡眠安全约束、旧世界字段缺省以及本地故事选择。PR CI 的检查结果与**真实桌面/手机画面操作**必须分别记录。

本轮清晨效果为轻量过场与帐篷门前的定位，不是完整的帐篷进出骨骼动画。夜间照明/夜行安全规则、逐日大型经济调整以及完整睡眠起床表演留待专项验收。
