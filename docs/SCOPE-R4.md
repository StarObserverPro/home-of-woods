## 入口与目标

在主体根目录执行 `npm.cmd ci` 和 `npm.cmd run dev -- --port 5173`，访问 <http://127.0.0.1:5173/>。`?inspect=1` 为诊断入口，包含选择最近成材经营树、重入及录像工具；正常流程通过场景拾取选择树木。目标是让玩家在同一山谷里辨认地形与植被、走近并明确发出砍伐意图，看见挥斧和整树倒下，并在保留树位的同时得到一次原木结算。

R3 的五个 GLB、地表锚点、统一地面插值和固定树位继续使用。R3 的概念认可不外推为 R4 实机视觉通过；原始图像/Atlas 链路继续由 [PIPELINE.md](../art-direction-r3/PIPELINE.md) 追踪。

## 涉及层与实现

| 层 | R4 内容与所有权 |
| --- | --- |
| content | forestry.ts 放候选耗时、额度与补生参数；biomes.ts 放林下、草甸及过渡色板；environment.ts 放原创远山和固定白昼天光参数。 |
| domain | GameState 持有唯一模拟时间和林业状态。domain/forestry.ts 负责资格、距离、单动作预留、完成复核与一次结算，保留 slotId / 逐代 individualId。 |
| world | 沿用统一地表、路径、河道与稳定树位。砍伐后的树桩和成长中的幼树碰撞消费当前状态；地被/水面 shader 不修改导航事实。 |
| scene | forestry-presentation.ts 消费状态，展示斧头、木屑、树体倾倒、树桩和幼树，不结算奖励。ground-material.ts 按规划着色。environment.ts 建立六组 PNW 风格原创远山、Sky 天空/PMREM 和原河面材质；共享资源由 Resources 释放。 |
| app / HUD | runtime 统一更新并提交状态，提供 approachSelected / chopSelected / cancelChop。走近优先相机前方斜侧 45°，按 8 方位 A* 找安全落点，不瞬移。HUD 合并摘要和工具、移除常驻底板，以文字和图标阴影衬起内容，显示树木状态/距离/资格/进度；近树时可“调整站位”，action-message 显示导航/取消等运行时反馈。App 为场景重入持有同一状态引用，不复制经济余额。 |

仍只有一个 app RAF、一个运行时状态源和一个可玩地表事实。新增模块没有独立定时器；表现层不结算奖励。固定 seed 不按加载顺序生成持久身份。

## 可见验收目标

- 同一固定相机/seed 下能辨认草甸、林下、路和水岸色块，地被不随每次重入或砍一棵树随机变化；角色落地、路线和碰撞继续一致。
- 雪山具有宽阔冰川火山、分层山脊、冰斗、刃脊、裸岩与雪线；保留圆润玩具世界的前景材料，远山有距离和空气层次。它们是 PNW 启发的原创轮廓，不声称重建某座真实山。
- 天空有白昼和云层层次，水面有岸边浅色/泡沫与流动细节；天空、PMREM 与水流在浏览器中实际编译并显示，暂停和减少动态效果可用。
- 选中成材经营树，走近后明确开始；四次挥斧后提交一次原木和额度，再倒下成桩。倒伏源树躺地保留 1.8 模拟秒再隐藏，期间不参与拾取。重复操作不重复结算；保护巨木无砍伐按钮或预计可收获成本/产物；幼树禁伐。
- 取消、移动离开、暂停恢复、隐藏恢复和场景重入保持合理的动作与余额。倒下后的树位不消失，补生使用同一 slot 的新一代身份；加速检查使用固定模拟状态，不等待现实计时来替代行为断言。
- 桌面、390×844 竖屏与 844×390 横屏中，透明 HUD 保持可读，不遮挡必要操作，面板/摇杆输入不穿透场景。真实手机触控与性能需另有设备证据。
- 对最终组合版本取得固定 seed/相机/状态截图、完整砍伐操作证据及资源/销毁循环检查。模块几何预算和旧 R3 性能数据不能替代当前实机验证。
