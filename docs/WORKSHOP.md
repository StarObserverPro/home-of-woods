# 图纸、木作与摆放（首个可玩切片）

从路线面板可以选择林间行商、营地工作台或林间祭坛；场景中的这些对象也可直接点选。帐篷的详情有工作台入口。

## 玩家流程

行商常备暖木墩图纸，并可能在当天带来稳木墩图纸。每张未学过的图纸暂用一份木料交换；人物须先走到行商身边。当天货物按世界种子和本地游戏日确定，重开面板不会刷新货物。

在祭坛献上一份蘑菇，人物会走到操作位置，祈祷并显示进度。1× 时暂定 1.8 秒；每次完成时有 35% 暖木墩、35% 稳木墩和 30% 仅回应的结果。重复图纸不重复学习，供品仍会消耗。当前不设冷却、日限或保底，概率与成本均是原型参数。

获得图纸后，到帐篷前的粗木工作台制作。人物走到操作点，以临时蹲身姿态完成 3 秒进度；完成时消耗一份未预留木料，得到一件独立家具。碎柴是燃料，不可用于制作或交换图纸。动作中途取消、目标变化或离开操作点不扣材料。

暖木墩和稳木墩使用相同轮廓，分别记录“舒适 2”和“稳固 2”。这些词条本轮仅用于验证同款不同实例，不提供经济增益、制作加速或人物属性效果。家具并不因为外形一样而合并堆叠。

在仓库的“木作家具”中选择摆放，点击地面选择位置，再旋转或确认。绿色预览表示当前位置通过检查，红色预览会给出原因。已摆放的木墩可以移动或收回；实例编号和词条保持不变。还没有实际坐下动作。

## 服务与存档边界

材料继续由 `inventoryTransaction` 结算。独立家具在同一 `inventory.instances` 中持有唯一 `instanceId`、定义、图纸来源、生成时间、词条和位置；`location` 在仓库/世界二者间切换，场景没有第二份所有权数据。

制作和供奉服务构造扣料及奖励候选状态，再同步提交到根 `GameState`；动画、进度条和 UI 不发放奖励。完成后清除任务，重复 tick 不会重复结算。未知物品定义或词条会保留，但不能被当前目录用于制作/摆放。

世界规则版本升至 3，保留布局版本；旧版本 1/2 升级时补充木作与沙漏状态。含实例的库存切片使用格式 3，旧材料切片仍可读取。唯一世界存档继续负责写入，进行中的任务、已学图纸、家具位置和速度一并保存。校验拒绝损坏字段、重复实例和会导致复用物品编号的计数。

## 时间与后续范围

沙漏提供 1×、4×、12×。只有原有世界模拟时间乘速，人物走路仍走原固定步长。动作、资源生命周期和昼夜消费同一时间；关闭页面不补离线收益。显式暂停停止整个循环；打开仓库暂停人物和游戏日历，局部木料仍在同一循环中落稳。日历从原昼夜的 14:00 起点推导，每天 1200 模拟秒、每季暂定 7 天；季节索引已提供，但完整四季美术未在本轮新增。

工作台和固定小凳拥有独立场景身份和一级配置，升级仍为后续功能。新桌面和木墩使用项目原创低面数几何；支撑复用仓库已有 Kenney Nature Kit 的 CC0 原木束，不新增外部运行时下载。

**营地木料物理岛已另行接入本分支。** 原木与枝杈可以从库存搬入局部区域，真实下落、堆叠、休眠和收回；参见 [Woodcraft](WOODCRAFT.md)。本页的家具仍采用静态地面摆放，工作台承托面、家具堆叠与玩家推动没有混入本轮。

## 2026-11-02：实例分级与新存档基线

当前保存基线已改为世界规则 5 / 库存格式 4 / 新数据库 v2；前文规则 3 是该阶段历史记录，不再提供旧档迁移。参见 [世界存档](WORLD_SAVE.md)。

木作完成时按实例身份确定普通、优秀、稀有、史诗、传说五级，初始内容权重为 60/25/10/4/1；这是可调整的初始分布，不是平衡定稿。取消、倍速和读档不重抽下一个实例。等级独立于原料品质 `qualityId`，不改变投入数量和现有舒适/稳固词条值；每件物品明确保存 `rarityId`。

仓库名称、边框、图标框、文字等级和世界详情共用色表。史诗/传说在地图上保持覆盖端面与侧面的柔光，摆放后不自动关闭；预览仍用操作绿/红色，避免把合法性和等级混淆。没有新增完整装备槽、战斗属性或经济加成。后续装备复用同一字段解析与材质入口。

## 2026-11-02：图纸目录与木屋第一阶段修缮

图纸是已掌握的制作与升级知识，可重复使用，不在制作时消耗。树木沿用成长、采伐和物产规则，原料级掉落物沿用采集与搬运规则；设施、家具和其他制成品的制作及升级必须引用对应图纸。新内容把图纸和阶段登记到目录，再由同一个事务入口校验，不能以升级之名绕开图纸或结构木成本。

营地自带「木屋修缮·第一阶段」图纸；已有的规则 5 存档首次读取新增字段时补入该图纸。仓库的图纸标签显示已掌握图纸的来源与用途。暖木墩、稳木墩继续通过行商或供奉获取，修缮图纸不会出现在工作台的家具制作列表中。

第一阶段修补两处屋顶缺口并加固门边支撑，暂需 2 根未预留原木与 3 份未预留枝杈，耗时 4 模拟秒。这些是当前可玩切片的参数；整屋翻修、墙体与其余屋面仍待后续图纸。远处可查看要求并走近，走近只移动人物；到达后再次明确开始修缮，完成时一起扣除材料、记录投入并推进修缮阶段。取消、离开、切换目标或材料不足不扣料；读档和重复更新不会重复结算。

`content/upgrades.ts` 登记营地设施的独立路径，`domain/upgrades.ts` 提供查看、走近、开工和一次结算。木屋首阶段已经开放；帐篷、篝火、原木架、木料围框、工作台、小凳、祭坛与已拥有家具显示各自后续方向及“尚未开放”。升级进度按目标稳定 ID 保存于现有 `workshop.upgrades`，材料账本保留原始批次属性，表现层只读取阶段。没有为尚未开放的升级提前创建独立运行时或经济系统。

领域验证见 `tests/upgrades.test.ts`：远近交互、真实碰撞下的可达路线、图纸/材料校验、分批材料守恒、取消与重复结算、进行中和完成后的存档往返及规则 5 兼容。画面和完整操作验证另随本次 PR 记录。
