# 参数化图纸与装配评分 · 数据层首版

本方案只负责图纸、几何定义、制作评估、成品概率和存档记录。**不实现**虚线引导美术、拖动手工装配、多工序动画、新家具场景模型或复杂关节机械。继续使用既有工作台、库存事务、单一 GameState 与世界存档，不引入第二套物品所有权。

## 与独立物品安装关系的分界

参数化 Assembly 只存在于制作流程里，完成品可简化为一条带 `geometry` 的 `inventory.instances` 记录。其后把一个已完成的门铃、铜壶或其他独立道具安装到宿主上，是 **Mounting/物品去向**；道具仍有单独身份、品质和词条，宿主只提供槽位与触发环境。参见 [独立道具去向与宿主关系](ITEM_DESTINATIONS.md)，这一步不需要恢复制作时每根材料的动态刚体。

## 共同语义

- `ItemDefinition` 描述成品物品的身份和用途；并非所有物品都需要参数化几何。蘑菇、成品食物和一般物件可以完全没有 `geometry`。
- `Blueprint` 是学习与解锁入口；`CraftProfile` 记录配方、制作方法、材料选择、品质档次、几何模板及分步处理模块 ID。
- `GeometryTemplate` 定义合法参数空间和版本。首版为 `solid` 和 `supported-surface`；以后风车的径向重复、木偶和机械运动可各自注册新原型，不污染简单家具。
- `Assembly` 只是制作中的阶段。完成品不保留散件的物理刚体、自由顶点或每根支撑木的独立库存身份；只保存可以确定性重建形状的 `geometry: {templateId,version,family,parameters}`。
- `CraftOutcome` 是可替换制作动作模块与库存结算之间的接口。只有经过几何参数验证、装配合法性评估和等级摇号后才可创建新的物品实例。

## 图纸档次、工艺成绩和成品稀有度

图纸的 `rarityTier` 是**基础档次与概率范围**，不是成品的最终稀有度。首版表见 `BLUEPRINT_QUALITY_BANDS`：普通图纸只允许普通与优秀；稀有图纸大概率为稀有，但小概率出优秀、史诗、传说。分布参数是候选值，待玩法测试后调整。

玩家装配的评分范围为 0–100，使用尺寸/支撑的几何引导点和角度偏差：超过硬容差直接失败，不允许结算；容差内偏差越大，评分越低。被认可的低分组装仍然有小概率得到传说级产品，只要该图纸本来允许传说。对于禁止的等级，概率权重严格为零，无法通过工艺分数突破上限。

等级概率 = 图纸档次的基础权重 × 随评分变化的正数权重，再归一化。由于正数因子不会把非零概率压成零，运气始终保留；同时硬上限绝不被破坏。结果使用世界种子、成品流水号、图纸 ID 确定性抽取；取消、暂停、倍速、查看、读档不增加抽取次数。**工艺评分与最终稀有度是两个字段**，不会把巧合的传说装备错误记为装配精度极高。

参考方向：[Albion Online 官方制作与专精说明](https://albiononline.com/news/guide-crafting)、[FFXIV 官方木工制作与 HQ 质量说明](https://na.finalfantasyxiv.com/crafting_gathering_guide/carpenter/)。本项目的概率权重和上限并非复制任何游戏的具体数值。

## 两类几何与虚线引导接口

- `solid/stump.round`：直径、高度与轮廓选择。工作台现有的暖木墩和稳木墩已接入，沿用当前 3 秒预设动作与一份合格木料输入。**因为没有手工动作，质量来源明确标注 `preset-neutral`，概率计算使用中性分数 50，不伪造玩家评分。**
- `supported-surface/bench.supported`：长度、宽度、高度、面厚、支撑数量与内缩距离。系统自动对称排列支撑，重建承托面和碰撞代理；不在物品中保存每一条桌腿的位置。通过 `assemblyGuides` 输出每个必要接点的目标姿态与硬容差，供未来虚线或吸附 UI 使用。可做小偏差、低评分、高误差不可结算的纯业务测试。
- `blueprint.bench-guided` 仅登记为 `planned` 的蓝色图纸示例，不加入玩家图纸掉落、行商供应和制作菜单，避免未完成的交互冒充可玩功能。
- 木作切割、涂漆、手动拼接与进度/动作系统由 `CraftProfile.steps[].moduleId` 后续接入。此 PR 只创建抽象接口，不添加颜料道具或宣称能购买涂料。

## 保存、所有权和兼容边界

成品沿用现有 `inventory.instances`、`instanceId`、`definitionId`、`blueprintId`、`rarityId`、`traits`、`location`；新增可选 `geometry` 与 `crafting` 元数据。不改 `InventoryStack`、`WoodcraftState`、世界规则或仓库写入者。现有的高等级光效继续根据成品 `rarityId`，不会因为低档图纸得到高等级装备而变成另外一套稀有度。

`geometry.version` 是生成器的语义版本。新客户端不能以新模板默认参数重建不认识的旧版模型：应保留未知原始 JSON、报告无法重建，必要时使用保守外观占位，不能静默修改旧成品。更大范围的兼容与几何运行时呈现留待后续视觉接入；本轮存档仅保存和往返已登记的几何参数。

## 验收范围

`tests/parametric-crafting.test.ts` 覆盖：档次上限、低分仍有非零幸运概率、评分改善概率分布、决定性抽取、参数版本与量化、对称支撑生成、小偏差合格、大偏差失败、错误装配不能完成结算、默认木墩经既有工作台生成物品以及整档存读。旧等级生成器保留供现有数据兼容测试，但新制作路径已改为图纸权重。

禁止把这些数据单测称为真实木作物理操作验证：虚线引导和物理装配 UI 仍是后续独立任务。
