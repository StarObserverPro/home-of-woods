# 营地木料堆：Woodcraft 物理岛

2026-11-06：木料堆按原木、枝杈、碎柴分别展示“堆中 / 营地 / 随身”数量，库存与堆中单件不重复计数。碎柴改为带浅色劈裂面的短碎块；可见凸包与物理碰撞共用轮廓。仓库的“木料堆”页采用各自图标，待释放的物品也计入堆中。修正范围与验证见 [本轮记录](scopes/wood-materials-and-grain-preview.md)。

2026-11-05 取放修复：物品→随身中的原木、枝杈、碎柴均提供明确的“走近木料区投放／投放到木料区”；可直接从随身批次投放，无需先扔地上或存入仓库。原木另有“放入原木架”的逐项入库入口，架旁目标卡可一键存入随身材料。容量为围框内最多 32 件（含待落下队列），不因还有排队木料而禁用下一次投放；原木架的 18 根仅为陈列上限，营地仓库当前不限量。范围与本轮验证见 [取放与晾晒 scope](scopes/material-storage-drying-fix.md)。

在 PR #7 木作/库存基础上建立局部物理岛，不改全地图。当前入口是仓库或「路线 → 营地木料堆」；进入只走近和查看，不自动转移库存。走近后可从仓库拖出指定批次的一根原木/枝杈，松手放进围框；地上木料可拖回仓库。支持“全部放入 / 全部收回仓库”，单根手动投放仍保留。完整约定见 [营地交互](CAMP_INTERACTIONS.md)。

新档没有材料时不会赠送样品。当前“全部放入”同时接受随身与营地的可投放木料，最多填满 32 个位置；超出部分留在原位置。碎柴可收纳并保持燃料身份，不会变成可制作的枝杈。预留木料、未知品质、地面尚未拿起的材料与蘑菇不参与投放。重进场景/读档不会自动搬空库存；批量搬运始终由明确按钮发起。

## 接触与范围

木料区位于营地东侧的平坦空地，中心 (-29, 7)，围框内约 6 × 5 个世界单位。矮木边框有可见几何和对应的固定碰撞体。地表碰撞复用 world/surface 的同一 2 单位三角网格；没有另垫一层隐形平地。原树林、工作台、角色和树木采伐仍走原机制。

碎柴使用短劈裂块凸包，碎柴自身采用较高阻尼减少细小接触抖动；原木和枝条使用与可见九边形圆柱一致的凸包；Y 形枝杈把两个凸包挂在同一刚体上，保留枝杈之间的空隙。该轮没有采用光滑数学圆柱，因为实测稀疏木料会持续微滚。出生点与初始朝向只规定投放意图，最后的 XYZ 和四元数由重力、接触、摩擦及休眠求解，不按堆层指定坐标。

材质规格完整保存；当前模型是适配玩具比例和小木料区的有界外观代理，不声称与库存毫米规格等比例。没有规格的旧材料使用默认轮廓，不伪造其原始尺寸。

## 所有权与时钟

`inventory.stacks` 按位置持有在库、随身及地面材料，`GameState.woodcraft.pieces` 独占已投放的单件材料；同一件不会同时出现在两处。投放先构造完整库存候选，再同步提交扣料和对应实体，队列中的物品也已从库存移出，随身负重同时卸下。收回统一进入营地，恢复 itemId、qualityId、wood spec、measureId 等原始字段，重复收回无效。围框中的木料需先收回，才能用于制作。

既有 `inventory.instances` 家具身份不改。Rapier 内部刚体只是由领域数据重建的运行时缓存；场景只读位置/朝向，不结算材料，也不另建存档。队列、来源、三维位置、四元数、线/角速度、休眠状态和递增 ID 计数统一保存。世界规则升至 4，接入旧规则 1/2/3；损坏及未来格式保留原字节。

物理使用既有 app 固定步长 1/60 秒，但不乘沙漏速度。1×/4×/12× 只影响原有世界时间，木头不会加速十二倍。仓库打开时人物和游戏日历暂停，局部木料仍可落稳；显式暂停、后台隐藏和图形上下文丢失会停止整个既有循环，不补算离线下落。

距离物理岛 18 单位以内可按需加载，有 24 单位卸载边界。离开时保留最后姿态与速度，释放刚体世界；回来再恢复。静止刚体自动休眠，全部休眠后跳过求解步骤。收回支撑物时唤醒岛内剩余刚体。越过有限地表或出现无效模拟结果时，尝试将对应木料原样收回；模块异常则停下模拟并保留物品，不让整个游戏循环崩溃。

## 依赖和成本

运行时锁定 `@dimforge/rapier3d-compat` 0.21.0，Apache-2.0；随生产包附完整许可。WASM 包含在本地按需 JS chunk 中，不从 CDN 初始化。首版生产构建该 chunk 约 4.34 MB，gzip 约 1.67 MB；进入普通森林不会请求它，首次使用木料区才加载。这里的「轻量」是局部作用域和有限刚体预算，不代表依赖下载为零。主包既有大 chunk 警告未提高阈值或隐藏。

每岛最多 32 件、每件最多两个凸包。该值是原型容量，不是手机性能承诺。仓库拖拽负责取放，不是在求解器内连续拉动刚体。尚未接入工作台承托面、家具/工具物理、玩家推动、手部投掷动画、全地图地形刚体或柔体；后续沿用物品事务和物理区接口扩展。

实际检查与边界见 [WOODCRAFT_VERIFICATION](WOODCRAFT_VERIFICATION.md)。回退须先导出规则 4 存档；旧客户端不能覆盖规则 4 数据。撤回本 PR 不改 PR #7 的木作功能。
