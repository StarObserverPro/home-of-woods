## 1. 选择顺序与授权

优先选择 **CC0 等免费资源**，经统一修整后成批接入。优先级为：适配的 CC0/可确认公有领域资源 → 允许修改与公开分发的其他免费许可资源 → 有针对性的自制或获准工具生成。

候选必须核对具体资源包、版本、作者、来源和实际许可文件，而非仅看网站首页、免费标签或旧 FAQ。分别确认：获取成本、修改权、游戏使用权、公开仓库再分发权，以及必要署名。付费素材、新订阅或额外付费额度须另行授权；允许使用工具不等于购买授权。

- CC0 可用于复制、修改和分发等用途；仍检查第三方商标、人物肖像等独立权利，不宣称资源作者为项目背书。见 [CC0 官方说明](https://creativecommons.org/publicdomain/zero/1.0/)。
- CC BY 等免费许可可按具体条件采用，并保留作者、来源、许可、修改说明及要求的其他通知。见 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。带额外义务的许可单独审查，不自动混入项目统一许可。
- 来源不明、NC/ND 与当前用途不兼容、仅限特定引擎、禁止独立再分发或无法证明可公开入库的文件，不进入运行时或公开素材目录；选择可替代资源。
- 原资源许可证与项目代码许可证分别保留。修整、重绘或生成处理不自动清除原输入的授权义务，不能统一改标 CC0。

## 3. Midjourney：设计稿

允许用于山谷构图、配色、角色、建筑、季节和道具设计稿。先按 ART_HUD 给出同一风格与比例需求，再选择方向；记录模型版本、用途、简要生成信息、输入来源和实际账号适用的输出条件，不上传私人资料或无权处理的参考图。

使用官方允许的操作方式；本项目不预设第三方非官方 API 或脚本自动化。实际使用时核验 [条款](https://docs.midjourney.com/hc/en-us/articles/32083055291277-Terms-of-Service) 与 [使用说明](https://docs.midjourney.com/hc/en-us/articles/27870375276557-Using-Images-Videos-Commercially)。生成稿不自动标为 CC0。

设计稿用于审稿和模型修整方向；不能代替独立模型、碰撞、动作或实机截图。纳入仓库前同样检查输出权利及输入素材约束。本轮实际沿用用户已登录页面，比较少量 Draft 候选，使用屋顶局部蒙版、清晰度编辑与 Reframe 扩图；采用和淘汰分别登记在 R3 PIPELINE。用户指定最多每分钟提交一次、优先 Draft；局部编辑输出按实际模式记录，不把所有 Edit 都称为 Draft。后续继续遵循这项频率和用量约束。

## 4. Marble 2：场景建立与交互原型

允许用于山谷空间建立、场景构图、可漫游空间与交互试验。具体操作与导出能力按账号当时已开放的接口执行，不把通用 Marble 功能、预览能力或不同版本能力当作本账号已具备。

实际使用前核验 [Marble 2 文档](https://marble5.worldlabs.ai/docs/quickstart)、[API 能力](https://marble5.worldlabs.ai/docs/api-reference) 与 [World Labs 条款](https://docs.worldlabs.ai/terms-of-service)。工具权限、导出权利、公开入库/发布条件和成本记录在资源条目，不在仓库写入密钥、签名 URL 或账号身份。本轮实际完成 Atlas 图像转配对 RGBD、平移视图、三视图 Draft splat 和局部网格提取；扩展视图失败及有界重试已如实登记。大角度视图存在缺面和漂浮斑块，整景网格不可分离，均未作为整块经营区接入。

导入后统一坐标、尺度、材质、地表与碰撞；把可经营树、巨木资源点、可修缮建筑、道路和交互锚点接入本项目 world/domain。交互动作转成现有命令，库存、时间、额度、再生与存档仍由本地游戏拥有。

整景 splat、贴图或不可拆模型仅作经过审查的景观候选。可采伐树和修缮建筑必须是独立实体，不以整景烘焙替代。生成服务不成为运行时必需依赖；不得用外部漫游演示替代本游戏交互验收。

## 5. 一个可见功能包的流程

1. **候选与授权**：围绕阶段列出少量候选；核对具体许可、输入权利、公开分发和成本，在 ASSET_REGISTER 建记录。未通过前只保留合法的来源信息，不把文件提交公开仓库。
2. **统一修整**：在 Blender 或等价工具中统一轴向、尺度/枢轴、轮廓、法线、材质/色板、UV、纹理大小、骨骼/动画、LOD、碰撞与命中体。移除未用节点、材质和高频写实细节，按 ART_HUD 调整成同一套玩具风格。
3. **可复现导出**：优先 GLB/glTF；记录源包版本/校验值、使用部件、修整摘要、导出工具/版本/设置、产物校验值。需要的源文件在许可允许且体量合理时保留；不能只留下无法追溯的导出结果。
4. **成批接入**：同一体验所需模型、材质、动画、状态映射、导入缓存、碰撞/拾取和 UI 图标在同一批次接入。只包含使用到的文件，按需加载，不把全素材库和实验输出打进游戏。
5. **实机验收**：固定 seed/视角/状态检查整体比例、光照、季节/成长切换、动作、碰撞/命中、手机可读性、性能与资源释放。记录当前提交证据，旧试稿不得代替。
6. **登记与交付**：更新资产状态、运行时路径、署名/许可证和证据；本批通过后才记为 integrated/verified。概念稿可 approved-for-reference，不能标为运行时已集成。

建议批次：家园与邻近林地（M0）；修屋工具、材料与动作（M1）；四季、行商与扩建（M2）。批次可调整，资产与交互必须共同收口。
