# 营地取放、图纸与第一阶段修缮

2026-11-05：远处设施统一一个走近入口，改造要求按需展开，营地路线快捷入口统一只查看；详见 [HUD 与操作路径](HUD_INTERACTION.md)。

本轮基于 main `b670911`，调整仓库、物理木料堆、原木架、家具与营地设施的操作，并接通木屋第一阶段修缮。代码提交、合并与发布分别记录；本轮不是完整 M1 验收。

## 操作规则

远处点选只查看信息，操作区先提供“走近”。走近不消耗材料、不自动制作，也不自动搬空库存。到达后才显示取放、交换、制作或修缮；缺材料、缺图纸、容量已满等条件在近处解释并禁用相应操作。原木架查看唯一库存，散放原木与枝杈仍进入营地木料堆。

仓库使用能露出场景的侧栏，手机使用下半屏面板。材料卡可以拖进木料区，地上的单根木料可以拖回仓库；附近木料卡和“收回”按钮提供同样的回收入口。家具也能从仓库拖到人物附近的有效空地，或先走近已摆放家具再移动、收回。点击投放、摆放确认和批量“搬入木料，留一根”继续保留。

按住后移动超过拖拽阈值才进入拖动。松手时重新检查距离、当前物品、批次、数量、预留、容量与位置；之前不转移所有权。无效落点、取消、失焦和触控中断不扣料。材料拖拽携带完整堆叠 key，不能以同名物品的另一批材料替代。打开仓库会取消未提交的点击投放/摆放草稿，避免场景残留输入模式。

仓库打开期间，人物与游戏日历暂停；同一个主循环仍允许附近木料落稳，不另开时钟或 RAF。显式暂停、后台隐藏和 WebGL 上下文丢失仍停下整个循环。远处走向空木料区时保留初始化意图，到达加载范围后准备物理模块。

## 图纸与升级

仓库增加“图纸”标签，统一展示已获得的图纸、用途和来源，以及已登记但未获得的图纸。图纸代表已学会的方法，使用时不销毁。树木沿自然成长和林业路径演进；原料级掉落物可以直接采集和搬运。其他制作或改造都通过含图纸 ID 的配方/升级路径完成。

设施和物品原则上可以继续改良，不同对象拥有各自路径。当前登记木屋、帐篷、篝火、原木架、木料围框、工作台、小凳、祭坛与已拥有家具；未开放的路径明确展示方向，不假装已有数值收益。

首张「木屋修缮·第一阶段」随营地提供，已有有效规则 5 存档会安全补入。当前原型成本为原木 2 根、枝杈 3 份，耗时 4 模拟秒。人物须走到屋前操作点，明确开始后才施工；完成前取消不扣材料。完成时一次提交扣料、原批次投入账本、已完成路径和阶段。模型在两坡各补一块屋顶板，门边增加两根支撑；其余缺口保留，整屋翻修仍需后续图纸。
