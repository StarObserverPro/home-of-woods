# 森林之家 · Home of Woods

单人林场经营、自由造景与木作制作相结合的轻度 RPG。住在山间帐篷里，修复身旁的残破木屋；巡林采集、有限采伐、原位补生，再把家园慢慢扩建起来。

**这是可操纵角色的森林生活游戏。** 场景是主界面，采用 low-poly、圆润 Q 版和柔和的塑料玩具质感。没有耕地、普通作物和每日浇水收菜循环。

## 第一段可玩体验

家在大山的针阔混交带。宅后可以登高一小段，继续向上的山体暂作景观；主要经营路线向下穿过林地、溪谷，到达对面小山。周围群山形成开阔的完整景观，详细模拟分阶段开放。

**帐篷与破屋 → 收集枝杈 → 轻型修缮 → 即时规则审批与限额采伐 → 加工结构木 → 修好木屋 → 种树、造景与扩建。**

M0 建立可行走的山谷；M1 完成修屋闭环和存档；M2 接通四季、跨年、盖亚、行商与持续经营。各阶段都按新基线验收，不能用旧图或孤立设计稿代替实机结果。

美工与建模优先寻找许可适合公开仓库的 CC0 等免费资源，统一修整后连同交互、碰撞、材质和资源登记成批接入。Marble 2 可用于场景建立与交互原型，Midjourney 可用于设计稿；工具输出通过同一资产准入与实机验收流程。
