## 溪流东岸扩区

本轮功能分支接通跨溪木桥与东岸经营林：营地自带桥梁图纸，投入 4 根已收运原木和 3 份枝杈后在桥头施工。桥建成才可步行跨河，东岸提供树木、枝杈、蘑菇和地面碎柴，不增加第二营地。

未收运的采伐木料只拦其来源林区；搬过桥或中途放下不改变归属，全部入库才解除。两岸的收运限制分别判断，年度采伐额度仍共用原账本。近身树木和采集命中随区块加载，远处使用共享简化实例；女神初始覆盖仍限营地。实现、验证和边界见 [地图扩展](docs/WORLD_EXPANSION.md)。本轮不包含合并或发布。

## 第一段可玩体验

家在大山的针阔混交带。宅后可以登高一小段，继续向上的山体暂作景观；主要经营路线向下穿过林地、溪谷，到达对面小山。周围群山形成开阔的完整景观，详细模拟分阶段开放。

**帐篷与破屋 → 收集枝杈 → 轻型修缮 → 即时规则审批与限额采伐 → 加工结构木 → 修好木屋 → 种树、造景与扩建。**

M0 建立可行走的山谷；M1 完成修屋闭环和存档；M2 接通四季、跨年、盖亚、行商与持续经营。各阶段都按新基线验收，不能用旧图或孤立设计稿代替实机结果。

美工与建模优先寻找许可适合公开仓库的 CC0 等免费资源，统一修整后连同交互、碰撞、材质和资源登记成批接入。Marble 2 可用于场景建立与交互原型，Midjourney 可用于设计稿；工具输出通过同一资产准入与实机验收流程。

### Windows 固定本地入口

访问 http://127.0.0.1:5286/ ，或双击项目根目录的 `打开森林之家.cmd`。本机任务 `HomeOfWoods-Local-5286` 登录后通过无窗口启动器 `tools/run-local.vbs` 启动 `tools/serve-local.ps1`；游戏子进程退出后 10 秒重试，整项后台任务停止后由每分钟触发器重新启动（另需冷启动时间）。仅在当前用户已登录期间运行。只监听本机，使用互斥锁避免重复启动，端口冲突时等待，不结束其它项目进程。日志位于忽略提交的 `.cache/local-server/server.log`，超过 5 MB 时保留一份上一轮日志。

此地址直接运行当前工作树，源码修改自动更新。电脑关机或睡眠期间不可访问，恢复后可刷新；重启登录后自动恢复。需要永久停用常驻时，先在 Windows 任务计划程序中禁用 `HomeOfWoods-Local-5286` 并结束该任务。任务注册属于本机设置，克隆仓库不会自动注册。

浏览器存档按地址隔离；旧 5173 端口的存档不会自动显示在 5286 下，旧档可在旧入口导出后另行处理。
