# 林相观察沙盒

入口：在本目录运行 `npm install`，然后 `npm run dev`，打开终端给出的地址。也可以在项目根目录执行 `npx vite sandbox/tree-variation --host 127.0.0.1`（需要已安装依赖）。

固定种子样区展示高处松林与溪谷混交，以及每棵树稳定的色彩、比例、冠形与倾斜。按钮切换观察位置；拖动和双指可改变镜头。林相按样区高度平滑控制比例，属艺术方向实验。

当前树木由本沙盒程序生成；早期试验曾参照项目原有的两种树木模型，当前入口不加载这些模型。本样区无玩法、碰撞、存档或真实地理模拟，不改主体。后续接入须另经用户指示，并重新处理物种、个体持久化、碰撞及动画衔接。

第二轮：在原有两种网格上构造圆冠与窄冠针叶、舒展与浅树皮窄冠阔叶四种视觉树形。树形对照按钮可单独观看；它们是造型方向，不代表已完成四个真实物种模型或正式物种生态。

第三轮：以程序网格绘制松、云杉、冷杉、栎、桦、杨、榆七种属级代表树形，并按高度、距溪距离及开阔程度混合。SPF 的三个名称分别呈现；这里是设计原型，树种的具体地域和栖境尚未选定。

参考：美国林务局 [纸桦](https://research.fs.usda.gov/silvics/paper-birch)、[美洲榆](https://research.fs.usda.gov/silvics/american-elm)、[黑棉杨](https://research.fs.usda.gov/silvics/black-cottonwood)、[树木识别图鉴](https://www.fs.usda.gov/Internet/FSE_DOCUMENTS/fsm9_021378.pdf)。参考具体树种只为建立可能的生境和形态方向，并非把不同地域自然分布认作同一林区。

第四轮：重做树干和枝架，增加鹅掌楸与杨树近距离对照。杨树使用窄冠直立型造型；鹅掌楸以长净干、高位较宽树冠为造型参考。树形受具体物种、林龄、林分密度影响；参照 [鹅掌楸林木形态](https://research.fs.usda.gov/feis/species-reviews/lirtul) 和 [杨树林内外形态](https://research.fs.usda.gov/feis/species-reviews/popdel)。沙盒为概念造型，并非地域物种分布复原。

第五轮：杨和鹅掌楸树冠使用固定个体种子的连续起伏网格，枝干逐级收细、分枝进入树冠；“查看枝架”可隐藏阔叶及松树冠，观察分枝结构。其余树种沿用前轮造型。

第六轮：其余阔叶树及松树枝冠加入按个体固定的连续起伏；松树另调整树干弯曲、分枝位置和针叶团的宽高。杨与鹅掌楸保持第五轮形态。

## 验收状态（2026-10-30）

用户认可本轮沙盒效果。当前交付是独立可运行的树形与林相样区，尚未回接游戏主体；采伐、碰撞、生命周期、持久化及移动端真实性能仍需在未来接入时单独设计和验证。已运行 Vite 构建，并在浏览器中查看样区、树形及枝架切换；没有记录完整的手机实机操作或性能验证。
