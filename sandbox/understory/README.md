# 林下形态沙盒
运行：在仓库根执行 `node node_modules/vite/bin/vite.js sandbox/understory --host 127.0.0.1 --port 5182`。
全部形态为本轮程序生成，无第三方美术资产；Three.js 使用现有安装库（MIT）。不依赖游戏运行时或存档。
标准密度浏览器主通道实测：阴凉林下 13 calls / 77128 triangles；林缘空地 13 / 38712；溪谷缓坡 14 / 74264。固定 seed 731，DPR 1.25。无贴图资产，renderer 显示 1 个内部纹理。
共享实例批次、DPR 上限 1.5、静止按需渲染、轻量密度 55%；无实时阴影/反射/后处理。三组均低于预设 100k 三角形和 40 calls。
已检查三组桌面画面、切换与生产构建。真实手机帧率、窄屏及触控、长期资源释放未验证。当前是形态样片，背景树为比例陪衬，朽木断口和植被接地仍可继续精修。未经用户批准不回接主体。

## 第二轮精修
按用户要求继续独立，暂不回接。蕨类改为三处可见树冠附近的紧密群落，无遮蔽中央空地不生成蕨类；灌木改为单一不对称低多边形体块；石头改为扁棱角网格；朽木增加不齐端部、暗色端面与断枝；落叶使用折起的非对称薄片并在树下聚集。窄屏增加相机视野。
本轮主通道实际计数：阴凉林下 83688 triangles / 15 calls，林缘空地 51450 / 15，溪谷缓坡 77100 / 16。仍低于原定预算，未增加实时阴影或后处理。构建通过；已观察阴凉和溪谷窄屏画面及三组计数；真实手机性能未测。前文数值属第一轮。

## 第三轮：遮罩与带状草
树冠显示与投影遮罩使用同一组椭圆参数，重叠覆盖累计；遮罩 >= 0.42 才允许放蕨，连续场控制密度与尺度，边缘更低更疏。该值为设计参数而非真实光照测量。标准固定 seed 每组 56 株。
草为本轮原创五片弯曲带状叶合并网格，每簇 25 三角形，通过 InstancedMesh 单批次绘制；无透明纹理。只读核对了既有温室近景的单三角草叶实例化方法及本项目远景树合并后实例化方法，未导入其他项目代码/资产。
本轮标准密度主通道：阴凉林下 60580 / 15 calls；林缘空地 60260 / 15；溪谷缓坡 59443 / 16。已看窄屏整体画面、切换三组统计；真实手机 GPU 帧耗未测。保留独立沙盒。
