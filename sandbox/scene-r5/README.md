# 溪光与营火 · R5 独立场景沙盒

本轮以当前已审查的山谷、采集、角色、统一库存作为独立快照，优化场景并提供观察入口。本目录保持独立运行；选定模块的主体回接另见 [R5 回接记录](../../docs/scopes/scene-r5-integration.md)。本轮合批提交保留沙盒与证据，未合并或发布。

当前为 **R5c**：溪流、火焰、崖顶交界和祭坛下半部保留已接受版本；崖面内部增加少量真实碎面，祭坛上部改为悬浮裂石环与发光种核。前沿三格陈列供品，右上方悬浮可点读神谕。详见 [R5c 验证](VERIFICATION-R5C.md)；[R5b](VERIFICATION-R5B.md) 保留为上一轮记录。

## 查看与运行

离线审看包为 [review.html](review.html)，内嵌实际使用的 10 个运行时资产，不依赖开发服务器。浏览器工具限制 file 协议，本轮尚未自动验证双击打开；临时开发入口 [http://127.0.0.1:4215/](http://127.0.0.1:4215/) 已实机检查，验收后关闭服务器。右上九个观察位置；“祭品与神谕”适合查看上部。左下可切昼夜、篝火、原木数量、祭坛四状态和空盘/林产/林产＋木料，或关闭倒影。点选道具查看状态，点击悬浮纸页读取全文。WASD/点地移动，拖动旋转，滚轮缩放。

```powershell
Set-Location sandbox/scene-r5
npm.cmd ci
npm.cmd run dev
```

重新制作离线页：`npm.cmd run build` 后运行 `node export-review.mjs`。离线页保留原素材许可，可在浏览器直接导出画面；开发入口另保存画面与运行数据到本沙盒 evidence。

自己的 package/lock、src、public、构建输出和状态都在此目录，不导入父项目源码，不使用符号链接。此次本地检查由 Node 22 与当前安装的相同锁定版本解析依赖；复制到独立目录后按 lock 安装即可运行。

## 本轮内容

- 河道保留既有几何事实，加入低分辨率平面倒影、波纹扰动、碎光、绕石白沫和低面水滴；单目标、无额外阴影，手机降为 256²。
- 陡崖使用较大三角平面与逐面光照，R5c 在内部稀疏增加 166 处浅碎面；共享三角形边和已接受的崖顶保持。路面保留柔和边缘、中心磨损和微量碎石色差。
- 近处 ±90m 地表以 2m 网格为基础，沿崖顶精确切边；外圈逐级减点，侧壁与底面闭合。R5c 总三角形 19,896，比 R5b 增加 332，仍低于原有 23,000 上限；草地和石壁法线分开。可见地表与高程查询使用同一套碎面。
- 篝火有石圈、焦木、炭火、13 条曲面火舌、半透明外焰、发光亮芯、局部辉光、火星、烟与夜间局部照明；可熄灭。
- 原木架响应统一库存所有品质堆叠的 `wood` 总量，0–18 根逐根表现，更多库存仍有准确读数；不持有第二份库存、不修改额度。
- 祭坛保留顺坡埋地石基与水平台阶；上部有七块悬浮环石、种核、光轨和回应粒子。前沿三格供盘实际陈列蘑菇、枝条、小原木；神谕在右上方悬浮，内容随四状态更新，点击纸页显示可读文字。上部 2,910 三角形，一张按状态更新的 512×640 文字纹理，无全屏后处理。

昼夜是沙盒状态与唯一应用时钟上的表现预览，未接季年经济。祭坛不消费供品、不发祈愿奖励；篝火未接燃料经济。库存按钮是明确的沙盒设定入口。完整存档沿用原范围，未在本轮添加。
