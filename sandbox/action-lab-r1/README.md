## 本轮实现

| 动作 | 时长 | 可见内容 |
| --- | --- | --- |
| 伐断 | 7 秒 | 最后两斧、切口缺口、木屑、短纤维牵连、先慢后快的倾倒、断开并滑离根桩、木质接地、树冠压缩与余振、倒木停留 |
| 抱树 | 8 秒 | 双手攀附、抬脚、向上蹬一步；镜头拉远时把短段上移藏入树冠遮挡，枝叶晃动/落叶；回落到树下 |
| 采菇 | 5 秒 | 屈膝俯身，左/右手轮流伸取，收手起身；简化双拳式手型，无逐指抓握 |
| 祈祷 | 5.5 秒 | 胸前合拢双手、低头停留、柔和祭坛回应、放手 |

动作按用户要求做到姿态和意思可辨，尚未精修手指、所有镜头下的肢体轮廓或真实树种攀爬能力。树冠压缩是风格化表现；树脂、采果、奖励等玩法不在这里产生。

### 树干局部替代

`src/tree.js` 保留原树的树冠、分枝和 1.65m 以上实际树干三角形；1.65m 以下为本轮程序生成的树根/树桩、切口段和倒伏段。替代段顶端采样原树干截面，沿用原树皮色；两种树共用相同算法。

切口在 .88m：浅色木心、少量年轮、方向性缺口和粗断茬。缺口对应被砍去的楔形部分，其余两侧共用截面形状。开始以切口附近支点倾转；纤维拉断后叠加连续位移脱离树桩。最终根据木质网格与同一斜面求落地角度，树冠作为软体压缩到地面之上，不再用整团树叶把倒木撑成站姿。

`src/actor.js` 用现有 KayKit 骨架基姿和短接触求解，双手跟随同一刚性斧柄，斧刃落在同一切口高度。`src/motion.js` 集中时间和过渡，`src/world.js` 管理展示地台/祭坛/粒子，`src/main.js` 是唯一循环和时间源。暂停与反向拖动均直接重采样，不累积骨骼或树冠变形。没有主体模块 import。

## R2 隔离修整（2026-10-30）

- 中等树形：切口处直径约 0.50m（松）/0.56m（阔叶），上部模型按比例收窄。切口高度仍为 0.88m。
- 照片对照见 [REFERENCES](REFERENCES.md)。断面改为较平的木心、浅色边材、树皮外缘和偏心细年轮，短纤维集中在连接带；根部改为渐变外扩，删除独立锥形根刺。保留低面风格，尚非写实树皮或逐纤维破坏。
- 放树方向可选东/北/西/南，缺口、支点、人物、撤步与木屑一起转向；坡面留在固定世界方向。顺坡、逆坡、横坡分别求接地。减小木质反弹，增加短促镜头震动，树冠保留余振与软压缩。
- 抱树增加先抬腿、蹬伸、另一脚跟上的两阶段动作；侧面镜头显示脚与树干关系。采菇从斜前方转至背后，保持至采摘结束。
- R2 验证：6 组测试通过，包含两树种×四倒向的固定坡面接地；构建通过，仍有单包 >500kB 提示。桌面实际切换和拖时刻检查断口、横坡、抱树、采菇；390×844 视口检查断口和采菇，无真实手机性能测试。截图在 evidence/r2，当前构建源码哈希在 evidence/source-snapshot.json。原版离线页保留在 archive/r1-review.html。
- 所有改动继续留在沙盒及范围文档；没有主线接入、PR、合并或发布。等待用户评价断口与重量感，再继续隔离打磨。
