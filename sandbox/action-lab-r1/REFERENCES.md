# R2 伐断照片对照

2026-10-30。用户未指定照片，明确允许搜索公开伐木照片；本轮实际在浏览器观察以下两张实拍。照片只作形态依据，不下载、不嵌入纹理、不打包进审看页，也不声称取得重新分发许可。

- [TCI Magazine / Advanced Felling Techniques，低桩照片](https://tcimag.tcia.org/training/arboriculture-best-practices/advanced-felling-techniques/)（2024-12-01，Matthew Meckley 提供）：低桩，主要切面近乎平整，薄纤维集中在木质连接带的一侧；边缘有真实树皮厚度，基部渐变为不规则根张，年轮不呈放射星形。
- 同文 Humboldt 缺口照片：斜切缺口具有明确方向；上下切面围绕同一剩余连接带组织，未切断前不是整圈张开。该照片为链锯伐切；本沙盒用其结构关系，斧砍表面保留较粗的分面，不冒充链锯操作模拟。
- [Husqvarna / Understanding directional felling](https://www.husqvarna.com/in/learn-and-discover/chainsaw-academy/basic-tree-felling/understanding-directional-felling/)：作为方向关系的辅助文字依据；连接带引导倾倒，缺口合拢后分离。

本轮提取到程序模型的特征：不规则浅椭圆木心、浅色边材/较深树皮外缘、少量偏心细年轮、集中式纵向撕裂带、低矮且渐变的根张。所有新网格/颜色/纹理为本沙盒原创，不复制照片像素。

树干规格按游戏角色尺度选为约 0.50–0.56m 直径（切口处）；这是本游戏“中等、不超过合抱”的表现选型，不是由照片测量出的实物尺寸。倒向同时控制切口、木质连接带、人物站位/撤步、尘屑与落地求解。
