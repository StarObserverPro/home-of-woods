2026-10-30。用户接受 R5c 祭坛与碎石密度，要求加白昼熄灭炭头、增强随机碎面后直接回接。现已接入本地 `codex/gathering-sources` 的主体源码；没有覆盖既有角色、采集、库存或完整存档。本轮已纳入合批提交，未合并或部署。

## 实现

- 溪流沿用已接受的倒影、碎光、绕石白沫和水滴。单个 512²/256² 目标，每 3/4 帧有界更新，不重复阴影。
- 地形沿实际崖沿切边，石/草法线分开，远处减点，侧壁与底部真实封闭。166 处碎面密度不变，插点的三个重心权重独立变化，深浅和正负起伏分别取样；16–36cm 左右的法向起伏更易辨认。固定坐标哈希保证重开不重抽，总计 19,896 三角形，23,000 上限未提高。
- 白昼篝火为灰黑焦木、十个低面炭头和灰烬端环，无火舌/烟/火星/辉光/局部照明；夜间恢复已接受的半透明外焰、亮芯、辉光与照明。13 条火舌仍为 2,808 三角形/3 次绘制。
- 原木架从统一库存各品质的 wood 总量派生，0–18 根逐根表现，超过部分保留准确读数。场景不扣/发原木。
- 祭坛保留下部顺坡石基与水平台阶，上部为七块悬浮环石、种核与细光轨。前沿三格供盘，纸页在右上方可点读；上部 37 网格、2,910 三角形、一张按状态更新的 512×640 纹理。正常模式供盘为空；四状态和供品示例在检视中呈现，正式供奉/奖励仍待 M2。

正常入口 `npm.cmd run dev`；`?inspect=1` 的“运行检查 → 场景检视”提供九个固定相机、昼夜与祭坛示例。检视暂停模拟并借用当前相机，结束/复位恢复角色跟随；正常操作不使用沙盒的固定相机 UI。视觉昼夜从 GameState.time 派生（候选 1,200 秒/日，起始 14:00），不是第二套时钟或正式日历。
