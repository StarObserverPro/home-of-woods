# 动物第一阶段证据

本批为 `feat/wildlife-phase1` 的松鼠/野兔接入，不代表鹿、鸟群、音效、互动或 M1/M2 完成。

- `asset-normalization.json`：原始文件 SHA、实际骨骼/三角形数、包围盒、统一尺寸及产物 SHA。
- `check.log`：实际运行的资产核验、102 项规则/资源/存档回归、TypeScript 与生产构建结果；构建仍有既有大包提示，未上调阈值。
- `browser/report.json` 与 PNG：实际 Chromium 游戏画面、暂停、夜景、五轮重入及可选加载失败检查。文件只有在浏览器执行后才产生，缺失不视为通过。

浏览器结果包含源提交、后端和实际统计。手机仅模拟 390×844 视口与触控，不是物理手机性能结论；软件渲染帧时间不等于用户设备性能。旧森林截图仍只证明 PR #6 的冻结源码。
