# Wildlife phase-two browser evidence

These images were captured inside the production Three.js game via the \`?inspect=1\` read-only camera presets, not standalone asset renders.
- \`desktop-stag.png\` / \`desktop-goat.png\`: landscape review.
- \`mobile-stag.png\` / \`mobile-goat.png\`: simulated narrow touch viewport.
- \`browser/report.json\`: source commit, GPU backend, landmark visibility, zero shader errors and two scene lifecycle re-entries.

The same batch's design and limitations are documented in [the phase-two guide](../../docs/WILDLIFE_PHASE2.md).
The capture uses Chromium/SwiftShader; physical mobile GPU testing remains outstanding.
