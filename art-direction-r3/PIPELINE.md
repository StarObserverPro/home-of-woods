## 进入可玩版的内容

采用经过人工判断的地面锚点，再明确加入外围轮廓、营地整平、连续路线和缓岸修整，形成统一的可玩高程网格。工具为 tools/build-r3-surface.mjs，安全的标注源为 art/reference/r3-ground-annotations.json；重新生成的网格 hash 与规范文件一致。

树、巨木、木屋、帐篷、人物都是独立稳定实体，使用本轮 Blender 模型。大场景 SPZ / 网格没有接管游戏状态、碰撞、资源或存档，也没有被整块充当经营区。此做法符合主项目对 Marble 输出解析入 world 的要求。

原始 API 回执含临时链接和账号关联信息，仅留在私有沙盒目录。审查 / 回接包使用白名单，不包含这些回执和整景文件。2026-10-30已获明确授权，选定的原生场景、模型与安全标注源现已回接实现分支；原始API回执和整景文件仍不入库。
